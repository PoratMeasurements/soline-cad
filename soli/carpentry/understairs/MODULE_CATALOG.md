# MODULE_CATALOG.md — קטלוג מודולי מתחת-למדרגות של Soline (Soli Under-Stairs)

מערכת מודולים מקורית של Soline. קידומת-קוד: `U`. עומק/גובה במ"מ.
הגובה של כל מודול **מדורג** — נגזר מגובה-הסוֹפִיט בקצה-הנמוך שלו (שמרני, מלבני).

---

## סדרה מדורגת מהקצה-הנמוך לגבוה
| קוד | סוג | גובה-שמיש | מנת-רוחבים |
|---|---|---|---|
| (DEAD) | פינה-מתה | < 200 | — (אטום) |
| UPULL-<w> | משיכונים/מגש | 200–400 | 600/500/450/400 |
| UDR-<w> | בנק-מגירות | 400–900 | 800/600/500/450/400 |
| USH-<w> | מדפים קבועים | 900–1200 | 1000/900/800/600/500/450/400 |
| UB-<w> | תאים: תלייה+מדפים | 1200–1800 | 1000/900/800/600/500/450/400 |
| UCL-<w> | ארון-כניסה walk-in | ≥ 1800 | נפח-יחיד, דלת בקצה-הגבוה |

## UCL — פרטי ארון-הכניסה
| שדה | משמעות |
|---|---|
| doorH | גובה-דלת = min(שיא-גובה, 2040); <1800 → למעשה reach-in |
| railH | מוט-מעילים 1600 |
| peakHeight | גובה-הסוֹפִיט בקצה-הכניסה |

## UF — מילוי / סקרייב
| קוד | תפקיד |
|---|---|
| UF-<w> | פס-מילוי בתוך זון; <30 → `scribe` |

---

## מיפוי גיאומטריה → התנהגות (מנוע-התכנון)
```
slope = rise/run  → x לכל סף-גובה  → גבולות-הזונים
descend           → היפוך הקצה-הנמוך לקצה-הגבוה-של-הקיר
זון UCL            → נפח-יחיד + דלת בפאה-הגבוהה
זון אחר            → מילוי-חמדני; כל קרון בגובה-הסוֹפִיט בקצהו-הנמוך
beam/עמוד/stringer בתחום → נשאר; לתכנן סביבו
elec/water מתחת    → אזהרה "לא-נגישה"
```
