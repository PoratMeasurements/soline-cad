# PLANNING_LOGIC.md — מנוע-התכנון (Soli Under-Stairs)

הצינור שבו `plan_understairs.js` הופך **מדידת-חדר + תיאור-מדרגות** ל**תוכנית אחסון מדורגת** תחת
מדרגות ישרות, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`, בתוספת **תיאור-מדרגות**. חוזה-הקלט המשותף
ב-`../_lib/carpentry_core.js`. מקור-גיאומטריה, לפי-סדר: (א) fixture-מדרגות (`stair`/`מדרגות`) שנותן
`run=w`, `rise=h`, ומיקום-קצה-נמוך; (ב) דגלי `--run/--rise`; (ג) ברירת-מחדל 3600/2600 **עם אזהרה**.

## שלבים
1. **מודל-מדרגות** (`stairModel`) — קובע `wall, run, rise, slope=rise/run, a` (הסטת-קצה-נמוך), `descend`, `going`. המהלך נחתך לאורך-הקיר.
2. **גיאומטריית-סוֹפִיט** — `heightAt(x)=slope·x`; `xAtHeight(h)=h/slope`. `absAlong` ממפה מרחק-מקומי (0=נמוך) חזרה למיקום-מוחלט לאורך-הקיר, בכיבוד הכיוון.
3. **בניית-זונים** (`buildZones`) — פינה-מתה עד x(200); לכל סף-גובה זון בין x(from)→x(to):
   - **UCL** (≥1800): נפח-יחיד, דלת בפאה-הגבוהה = min(שיא, 2040), מוט 1600.
   - אחר: מילוי-חמדני של רוחב-הזון בקרונות; כל קרון בגובה-הסוֹפִיט **בקצהו-הנמוך** (מדורג, שמרני).
4. **ולידציה/אזהרות**: גובה-דלת walk-in <1800 → reach-in; פינה-מתה → אטימה/דלת-שירות; תשתית מתחת/מאחורי → "לא-נגישה"; **אלמנט מבני (זקף/עמוד) נשאר במקום**; **בדיקה-באתר חובה**; מגבלת-עומק-מגירה צדית (~going); הערת-כיוון ב-`--descend`.
5. **פלט**: `report()` עברית + `out/<room>_understairs_plan.md` + `.json` (wall/stair/zones/modules/warnings).

## וריאנטים
```
node plan_understairs.js <room> [--run N] [--rise N] [--going N]
     [--steps N] [--descend] [--out DIR]
```

## הנחות-תכן
1. מדרגות **ישרות** (משולש ישר-זווית בחתך). מדרגות מפותלות/L נדרשות מדידה נפרדת.
2. גובה-קרון = הסוֹפִיט בקצהו-הנמוך → מלבני ובטוח (לעולם לא גבוה מהסוֹפִיט בפועל).
3. **אלמנט מבני אינו זז** — האחסון מתוכנן סביבו.
4. ברירת-מחדל (3600/2600) היא מוצא-אחרון עם אזהרה — יש למדוד בפועל.
