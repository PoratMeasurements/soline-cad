# STANDARDS.md — ארון הזזה / פתיחה (Wardrobe / Closet) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **ארון-בגדים קיר** בשתי מערכות-דלת: **הזזה** (Sliding) ו**פתיחה/ציר** (Hinged),
וכן **reach-in** (ארון-נישה רדוד). מנוע-התכנון (`plan_wardrobe.js`) משתמש במספרים כאן.

---

## 1. עומק (Depth)
| מערכת | עומק גוף | הערה |
|---|---|---|
| פתיחה (ציר) | **600** | קולב תלוי דורש ~600; מוט 30מ"מ+ מהקיר האחורי |
| הזזה | **650** | + מסילה וחפיפת-כנפיים |
| reach-in (נישה) | 600 | מינימום לתלייה; 500 אפשרי לאחסון בלבד |

מוט-תלייה יישאר לפחות ~50מ"מ מתחת למדף שמעליו; המוט ≥300מ"מ מהקיר האחורי.

## 2. גבהים (Heights)
| רכיב | גובה מהרצפה | מקור-כלל |
|---|---|---|
| מוט **כפול** — עליון | ~2075 (81¾") | חלוקה כפולה |
| מוט **כפול** — תחתון | ~1030 (40½") | |
| מוט **תלייה-ארוכה** (מעילים/שמלות) | ~1750–1800 | (מוט-בסיס 66" ≈ 1676 לחולצות) |
| גוף-ארון תקן | **2400** | ארגז-על עד התקרה מעל |
| מדף עליון (מזוודות) | מעל המוט העליון | |

## 3. מדפים ומגירות
| רכיב | מרווח |
|---|---|
| מדפי-קיפול (בגדים) | ~300–320 (12") |
| מדפי-נעליים | ~180 (7") — נטוי 15° אופציונלי |
| מגירות פנימיות | בנק 5 מגירות בגובה תלייה-תחתונה |
| מרווח מוט↔מדף מעל | ≥ 50 (2") |

## 4. דלתות
| מערכת | כלל-תכן |
|---|---|
| **הזזה** | 2–4 כנפות; כנף ≤ ~1200; חפיפה ~40–50; **אין מרווח-פתיחה קדמי**; מסילה עליונה נושאת + תחתונה מיישרת |
| **פתיחה (ציר)** | כנף ≤ **600** (מעבר לכך → 2 כנפות לתא); דורש **מרווח-פתיחה ≥ רוחב-הכנף** מלפנים; צירי 35מ"מ |
| **מתקפל (bi-fold)** | חלופה כשאין מקום לציר מלא ואין תקציב הזזה |

## 5. רוחבי-תא (Bays / Carcass)
מודולריות: 1000 / 900 / 800 / 600 / 500 / 450 / 400. פערים נסגרים בפס-מילוי (WF) / סקרייב.

## 6. מרווחים וארגונומיה
- מול ארון-הזזה: אין דרישת-פתיחה; שמור מעבר-חדר ≥ 700מ"מ לגישה.
- מול ארון-ציר: מרווח-פתיחה ≥ רוחב-כנף (≥600) + מעבר.
- **כלל Soli:** תשתית (מים/חשמל/גז) שנופלת **מאחורי** ריצת-הארון = לא-נגישה → אזהרה; יש להעביר/לנתק לפני התקנה.
- חלון/דלת/קורה שחוצים את קו-הארון מקצרים/מפצלים את הריצה → אזהרה.
