# PLANNING_LOGIC.md — מנוע-התכנון (Soli Wardrobe)

הצינור שבו `plan_wardrobe.js` הופך **מדידת-חדר** (קירות + תשתיות מהמודל של Soline)
ל**תוכנית-ארון לנגר**: ריצת-תאים על קיר, מערכת-דלת, פנים לכל תא, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף מוגדר ב-`../_lib/carpentry_core.js`:
`walls[]`, כל קיר `{num,sx,sy,ex,ey,length,height,thick,fixtures[]}`, כל fixture `{name,desc,w,h,x,y}`
(`x`=מרכז לאורך הקיר, `y`=גובה מהרצפה).

## שלבים
1. **ניתוח-קיר** (`analyseWall`): כל fixture מסווג (`classify`) — פתח/מכשול מקבל **פס-חסימה עם רום-אנכי** `[z0,z1]`; תשתית נאספת כנקודה.
2. **קטע לפי-רום** (`bandSpans` על `[0,2400]`): רק חסמים שהרום-האנכי שלהם חופף לגובה-הארון מסירים אורך. חלון גבוה שאינו מגיע לגובה-הארון לא יחסום; דלת/עמוד-מלא חוסמים.
3. **בחירת-קיר**: `--wall N` מפורש, אחרת הקיר עם **הקטע-הפנוי-הגדול-ביותר** בגובה-מלא. מתחת ל-`MIN_RUN=600` → אזהרה.
4. **מילוי-תאים** (`fillSegment` עם `BAY_WIDTHS`): הגדול-לקטן 1000→400; שארית≥30 → WF, אחרת סקרייב.
5. **פנים** (`fitOut`): כל תא מקבל ייעוד לפי תמהיל-סבב (DBL/DBL/LNG/SHF/DBL/DBL/LNG/DRW/SHO) עם הגיאומטריה (גבהי-מוטות/מדפים).
6. **דלתות**: הזזה → 2–4 כנפות ≤1200 עם חפיפה; ציר → כנף ≤600 לתא (רחב→2). ברירת-מחדל הזזה; `--hinged` לציר.
7. **ארגז-על**: אם תקרה−2400 ≥ 150 → WTB.
8. **ולידציה/אזהרות**:
   - תשתית **מאחורי הריצה** → "לא-נגישה, להעביר/לנתק".
   - פתח/מכשול **חוצה הריצה** → "קיצור/פיצול".
   - ציר → "מרווח-פתיחה ≥600 מלפנים"; הזזה → "אין מרווח קדמי, מסילות".
9. **פלט**: `report()` עברית לקונסולה + `out/<room>_wardrobe_plan.md` + `.json` (wall/run/bays/doors/modules/warnings).

## וריאנטים
```
node plan_wardrobe.js <room> [--wall N] [--hinged] [--reach-in] [--out DIR]
```
- `--hinged` — דלתות-ציר במקום הזזה (מוסיף דרישת-מרווח-פתיחה).
- `--reach-in` — ארון-נישה רדוד (עומק 600, אחסון).

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר.
2. גוף-תקן 2400; מעליו ארגז-על עד התקרה.
3. הארון הוא גוף מלא-גובה → כל חלון/דלת/עמוד שחופף לגובה-הארון חוסם.
4. המנוע **מכבד את מיקום-התשתית הנמדד** — לא מזיז אותה, אלא **מסמן אזהרה** (החלטת-ההעברה של האינסטלטור/מתכנן).
5. פערים <30מ"מ = סקרייב, לא מודול.
