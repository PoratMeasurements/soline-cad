# STANDARDS.md — מבואה / ארון-כניסה (Entry / Mudroom) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **מבואה/ארון-כניסה**: רצף **לוקרים לאדם** על קיר. כל לוקר נערם אנכית:
**ספסל** (תחתית) + **תא-נעליים** מתחתיו · **אזור-ווים פתוח** מעל הספסל · **תא-עליון** למעלה;
בנוסף **ארונות-מעילים גבוהים** (מוט-מעילים) אופציונליים. **פתח/דלת** מפצל את הריצה למקטעים
(דלת-הכניסה נשמרת פנויה). מנוע-התכנון (`plan_entry.js`) משתמש במספרים כאן.

---

## 1. ספסל ונעליים (Bench)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| גובה-ספסל | **450** (טווח 450–485) | ישיבה לנעילת-נעליים |
| עומק-ספסל | **400** (380–450) | |
| פסיעת מדף-נעליים (תחת הספסל) | **~180** (7") | |

## 2. ווים ומעילים (Hooks)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| מוט-ווים למבוגר | **1700** (טווח 1525–1830) | |
| מוט-ווים לילד (משני, `--child-rail`) | **1050** (915–1220) | |
| פסיעת-ווים | **~280** (250–300) | |
| מוט-מעילים בארון-גבוה | **1600** | תלייה מלאה |

## 3. תא-עליון וגובה-ריצה (Bands)
```
ספסל          [0, 450]      (EB) + נעליים מתחת (ESH)
אזור-ווים פתוח [450, 1800]  (EHK — פאנל-גב + מוט, ללא גוף)
תא-עליון      [1800, 2100]  (EU)
ארון-מעילים גבוה [0, 2100]  (EL — מלא-גובה, מוט 1600)
```
תחתית תא-עליון = **1800** — מעל מוט-הווים כדי שמעילים יתנקו.

## 4. רוחב-אדם (Per-person)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| רוחב-לוקר יעד | **360** (טווח 300–380) | אדם בודד |
| מעל 380 (עד 450) | נוח, פחות לוקרים | הערה |
| מעל 450 (hard-max) | רחב מדי לאדם → אזהרת-פיצול | |
| מתחת 300 | צר, מעיל 17" מתקשה | אזהרה |

## 5. עומק וולידציה
- עומק-לוקר **450** (מעיל 17" תלוי); מינ' 300.
- **פתח-דלת** מפצל את הריצה — נשמר פנוי.
- נקודת-**חשמל** בריצה → הזדמנות לשקע-טעינה בתא-העליון/ספסל (הערה, לא אזהרה).
- מים/גז/ביוב מאחורי הריצה → לא-נגישה → אזהרה.
- מעל 2100 עד התקרה → ארגז-על אופציונלי.
