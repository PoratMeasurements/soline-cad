# PLANNING_LOGIC.md — מנוע-התכנון (Soli Entry)

הצינור שבו `plan_entry.js` הופך **מדידת-חדר** ל**תוכנית מבואה**: רצף לוקרים-לאדם על קיר, מפוצל
למקטעים סביב פתחים, עם ספסל/ווים/תא-עליון וארונות-מעילים, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף ב-`../_lib/carpentry_core.js`.

## שלבים
1. **בחירת-קיר** — הקטע-הפנוי הגדול עד רום-הריצה `[0,2100]`; פתח/דלת מסיר-רוחב ומפצל; `--wall N` גובר.
2. **מקטעים** (`runSegments`) — כל קטע-פנוי בין הפתחים הוא מקטע נפרד (דלת-כניסה נשמרת פנויה).
3. **בניית-לוקרים** (`buildLockers`) — כל מקטע מחולק ל-`round(len/perPerson)` לוקרים שווים; מכסת ארונות-המעילים (`coatLockers`) נצרכת ראשונה כלוקרי-EL מלאי-גובה, השאר לוקרי-ELK.
4. **ווים** — מספר ווים = `floor((w-40)/280)` בכל לוקר, בגובה-מבוגר 1700 (+ילד 1050 ב-`--child-rail`).
5. **ולידציה/אזהרות**: רוחב-לוקר >450 (פיצול) / <300 (צר) / >380 (הערת-נוחות); שפיות-גובה מוטים; ספסל 450/עומק 400; פתחים מפצלים; **חשמל** → הערת-טעינה; מים/גז/ביוב מאחורי הריצה → "לא-נגישה"; מעל 2100 → ארגז-על אופציונלי.
6. **פלט**: `report()` עברית + `out/<room>_entry_plan.md` + `.json` (wall/run/sections/modules/notes/warnings).

## וריאנטים
```
node plan_entry.js <room> [--wall N] [--per-person W]
     [--coat-lockers N] [--child-rail] [--out DIR]
```

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר; `y` = גובה מהרצפה.
2. פתח/דלת = מחיצה טבעית — הריצה **מתפצלת** ולא נכפית לרוחב-מלא.
3. הלוקר האחרון בכל מקטע סופג את שארית-העיגול (לוקרים שווים ככל האפשר).
4. חשמל במבואה = **הזדמנות** (שקע-טעינה), לא בהכרח קונפליקט.
