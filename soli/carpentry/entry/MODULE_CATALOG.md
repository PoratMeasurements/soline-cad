# MODULE_CATALOG.md — קטלוג מודולי המבואה של Soline (Soli Entry)

מערכת מודולים מקורית של Soline. קידומת-קוד: `E`. עומק/גובה במ"מ.
`plan_entry.js` בונה את הריצה אך ורק ממודולים אלו. עומק-לוקר 450.

---

## לוקר-סטנדרטי (ELK) — ערימה אנכית לאדם
כל לוקר-סטנדרטי מורכב מארבעה חלקים באותו רוחב-אדם:

| קוד | תפקיד | רצועה |
|---|---|---|
| ESH-<w> | תא-נעליים (תחת הספסל) | [0, 450] |
| EB-<w> | ספסל-ישיבה | ~450 |
| EHK-<w> | אזור-ווים פתוח (פאנל-גב + מוט) | [450, 1800] |
| EU-<w> | תא-עליון / ארונית | [1800, 2100] |

> `ELK-<w>` הוא קוד-האב הלוגי של הערימה; רשימת-החיתוך סופרת את ארבעת החלקים.

## EL — ארון-מעילים גבוה (Tall coat locker)
| קוד | תפקיד |
|---|---|
| EL-<w> | לוקר מלא-גובה [0,2100] עם מוט-מעילים 1600 (`--coat-lockers N`) |

---

## פרמטרים
```
--per-person W   רוחב-אדם יעד (ברירת-מחדל 360, טווח 300–380)
--coat-lockers N מספר ארונות-מעילים גבוהים בתחילת הריצה (ברירת-מחדל 1)
--child-rail     הוספת מוט-ווים משני לילד @1050
```

## מיפוי גיאומטריה / תשתית → התנהגות (מנוע-התכנון)
```
door/opening על הקיר   → פיצול הריצה למקטעים; הפתח נשמר פנוי
רוחב-לוקר >450 / <300  → אזהרת פיצול / צר
elec בריצה             → הערת שקע-טעינה (הזדמנות, לא אזהרה)
water/gas/drain בריצה  → אזהרה "לא-נגישה"
מעל 2100 → ארגז-על אופציונלי (הערה)
```
