# STANDARDS.md — חדר-כביסה / ארון-שירות (Laundry / Utility) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **אזור-כביסה נגרותי**: מכונת-כביסה + מייבש (זה-לצד-זה או מוערמים),
**משטח-קיפול** מעליהם/לצידם, **ארוניות-עליונות**, **ארון-שירות/מטאטאים גבוה**, ו**כיור** אופציונלי.
המכשירים ממוקמים על **נקודות-התשתית** של הקיר (מים+ניקוז למכונה, תעלת-אוורור למייבש, חשמל לשניהם).
מנוע-התכנון (`plan_laundry.js`) משתמש במספרים כאן.

|---|---|

## 6. רצועות-גובה (Bands)
```
בסיס / מכשירים   [0, 900]     (LB, LB-APP, LB-SINK)  → משטח 900 מעל
מוערם            [0, 1800]    (LB-APP stacked — ללא משטח/עליונות מעליו)
עליונות          [1500, 2100] (LU)
ארון גבוה        [0, 2100]    (LT — מלא-גובה, קוטע משטח/עליונות)
```
עוגן-שירות: **LB-APP (600)** יושב על מים+ניקוז (מכונה) / תעלה (מייבש).

## 7. מרווחים וולידציה
- **מרווח-חזית** מול המכשירים לפתיחת-דלת/פריקה: **≥1065** (42"–48"). המנוע מודד מרחק לקיר-הנגדי → אזהרה אם קטן.
- **מרווח-אחורי**: ≥150 לצינורות (הערה — מקטין עומק-שימושי).
- **מרווח-עליונות**: תחתית-עליונה ≥600 מעל המשטח (≈1500 מהרצפה).
- **בלי מים+ניקוז** → אין מכונה/כיור → אזהרה.
- **בלי תעלת-אוורור** → אין פינוי-מייבש → אזהרה (או מייבש-קונדנסציה).
- **בלי חשמל** → אזהרה.
- **ניקוז-רצפה / מגש-הצפה**: אם קיים floor-drain → הערת התקנת-מגש אנטי-הצפה תחת המכונה.
- תשתית שנופלת **מאחורי ארון-בסיס רגיל** (לא מכשיר/כיור) → אזהרת "מכוסה/לא-מנוצלת".
- חלון/קורה החוצה את רצועת-העליונות → פיצול/קיצור העליונות + אזהרה.
