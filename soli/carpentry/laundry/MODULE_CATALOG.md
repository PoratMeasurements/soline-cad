## מיפוי תשתית → התנהגות (מנוע-התכנון)
```
water+drain (עוגן ראשי)  → מכונת-כביסה / כיור; ציון-קיר 50+50
duct                     → מייבש-פינוי; ציון 20
elec                     → הזנת-מכשירים; ציון 15
water/drain/duct חסר     → אזהרה (אין מכונה/מייבש/כיור עד תיאום)
floor-drain (y<50)       → הערת מגש אנטי-הצפה
water/drain/gas מאחורי LB רגיל (לא מכשיר/כיור) → אזהרה "מכוסה/לא-מנוצלת"
window|beam חוצה         → קיצור/פיצול
עומק-חדר − 600 < 1065     → אזהרת מרווח-חזית צפוף
```
