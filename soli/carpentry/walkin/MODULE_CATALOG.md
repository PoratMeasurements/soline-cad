# MODULE_CATALOG.md — קטלוג מודולי חדר-הארונות של Soline (Soli Walk-in)

מערכת מודולים מקורית של Soline. קידומת-קוד: `C`. עומק/גובה במ"מ.
`plan_walkin.js` בונה את החדר אך ורק ממודולים אלו.

---

## CB — תא-גוף (Carcass Bay)

## מיפוי תשתית / גיאומטריה → התנהגות (מנוע-התכנון)
```
door רצפתי על קיר            → הקיר = קיר-כניסה, נשמר פנוי (אין ריצה)
elec/water/gas מאחורי ריצה  → אזהרה "לא-נגישה"
window|beam חוצה ריצה        → קיצור/פיצול + אזהרה
מעבר < 610 / 610–900 / <1070 → חסום / צר / עובר-צפוף
פנים פנוי אחרי מעברים ≥ אי   → הנחת CISL, אחרת אזהרה
```
