# PLANNING_LOGIC.md — מנוע-התכנון (Soli Walk-in)

הצינור שבו `plan_walkin.js` הופך **מדידת-חדר** ל**תוכנית חדר-ארונות**: ריצות מלאות-גובה על מספר
קירות, צורת-פריסה, מעברים, אי-מרכזי, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף ב-`../_lib/carpentry_core.js`:
`walls[]`, כל קיר `{num,sx,sy,ex,ey,length,height,thick,fixtures[]}`, כל fixture `{name,desc,w,h,x,y}`.

## שלבים
1. **ניתוח כל הקירות** (`analyseWall`) — כל fixture → חוסם עם רום-אנכי או נקודת-תשתית.
2. **החלטה פר-קיר**:
   - קיר עם **פתח-דלת רצפתי** (`z0<100`) → `door` (קיר-כניסה, נשמר פנוי).
   - אחרת הקטע-הפנוי הגדול בגובה-מלא `[0,2400]`; `<MIN_RUN=600` → `short` (אין ריצה).
   - אחרת → `run`: מילוי-תאים `CB` + פנים `CI` (סבב רציף `mixIdx` בין הקירות) + ארון-על `CU`.
3. **צורת-פריסה** (`decideShape`) לפי מספר קירות-הריצה: 1=בודד · 2=מקבילי(אותה אוריינטציה)/L(ניצבים) · 3=U · 4=היקפי.
4. **מעברים** (`computeAisles`) — לכל קבוצת-אוריינטציה (H/V), מרווח-הקירות פחות עומקי-הריצות = מעבר; דירוג נוח/תקין/צר/חסום.
5. **אי-מרכזי** (`interiorClear`) — מלבן-הפנים אחרי החסרת עומקי-הריצות; אם נשאר ≥900 מכל צד + ≥600 → `CISL`, אחרת אזהרה.
6. **ולידציה/אזהרות**: תשתית מאחורי ריצה → "לא-נגישה"; פתח/מכשול חוצה ריצה → "קיצור/פיצול"; מעבר צר/חסום → אזהרה מדורגת.
7. **פלט**: `report()` עברית + `out/<room>_walkin_plan.md` + `.json` (shape/walls/aisles/interior/island/modules/warnings).

## וריאנטים
```
node plan_walkin.js <room> [--depth MM] [--no-island] [--out DIR]
```
- `--depth` — עומק-ריצה (ברירת-מחדל 610).
- `--no-island` — לא להניח אי גם אם יש מקום.

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר.
2. אוריינטציית-קיר נקבעת מהפרש-הקצוות (H אם |Δx|≥|Δy|).
3. מעבר נמדד בין שני הקירות הקיצוניים בכל אוריינטציה.
4. המנוע **מכבד את מיקום-התשתית הנמדד** — לא מזיז, אלא **מסמן אזהרה**.
5. פערים <30מ"מ = סקרייב, לא מודול.
