# STANDARDS.md — חדר-ארונות (Walk-in Closet) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **חדר-ארונות**: חדר המרוצף ריצות-ארון מלאות-גובה על **מספר קירות**, עם **מעבר-הליכה**
ביניהן ו**אי-מרכזי** אופציונלי. בשונה ממודול-הארון (קיר-בודד), המנוע כאן עובר על **כל הקירות**,
בונה ריצה בקטע-הפנוי הגדול בכל קיר, ומחליט **צורת-פריסה** (בודד / מקבילי / L / U / היקפי) לפי מספר
הקירות הנושאים ריצה. מנוע-התכנון (`plan_walkin.js`) משתמש במספרים כאן.

---

## 1. עומק-ריצה (Run depth)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| ריצת-תלייה | **610** (24") | קולב תלוי + מוט מתנקה מהקיר |
| גוף מלא-גובה | **2400** | ארון-על (CU) מעל עד התקרה |
| ריצת-מדפים-בלבד | 350–400 אפשרי | ללא תלייה |

## 2. מעבר-הליכה (Aisle) בין ריצות מנוגדות
| דרגה | ערך | משמעות | מקור-כלל |
|---|---|---|---|
| מוחלט (מינימום) | **610** (24") | אפשר להידחק, אי-אפשר לפתוח מגירה | |
| מעשי | **900** (36") | אדם / כיסא-גלגלים | מינימום-נגישות |
| נוח | **1070** (42") | מגירה נפתחת + אדם עומד | |

בחדר עם שתי ריצות מקבילות: מרווח-קירות − 2×עומק-ריצה = מעבר. המנוע מודד זאת פר-ציר.

## 3. אי-מרכזי (Island)
| רכיב | ערך |
|---|---|
| רום-משטח | **950** (36"–40") |
| עומק | 600–900 |
| רוחב-מקס | 1400 |
| מעבר חופשי סביב | **≥900 מכל ארבעת הצדדים** |
| פנים | בנקי-מגירות דו-צדדיים |

אי מונח **רק** כשנשאר ≥900 מכל צד + גוף-אי ≥600.

## 4. רוחבי-תא (Bays / Carcass)
מודולריות: 1000 / 900 / 800 / 600 / 500 / 450 / 400. פערים → פס-מילוי (CF) / סקרייב.
מתחת ל-**MIN_RUN=600** קיר אינו נושא ריצה.

## 5. פנים (Interior fit-out) — סבב משותף עם הארון
כפול-תלייה (2075/1030) · תלייה-ארוכה (~1750) · מדפים (~320) · מגירות (בנק-5) · נעליים (~180).
תמהיל-סבב **רציף על-פני כל הקירות** (~50% כפול, ~25% ארוך, ~25% אחסון).

## 6. קיר-כניסה וולידציה
- **קיר-כניסה** (נושא פתח-דלת רצפתי) נשמר **פנוי** — לא מונחת עליו ריצה.
- **כלל Soli:** תשתית שנופלת **מאחורי** ריצה = לא-נגישה → אזהרה (העברה/ניתוק).
- פתח/מכשול **חוצה ריצה** → קיצור/פיצול + אזהרה.
- מעבר מתחת ל-610 = **חסום**; 610–900 = **צר**; 900–1070 = עובר-אך-צפוף.
