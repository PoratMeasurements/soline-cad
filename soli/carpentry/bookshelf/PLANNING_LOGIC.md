# PLANNING_LOGIC.md — מנוע-התכנון (Soli Bookshelf)

הצינור שבו `plan_bookshelf.js` הופך **מדידת-חדר** ל**תוכנית-ספרייה**: רצף תאים-אנכיים מוגבלי-מוטת-
שקיעה, מדפים לתא, בסיס-סגור אופציונלי, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף ב-`../_lib/carpentry_core.js`.

## שלבים
1. **פרמטרים** — חומר (`--material` → MAX_SPAN + מנת-רוחבים), עומק (`--depth`, מוגבל 200–350), פסיעה (`--pitch`, 200–380), מתכוונן (ברירת-מחדל; `--fixed` לקבוע), גובה (`--height`, ברירת-מחדל 2400).
2. **בחירת-קיר** — הקטע-הפנוי הגדול בגובה `[0,H]`; `--wall N` גובר.
3. **`--low`** — אם יש חלון חוסם, הגובה מונמך לסף−50 (רצה מלאה מתחת לחלון).
4. **ריצה + קטעים** — הקטע הגדול = ריצה-ראשית; קטעים נוספים ≥MIN_RUN מדווחים כהרחבה.
5. **תאים** (`fillSegment` עם מנת-החומר) — הגדול-לקטן; **מקס-המנה = MAX_SPAN** → אף תא לא נשקע.
6. **מדפים** (`shelfPlan`) — אזור-פתוח = H − (בסיס 800 / רגל 80); תאים = `round(openH/pitch)`; לוחות = תאים+1.
7. **בסיס-סגור** אופציונלי (`--base`): מבוטל אם H נמוך מ-1000.
8. **ולידציה/אזהרות**: שמירת מוטב-שקיעה (כל תא ≤ MAX_SPAN); **חובה anti-tip**; מתכוונן/קבוע; הערת-עומק; תשתית מאחורי הריצה; פתח/קורה חוצה; קטעים-פנויים נוספים.
9. **פלט**: `report()` עברית + `out/<room>_bookshelf_plan.md` + `.json` (wall/material/run/height/maxSpan/bays/totalShelfMetres/modules/warnings).

## וריאנטים
```
node plan_bookshelf.js <room> [--wall N] [--material melamine|ply|solid]
     [--height MM] [--low] [--depth MM] [--pitch MM] [--base] [--fixed] [--out DIR]
```

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר.
2. **מוטת-שקיעה נאכפת דרך המנה** — לא בדיקת-עומס נפרדת; בחירת-חומר קובעת את הגבול.
3. עליון/תחתון תמיד קבועים מבנית; רק הפנימיים מתכווננים.
4. פערים <30מ"מ = סקרייב.
