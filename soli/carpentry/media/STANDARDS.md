# STANDARDS.md — יחידת-טלוויזיה / קיר-מזנון (Media Wall) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **קיר-מזנון/יחידת-טלוויזיה**: **קונסולה-נמוכה** (lowboy) לאורך התחתית, **נישת-TV
פתוחה** (ללא דלת) הממורכזת על **נקודת-השירות הנמדדת** (טלוויזיה/קואקס/חשמל), **אגפים-גבוהים**
בקצוות, ו**עליונים** מסביב לנישה + **מדף-צף** מעל הצג. הנישה היא **עוגן-שירות** — כבל/קופסת-מדיה
שקועה נופלים מאחורי הצג בדיוק. מנוע-התכנון (`plan_media.js`) משתמש במספרים כאן.

---

## 1. גבהים אנכיים (Vertical bands)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| רום קונסולה-נמוכה | **520** | טווח ציבורי 450–550 |
| עומק קונסולה | **400** | 350–450 |
| מרווח פתוח קונסולה↔תחתית-צג | **90** | |
| מרווח-אוורור עליון מעל הצג | **120** | חום עולה |
| תחתית-עליונים (upper band) | **1450** | עליונים/מדף [1450, 2100] |
| גובה-תכנון כולל | **2100** | כל הפסים ב-[0,2100] |

## 2. גובה-הצג (Screen)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| מרכז-צג בישיבה | **1000–1100** | גובה-עיניים בישיבה |
| מרכז קופסת-חשמל/מדיה שקועה | **~1067** (42") | לצג 55–65" |
| חישוב מידות-צג | 16:9 מהאלכסון(אינץ') | ברירת-מחדל 65" |

תחתית-הצג = רום-קונסולה + 90; מרכז-הצג נגזר; המנוע מוודא שהוא בטווח 1000–1100.

## 3. נישה, קונסולה, אגפים
| רכיב | מנה (menu) / כלל |
|---|---|
| רוחב-נישה (R-menu) | 1600 / 1400 / 1200; ≥ רוחב-צג + 150 |
| קונסולה (MB) | 1200/1000/900/800/600; רוחב-צג+~600, ≥ נישה |
| אגף-גבוה (MT) | 900/800/600/500/450; צד <450 = צר מדי → מבוטל |
| עליון-נישה (MU) | 900/800/600/500/450; פער <300 → מילוי |
| מדף-צף (MSH) | ברוחב-הנישה, מעל הצג + מרווח-אוורור |

## 4. שירות ואוורור — כללי-ליבה
- **חובה** חשמל (ורצוי TV/קואקס + data) בקיר. חוסר → אזהרת-תיאום.
- **ניהול-כבלים:** חיתוך מעבר-כבלים בגב מיושר ל-X של **נקודת-השירות הנמדדת** (מרכז-הנישה).
- **אוורור:** מרווח-אחורי ≥60 מאחורי רכיבים + פתח-אוורור עליון.
- נקודת-שירות **מחוץ לנישה אך בתוך הריצה** → מאחורי ארון, לא-נגישה → אזהרה (למקם מחדש למרכז-הנישה).
- פתח/קורה חוצה הריצה → קיצור/פיצול.
