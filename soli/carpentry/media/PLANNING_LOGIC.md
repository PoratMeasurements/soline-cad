# PLANNING_LOGIC.md — מנוע-התכנון (Soli Media)

הצינור שבו `plan_media.js` הופך **מדידת-חדר** ל**תוכנית קיר-מזנון**: קונסולה-נמוכה, נישת-TV פתוחה
על נקודת-השירות, אגפים, עליונים, מדף-צף, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף ב-`../_lib/carpentry_core.js`.
(ברירת-המחדל היא `sample_room.json` של הסוג — סלון עם נקודת-TV — ואם אין, חדר-allelem של הממיר.)

## שלבים
1. **בחירת-קיר** — ציון פר-קיר לפי תשתיות-מדיה (`SVC_SCORE`: tv 100, elec 40, data 10; water/drain/gas = −999) + שובר-שוויון לפי אורך-קטע-פנוי; `--wall N` גובר.
2. **ריצה** = הקטע-הפנוי הגדול בגובה-התכנון `[0,2100]`; `<MIN_RUN=1200` → אזהרה.
3. **בדיקת-שירות** — אין elec/tv → תיאום-חשמלאי; אין tv → נישה תמורכז על חשמל; אין data → המלצת RJ45.
4. **עוגן** (`pickAnchor`) — נקודת tv > elec > data הקרובה למרכז-הריצה (אחרת מרכז גיאומטרי).
5. **מידות-צג** — 16:9 מהאלכסון (`--tv`, ברירת-מחדל 65"); רוחב-נישה מ-R-menu ≥ רוחב-צג+150.
6. **קונסולה + אגפים** — קונסולה ממורכזת על העוגן (רוחב-צג+~600, ≥ נישה); שארית בכל צד ≥450 → אגף-גבוה MT.
7. **נישה** — מוצמדת לאזור-הפנים בין האגפים, ממורכזת על העוגן.
8. **גובה-צג אנכי** — תחתית = 520+90; מרכז נגזר; שיא-נישה = תחתית+גובה-צג+120.
9. **עליונים** — פערי-נישה בצדדים ≥300 → MU (אחרת מילוי); **מדף-צף** MSH ברוחב-הנישה.
10. **ולידציה/אזהרות** — מרכז-צג מחוץ ל-1000–1100; גובה-קופסה נמדד מול ~1067; נקודה מחוץ-לנישה/מחוץ-לריצה; פתח חוצה; תזכורות אוורור + חיתוך-כבלים ב-X הנמדד; מרווח מעל היחידה עד התקרה.
11. **פלט**: `report()` עברית + `out/<room>_media_plan.md` + `.json`.

## וריאנטים
```
node plan_media.js <room> [--wall N] [--tv 65] [--out DIR]
```
- `--tv` — אלכסון-צג באינץ' (קובע רוחב-נישה + גובה-מרכז).
- `--wall` — כפיית-קיר.

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר; `y` = גובה מהרצפה.
2. הנישה **פתוחה** (ללא דלת) — אוורור פסיבי לרכיבים.
3. המנוע **מכבד את מיקום-התשתית הנמדד** — מיישר את מעבר-הכבלים אליה ומזהיר כשהיא מחוץ-לנישה.
4. פערים <30מ"מ = סקרייב.
