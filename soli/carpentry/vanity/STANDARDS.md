# STANDARDS.md — ארון-אמבטיה (Bathroom Vanity) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **ארון-אמבטיה (וניטי)**: ריצת-בסיס עם **כיור** המעוגן על נקודת **מים+ניקוז**
הנמדדת (הברז + הסיפון נופלים מאחוריו), **משטח** רציף, **מראה/ארונית-מראה** מעל, **מגדל-פשתן**
גבוה אופציונלי, ו**כיור-שני** אופציונלי. סביבה **רטובה** — חומרים עמידי-לחות. מנוע-התכנון
(`plan_vanity.js`) משתמש במספרים כאן.

---

## 1. גובה ועומק בסיס (Base)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| גובה-משטח סטנדרטי | **850** (32"–34") | וניטי קלאסי |
| גובה-משטח comfort (`--comfort`) | **900** (36") | כמו מטבח, פחות התכופפות |
| עומק-בסיס | **550** (21"–22") | |
| פאנל-רגל (toe kick) | 100 | |
| עובי-סלאב (משטח) | ~30 | |

## 2. כיור (Sink) — עוגן-שירות
| רכיב | ערך | מקור-כלל |
|---|---|---|
| רוחב ארון-כיור | **600–900** (מנה 900/800/700/600) | כיור בודד |
| מינ' מעשי | 600 | |

| רכיב | ערך | מקור-כלל |
|---|---|---|
| תחתית-מראה | **1100** (מעל ה-backsplash) | |

## 4. מגדל-פשתן וגובה (Tall linen)
| רכיב | ערך |
|---|---|
| רוחב-מגדל | **300–400** |
| גובה-מגדל | 2000 |
| תפקיד | מגבות/אחסון גבוה (`--tower`) |

## 5. מרווחים וולידציה
- **מרווח-חזית:** ≥600 (21"–30") רצפה פנויה מול הכיור; ≥750 נוח. המנוע מודד מול הקיר-הנגדי.
- **בלי מים+ניקוז** → אין כיור עד תיאום אינסטלציה → אזהרה.
- **מים/ניקוז מאחורי ארון-בסיס רגיל** (לא כיור) → מכוסה/לא-מנוצל → אזהרה.
- חלון/קורה חוצה קו-הבסיס → קיצור/פיצול.
- **סביבה רטובה:** גוף/חזית עמידי-לחות (MDF מצופה / PVC / דיקט-ימי), רגליות-ALU מוגבהות, איטום סיליקון.
