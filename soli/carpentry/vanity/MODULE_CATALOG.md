# MODULE_CATALOG.md — קטלוג מודולי ארון-האמבטיה של Soline (Soli Vanity)

מערכת מודולים מקורית של Soline. קידומת-קוד: `V`. עומק/גובה במ"מ. חומרים **עמידי-לחות**.
`plan_vanity.js` בונה את היחידה אך ורק ממודולים אלו.

---

## VB — ארון-בסיס (Base cabinet)
גובה 850 (או 900 comfort) · עומק 550.

| קוד | רוחב | תפקיד |
|---|---|---|
| VB-300 … VB-800 | 300/400/450/500/600/800 | מגירות/דלתות בסיס (ממלא את שארית הריצה) |

| קוד | רוחב | תפקיד |
|---|---|---|
| VB-SINK-<w> | 600/700/800/900 | ארון-כיור על נקודת **מים+ניקוז**; סיפון + ברז מתחתיו |

## מיפוי תשתית → התנהגות (מנוע-התכנון)
```
water+drain (עוגן ראשי)  → מרכז VB-SINK; ציון-קיר 50+50
elec                     → תאורת-מראה + GFCI; ציון 10
water/drain חסר          → אזהרה "אין כיור עד תיאום אינסטלציה"
מים↔ניקוז מרוחקים >400    → אזהרה "לוודא תחת אותו כיור"
water/drain מאחורי VB רגיל → אזהרה "מכוסה/לא-מנוצלת"
--double + מים שני         → כיור-שני; אחרת אזהרה
window|beam חוצה           → קיצור/פיצול
עומק-חדר − 550 < 600        → אזהרת מרווח-חזית צר
```
