# PLANNING_LOGIC.md — מנוע-התכנון (Soli Office)

הצינור שבו `plan_office.js` הופך **מדידת-חדר** ל**תוכנית עמדת-עבודה**: משטח, מרווח-ברכיים, פדסטלים,
עליונים, ארון-צריח, פתח-כבלים, רשימת-מודולים ואזהרות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף ב-`../_lib/carpentry_core.js`.

## שלבים
1. **בחירת-קיר** — הקטע-הפנוי הגדול ב**רצועת-המשטח** `[0,740]` (חלון בסף≥740 אינו חוסם); `--wall N` גובר.
2. **ארון-צריח** אופציונלי (`--tower`) — נוגס 600 מתחילת הריצה אם נשאר ≥MIN_RUN.
3. **בסיס** (`planBase`) — מרווח-ברכיים ממורכז (יעד 700, מינ' 600); שאריות לצדדים → בנקי-מגירות OB.
4. **עליונים** (`planUppers`) — קטעים פנויים ברצועה `[1150,2100]` שחופפים לריצה; מדף OSH או ארונית OU (`--uppers-cabinet`); `--no-uppers` לביטול.
5. **פתח-כבלים** (`planGrommet`) — נקודת data > elec > tv בריצה (אחרת מרכז).
6. **ולידציה/אזהרות**: מרווח-ברכיים <600; חוסר חשמל/רשת; **נסיגת-כיסא** (עומק-חדר−משטח <900); חלוקת-משטח >3000; חלון מעל-משטח = הערה; פתח/קורה חוצה; תשתית-רטובה מאחורי פדסטל.
7. **פלט**: `report()` עברית + `out/<room>_office_plan.md` + `.json` (wall/run/worktop/knee/pedestals/tower/uppers/grommet/modules/warnings).

## וריאנטים
```
node plan_office.js <room> [--wall N] [--depth MM] [--uppers-cabinet]
     [--no-uppers] [--tower] [--out DIR]
```

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר; `y` = גובה מהרצפה.
2. **עומק-חדר** נאמד מהקיר-הניצב הקצר ביותר (שמרני) לצורך נסיגת-כיסא.
3. חלון בגובה ≥740 מעל המשטח = אור-טבעי, מטופל כהערה ולא כחסם.
4. פערים <30מ"מ = סקרייב/פאנל-רגל.
