# MODULE_CATALOG.md — קטלוג מודולי חדר-הילדים של Soline (Soli Kids)

מערכת מודולים מקורית של Soline. קידומת-קוד: `K`. עומק/גובה במ"מ.
`plan_kids.js` בונה יחידה מרוכבת (ארון + שולחן + מדפים) אך ורק ממודולים אלו.

---

## מיפוי גיל / גיאומטריה → התנהגות (מנוע-התכנון)
```
--age → גובה-KDESK (toddler 620 / child 680 / teen 740)
window בריצה  → השולחן מתחת לחלון, הארון בצד-הרחב
elec/שירות מאחורי הריצה → אזהרה "לא-נגישה"
שירות y<400 בריצה → אזהרת בטיחות-ילדים
door|beam חוצה → קיצור/פיצול · תמיד → אזהרת anti-tip + פינות רכות
```
