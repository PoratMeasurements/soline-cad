# STANDARDS.md — חדר-ילדים / לימוד (Kids Room) — תקני Soli

> **גבול קניין-רוחני:** נבנה אך ורק מתקני-תעשייה ציבוריים ומהיגיון מקורי של Soline.
> לא נפתח/הועתק שום קובץ/מודול/DWG של צד-שלישי. יחידות במ"מ אלא אם צוין.

מודול זה מכסה **יחידת-ילדים מרוכבת** על קיר אחד, המשלבת שלושה אזורים:
**ארון** + **שולחן-לימוד** + **מדפים**. הכל ממוד לילד ו**מותאם-גיל** (ילדים מתבגרים מגובה-שולחן
קבוע תוך ~3 שנים — כלל 90-90-90). **עיגון נגד-התהפכות חובה.** מנוע-התכנון (`plan_kids.js`)
משתמש במספרים כאן.

## 1. גובה-שולחן לפי-גיל (Age-adjustable)
| גיל | קוד-דגל | גובה-שולחן | מקור-כלל |
|---|---|---|---|
| פעוט 3–6 | `--age toddler` | **620** | טבלאות-ארגונומיה |
| ילד 6–10 | `--age child` (ברירת-מחדל) | **680** | |
| נער/ה 10+ | `--age teen` | **740** | קרוב למבוגר |

> **מומלץ מנגנון גובה מתכוונן** — ילד גדל; כלל 90-90-90 (מרפק/ירך/ברך ~90°).

## 2. ארון-ילדים (מוקטן)
| רכיב | ערך | מקור-כלל |
|---|---|---|
| גובה-ארון | **2000** (לא 2400 של מבוגר) | בהישג-יד |
| עומק-גוף | **550** (< 600 של מבוגר) | קולב-ילד |
| מוט-תלייה נגיש | **1100** (טווח 1000–1200) | **יחיד**, לא כפול-2075 |
| פסיעת-מדף | ~320 | |

## 3. שולחן ומדפים
| רכיב | ערך |
|---|---|
| עומק-משטח | **500** |
| מרווח-ברכיים מינ' / מומלץ | **550 / 600** |
| מדפים פתוחים מעל השולחן | טווח **1150–1900** (בהישג-יד ילד) |
| פסיעת-מדף | ~320 |

## 4. אזורים ובטיחות
| רכיב | ערך |
|---|---|
| אזור-ארון (יעד/טווח) | 1400 (900–1600) |
| אזור-שולחן (יעד/טווח) | 1100 (1000–1300) |
| אזור-מדפים מינ' | 400 |
- **חובה עיגון anti-tip** לכל הגופים — בטיחות-ילדים.
- **פינות מעוגלות/רכות**, ללא קצוות חדים בהישג-יד.
- שקע/שירות בגובה **<400** בריצה → בטיחות-ילדים: להגביה/לכסות/להעביר.
- **חלון מעל השולחן** = אור-טבעי (לא קונפליקט); המנוע ממקם את השולחן תחת החלון כשאפשר.
