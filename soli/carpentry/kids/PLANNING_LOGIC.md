# PLANNING_LOGIC.md — מנוע-התכנון (Soli Kids)

הצינור שבו `plan_kids.js` הופך **מדידת-חדר** ל**תוכנית יחידת-ילדים מרוכבת**: ארון + שולחן-לימוד
מותאם-גיל + מדפים על קיר אחד, רשימת-מודולים ואזהרות-בטיחות.

## קלט
`.ordx` (Soline Measure XML) **או** `room.json`. חוזה-הקלט המשותף ב-`../_lib/carpentry_core.js`.

## שלבים
1. **גיל** — `--age` → גובה-שולחן (620/680/740).
2. **בחירת-קיר** — הקטע-הפנוי הגדול ב**רצועת-רצפה** `[0,300]` (חלון גבוה אינו חוסם); `--wall N` גובר.
3. **הקצאת-אזורים** (`allocateZones`):
   - **מודע-חלון**: אם יש חלון בריצה, השולחן ממוקם **תחתיו**, והארון בצד-הפנוי-הגדול, מדפים בצד השני.
   - **רציף**: אחרת ארון · שולחן · מדפים לפי הסדר; ריצה קצרה מעדיפה ארון+שולחן ומצמצמת מדפים.
4. **בניית-אזורים**: ארון (`buildWardrobe`, תאים KB + פנים KI בסבב) · שולחן (`buildDesk`, KDESK + פדסטל KI-DRW + ברכיים) · מדפים (`buildShelves`, מגדלי KSH בטווח 1150–1900).
5. **ארגז-על** KU מעל הארון (2000) עד התקרה.
6. **ולידציה/בטיחות**: גובה-לפי-גיל + מתכוונן; **anti-tip חובה**; פינות-רכות; מוט נגיש 1100; מרווח-ברכיים <550; תשתית מאחורי הריצה; **שירות נמוך <400 = בטיחות-ילדים**; טיפול-חלון; פתח/קורה חוצה.
7. **פלט**: `report()` עברית + `out/<room>_kids_plan.md` + `.json` (wall/age/deskHeight/run/zones/modules/warnings).

## וריאנטים
```
node plan_kids.js <room> [--age toddler|child|teen] [--wall N] [--out DIR]
```

## הנחות-תכן
1. `x` של fixture = מרכז לאורך הקיר; `y` = גובה מהרצפה.
2. **חלון = הזדמנות** (שולחן תחתיו לאור-טבעי), לא חסם.
3. הכל ממוד לילד: ארון 2000, מוט יחיד 1100, עומק 550 — לא מידות-מבוגר.
4. פערים <30מ"מ = סקרייב.
