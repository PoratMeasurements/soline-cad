# MODULE_CATALOG.md — קטלוג המודולים של Soline (Soli Kitchen v2)

מערכת מודולים מקורית של Soline. קודים בפורמט `S<טיפוס>-<תת>-<רוחב>`.
המתכנן `plan_kitchen.js` בונה את התוכנית אך ורק ממודולים אלו.
עומק/גובה במ"מ. `תשתיות` = מה שהמודול דורש כדי לתפקד.

> **גבול קניין-רוחני:** כל המידות והפרזול נגזרו מ**תקני-תעשייה ציבוריים** (Blum / Häfele /
> GRASS / Hettich / IKEA Metod / Nobilia carcass-practice / NKBA) ומהיגיון-מקורי של Soline.
> לא נפתח ולא הועתק שום מודול/DWG/קורפוס של צד-שלישי.

## SF / SP / STK — מילויים, לוחות, סוקל
| קוד | רוחב | תפקיד |
|---|---|---|
| SF-20 … SF-120 | 20–120 | פס-מילוי/סקרייב |
| SP-END | עומק-גוף | לוח-צד חשוף / החזרת-פינה |
| SP-BACK | לפי-ארון | גב חשוף (אי/חצי-אי) |
| STK | רץ | סוקל (toe-kick) גובה 100 |

> פערים < 20 מ"מ נספגים כ**סקרייב** בתוך הארון הסמוך (שדה `scribe`). פערים > 120 מ"מ → אזהרה.

## מיפוי תשתית → מודול (משמש את מנוע-התכנון)
```
water + drain            → SB-SINK
gas | elec(3ph)          → SB-HOB   (+ SW-HOOD מעל)
water + drain + elec     → SB-DW    (ליד הכיור; prio-נמוך)
elec                     → ST-FRIDGE / ST-OVEN
duct + elec              → SW-HOOD  (מעל הכיריים)
```
ראה `KITCHEN_STANDARDS.md` לפרטי הפרזול (Blum/Häfele) והחומרים, ו-`PLANNING_LOGIC.md` לאלגוריתם.
