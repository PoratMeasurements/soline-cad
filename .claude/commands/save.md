# שמירת-פרויקט Soline (סוף-סשן)

בצע שמירה מסודרת של מצב-הפרויקט. זו הפקודה שהבעלים מריץ בסוף רצף-עבודה/סשן.

1. **עדכן את לוח-הטאבלט** `G:\My Drive\claude\Soline\SOLINE_BOARD.html` למצב-הנוכחי (חותמת-זמן, סוכנים-רצים, מסלולי-עבודה, קבצים-לאישור, ממתין-ממך), ופרסם מחדש כ-Artifact **לאותו URL** (אותו file_path — שומר על אותו קישור/QR בטאבלט).
2. **עדכן את `SESSION_STATE.md`** — סנאפשוט חדש מתוארך עם מה שנעשה, מה רץ, ומה ממתין. שמור על עקרון "הכל-בקבצים".
3. **סגור קצוות:** ודא שאין `desktop.ini` תועים ב-`_LATEST`; ודא שסוכנים-רצים מתועדים (כדי שאפשר יהיה לחדש); רשום ב-SESSION_STATE כל תלות-שממתינה-לבעלים.
4. **דווח בקצרה** לבעלים: מה נשמר, מה מצב-הלוח, ומה הצעד-הבא לחידוש (`"תמשיך מ-SESSION_STATE"`).

אם `$ARGUMENTS` מכיל הערה — הוסף אותה לסנאפשוט-ה-SESSION_STATE.
