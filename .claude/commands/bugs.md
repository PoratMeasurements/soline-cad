# עיבוד דיווחי-באגים מהשטח

קרא את כל הדיווחים ב-`G:\My Drive\claude\Soline\bug_reports\` (זוגות `bug_*.png` + `bug_*.json`; ה-PNG = צילום-מסך-מסומן, ה-JSON = מטא+הערות). לכל דיווח:
1. **קרא** את ה-JSON (screen/notes/annotations/appVersion/context) ואת ה-PNG (הצג/נתח את הצילום-המסומן).

- **דרישות-שדה** → הוסף ל-`docs/MEASUREMENT_PROCESS_UPGRADE.md` / roadmap.
