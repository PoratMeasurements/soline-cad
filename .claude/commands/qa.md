# צבא-בקורת האפליקציה — Soline

הרץ סקירה מקיפה של אפליקציית-המדידה (`G:\My Drive\claude\Soline\app-measure`) ע"י **שיגור סוכני-בקורת במקביל**. כל הסוכנים **קריאה-בלבד** (מנתחים ומדווחים, לא עורכים) — כדי שירוצו במקביל בבטחה בלי להתנגש במסלול-האפליקציה המסודרתי. אחרי שכולם יסיימו, אאחד ממצאים, אדרג לפי-חומרה, ואיישם תיקונים **סדרתית** (סוכן-עורך אחד-בכל-פעם).

היקף אופציונלי מ-`$ARGUMENTS` (אם ריק — סקירה מלאה של כל האפליקציה).

שגר את הסוכנים הבאים **במקביל (בהודעה אחת)**, כל אחד `general-purpose`, ברקע, קריאה-בלבד:

1. **UX/UI** — סקור מסכי-Compose + זרימות: עקביות עברית-RTL, היררכיה ויזואלית, נגישות (גדלי-מגע/ניגודיות), עקביות-רכיבים, מלל-ברור, מצבי-ריקנות/טעינה/שגיאה, תחושה-מקצועית. דווח ממצאים מדורגי-חומרה עם קובץ:שורה.

2. **באגים/קריסות** — צוד קריסות ובאגי-יציבות: null-safety, מחזור-חיים (Compose/Activity), coroutines/מצב, שלמות Room DB + מיגרציות (v14), דליפות-משאבים (מצלמה/וידאו/קבצים), EXIF/כיווני-תמונה, גבולות-קלט, מרוצי-מצב, קריאות-FileProvider. דווח תרחיש-כשל קונקרטי לכל ממצא.

3. **QA/פונקציונלי** — אמת את הזרימה מקצה-לקצה: מדידה→ORDX/.sol, אלמנטים/פתחים, צילום-פר-חזית, וידאו, רשימת-משימות + שערי-סגירת-חדר/פרויקט, שלמות-ה-.sol (photos/videos/checklist). היכן חסר כיסוי-בדיקה? היכן הזרימה נשברת? דווח פערים.

4. **זרימת-מודד (שדה)** — שימושיות-בשטח: שלבי-המדידה, ניווט-אחורה/תיקון-עצמי, P2P, חזית+גליות, X6-רצפה/תקרה, נוחות-מודד, מניעת-טעויות. דווח חיכוכי-שדה + באגי-זרימה.

הנחיות לכל סוכן: קריאה-בלבד (אל תערוך קוד); החזר רשימת-ממצאים **מדורגת מהחמור-לקל**, כל ממצא עם קובץ:שורה + תיאור-כשל קונקרטי + תיקון-מוצע; היה מדויק, לא כללי.

אחרי שכל הסוכנים חוזרים: אחד את הממצאים, הצג טבלה מדורגת-חומרה למיכאל, ושאל אילו לתקן (או תקן את הקריטיים סדרתית). עדכן `SESSION_STATE.md` ואת לוח-הטאבלט (`SOLINE_BOARD.html`) עם תוצאות-הסקירה.
