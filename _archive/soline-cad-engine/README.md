# Soline CAD Engine

מנוע יצירת אלמנטים וייצוא CAD — הופך מודל גאומטרי מאומת (מ״מ) ל**DXF 2D + 3D** ול**דו״ח מדידה מפורט** (HTML מוכן-להדפסה ל-PDF), עם מבט-על ומבטי חזית/צד.

**ללא תלויות** — Node טהור. רץ ישירות (גם מ-Google Drive, כי אין `node_modules`).

## הרצה

```bash
node build.js
```

מייצר ל-`out/`:
| קובץ | תיאור |
|---|---|
| `soline-plan-2d.dxf` | מבט-על 2D — מתאר משטחים, פתחים (כיור/כיריים/ברז), ומידות. שכבות: COUNTER · CUTOUT · DIM · TEXT |
| `soline-model-3d.dxf` | מודל 3D — לוחות מחולצים (extruded) כ-3DFACE + מתארי פתחים |
| `soline-report.html` | דו״ח מדידה עצמאי — פתח בדפדפן → Print → Save as PDF |
| `report-artifact.html` | אותו דו״ח, גרסת body-only לתצוגה |

בדיקת תקינות ל-DXF:
```bash
node validate.js
```

## ארכיטקטורה (מקור אמת יחיד → היטלים)

```
src/model.js    → מודל גאומטרי מאומת (מ״מ) + פונקציות עזר
src/dxf.js      → מנוע אלמנטים + כותב DXF (2D ו-3D)   [ADR-004: CAD = היטל]
src/views.js    → מרנדר SVG: מבט-על, חזית, צד
src/report.js   → מרכיב את הדו״ח (A4, RTL, print-ready)
build.js        → מריץ הכל וכותב את out/
```

אותו `model.js` מזין גם את ה-DXF וגם את הדו״ח — שינוי מידה משתקף בשניהם. זה בדיוק העיקרון
מ[מסמך 17](../soline-measurement-engine/docs/17-Geometry-Pipeline-Export-Spec.md): הגאומטריה
המאומתת היא מקור האמת, וה-CAD/הדו״ח הם היטלים דטרמיניסטיים שלה.

## מנוע האלמנטים

`src/dxf.js` חושף factory של פרימיטיבים (`el.polyline / line / circle / text / face`) ובונה מהם
אלמנטים: משטחים, פתחים מלבניים ועגולים, מידות קוויות (עם חצים וטקסט), וחילוץ 3D. הוספת אלמנט
חדש = פונקציה שמחזירה פרימיטיבים — הכותב לא משתנה.

## מגבלות ידועות (v0)

- DXF ברמת R12 (AC1009) — תואם אוניברסלית; מידות מצוירות כקווים+טקסט (לא ישות DIMENSION מלאה).
- טקסט ב-DXF ב-ASCII (קודים באנגלית: SINK/COOKTOP) — עברית שמורה לדו״ח, לא ל-CAD.
- פתחים ב-3D מסומנים כמתאר על פני הלוח (ללא חיתוך בוליאני אמיתי בלוח).
- תמונות בדו״ח הן placeholders — בהרצה אמיתית יוטמעו כ-data-URI מהאתר.

## הבא בתור

- ישויות DIMENSION מקוריות ל-DXF · חיתוך פתחים אמיתי ב-3D (mesh עם חורים) · תמיכה ב-L-shape
  מלא · הטמעת תמונות אמיתיות · ייצוא PDF ישיר (ללא הדפסה ידנית).
