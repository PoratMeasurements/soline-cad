# מדריך מודד — Soline Measure
### חוברת-קליטה + פרוטוקול-בדיקת-שדה למודד חדש

> מסמך זה נכתב עבור מודד שמעולם לא ראה את התוכנה, וגם משמש את הבעלים כמסמך-ייחוס.
> הוא מבוסס על **הקוד האמיתי של האפליקציה** — הכפתורים והמסכים כאן הם מה שתראה בפועל.
> יש חלקים שעדיין "מחוספסים" — הם מסומנים בכנות ⚠️ כדי שתדע היכן לבדוק חזק.

---

## 1. מה זו התוכנה (בקצרה)

**Soline Measure** היא אפליקציית-אנדרואיד למדידת חדרים באתר, שמייצרת קובץ מדידה מסודר (`.sol`) שנשלח לממיר → משם לתוכנה של הנגר/המפעל (ORDX / PDP / DXF).

התמונה הגדולה — מ**מדידה** ל**ייצוא**:

```
פרויקט  →  חדר  →  מתאר-קירות  →  חזית + גבהים  →  אלמנטים ופתחים
   →  מפלסים (רצפה/תקרה)  →  צילום תמונות/וידאו  →  סגירת-חדר  →  סגירת-פרויקט  →  ייצוא .sol
```

מה שהמודד עושה בשטח:
1. **פותח עבודה/פרויקט** ומגדיר חדרים.
2. **מודד את מתאר-החדר** (הקירות) — עם מד-לייזר בבלוטות' (Leica DISTO X6, ואם יש חצובה DST 360-X) או ידנית.
3. לכל קיר — **מוסיף אלמנטים** (שקעים, מים, גז, חלונות, דלתות, מזגנים...) עם **מידות-אמת** ו**גבהים**.
4. **מודד מפלסים** — כמה הרצפה והתקרה לא-ישרות.
5. **מצלם** תמונות וסרטונים (חובה כדי לסגור חדר).
6. **סוגר חדר**, ואז **סוגר פרויקט**, ו**מייצא** את ה-`.sol`.

מד-הלייזר מזרים מדידות ישירות לתוך שדות-המספר: כשאתה נכנס לשדה ולוחץ על המכשיר — המספר נכנס לבד ("**📡 מדוד פעם אחת**").

## 2. סיור-מסכים — מסך-אחר-מסך

### 2.1 מסך-הבית (לוח-בקרה)
המסך הראשון שנפתח. שם התוכנה **soline** למעלה, לצידו **גלולת-סטטוס-הלייזר** (לחיצה = חיבור מכשיר), ובפינה גלגל-**הגדרות**.

| אזור | מה זה |
|---|---|
| מדדי-היום | שלושה מספרים: **פתוחות · נמדדו · לתזמון** (לחיצה → לו"ז) |
| ניהול לו"ז / ניהול מדידות | שני כרטיסים למעבר לצד-הניהול (לו"ז + כל הפרויקטים) |
| לו"ז היום | העבודות המתוזמנות להיום |
| סטטוס-לייזר | מחובר/לא-מחובר + כפתור **חבר / החלף** |
| פעולות מהירות | **פתיחת עבודה (נגר ← לקוח)** · **המשך: <פרויקט אחרון>** · **＋ פרויקט מהיר (ללא פרטי-לקוח)** |
| הפרויקטים האחרונים | רשימת פרויקטים — לחיצה נכנסת לחדרים |

### 2.2 מכשירי מדידה (Bluetooth)
כותרת: **"מכשירי מדידה · Bluetooth · Leica DISTO X6 / Bosch GLM"**.
- כפתור **סרוק** — מחפש מדי-לייזר. **נתק** — מנתק את המחובר.
- למעלה יופיע **"מחובר: <שם>"** כשמצליח.
- אם אין תוצאות: *"הקש 'סרוק' והפעל את מד-הלייזר"* / *"ודא שהמכשיר דלוק ולא מחובר לאפליקציה אחרת (CVSM)"*.
- כברירת-מחדל מוצגים רק מדי-לייזר; יש קישור **"הצג את כל המכשירים"**.

### 2.3 פרויקט → חדרים
כותרת **"חדרים"**. כפתורים ברמת-הפרויקט:
- **⬇ ייצוא לממיר (.sol → ORDX/PDP/DXF)** — בונה ומשתף את קובץ-המדידה.
- **🔒 סגירת פרויקט (גישה + חדרים)**.
- **🗑 מחק פרויקט זה** (הרסני — דורש אישור).
- כרטיס-חדר: **"פתח למדידת קירות"** + אייקון-מחיקה (🗑).
- **＋** (כפתור צף) — חדר חדש (למשל "מטבח").

⚠️ **שער-ייצוא לא-חוסם:** אם יש חדרים/קירות עם מדידה חסרה או מתאר-לא-סגור, יופיע דיאלוג **"נמצאו N ממצאים חוסמים"** עם שתי אפשרויות — **פתח אימות** או **ייצא בכל-זאת**. כלומר אפשר לייצא גם עבודה חסרה. (נקודת-בדיקה חשובה — סעיף 3.)

### 2.4 חדר → מדידת-קירות (מסך המרכזי)
כותרת **"קירות החדר"**. זה המסך העמוס ביותר — עליו כל הכניסות.

**פתיחת מדידה** (כרטיס עליון, מודגש כתום כשריק):
| שדה | מה זה |
|---|---|
| כיוון כניסה | 8 רוחות (צפון/מזרח...) או מעלות מדויקות + שיוך-קיר. הדוח מצייר ממנו חץ-כניסה. **מוזן ידנית** (אין מצפן). |
| מהלך גבהים | רשימת מדידות-תקרה. **הגובה-המחייב = המינימום**. |
| שינויים עתידיים | הערות-מודד לקיר/לחדר (למשל "קיר זה ייהרס"). |

**כניסות המתאר (6 מסלולים מקבילים):**
| כפתור | מתי משתמשים |
|---|---|
| ▭ אשף תבניות חדר (מלבן/L/U/T/Z) | חדר בצורה סטנדרטית — הכי מהיר להתחלה |
| 🖉 שרטוט חי (CAD · קשת) | ציור חופשי כולל קשתות |
| 📐 מדידה חיה (לייזר → קיר) | יורים אורך-קיר בזה-אחר-זה, זווית ידנית |
| ✎ שרטוט חצי-אוטומטי (היקף-החדר) | בניית היקף מודרכת |
| 📐 מדידת P2P (X6 · בניית-זוויות + T) | חצובה + DST — יורים כל פינה מעמדה אחת |
| ✏️ עריכת מידות + 🧊 תלת-מימד | תיקון-מספרים ותצוגה |

**כניסות נוספות:** ✓ אימות לייצוא · 🔒 סגירת חדר · ▦ מדידת רצפה · ▤ מדידת תקרה · ⌂ סגנון ראש קיר · 🔣 סמלי CAD · בדיקת התאמה (בליטה מול עומק).

**רשימת הקירות:** "קיר N · אורך X מ"מ · גובה Y מ"מ" — לחיצה נכנסת לקיר, 🗑 מוחקת (הקירות אחריו ממוספרים מחדש).
**＋** — קיר חדש (אורך + גובה, עם הזרקת-לייזר).

### 2.5 מדידת P2P (חצובה — X6 + DST 360-X)
המודד עומד במקום-אחד ו**יורה כל פינה של החדר**; כל ירייה נופלת לתוכנית.
- **שלב 1 · כיול-עמדה:** *"📍 קבע עמדה כראשית והתחל"*. ⚠️ אזהרה בולטת: **אל תזיז את החצובה עד סוף-הסקר**.
- **שלב 2 · ירי-פינות:** *"🎯 ירה פינה N"* — תוכנית-חיה מציירת תוך-כדי. יש **עריכה במקום (✎)**, **מחיקה (🗑)**, **↶ בטל אחרונה**, **🗑 נקה הכל**, והוספה-ידנית (מרחק + אזימוט).
- **כיווניות-בנייה:** מתג **נגד-כיוון-השעון ↺ / עם-כיוון-השעון ↻** — אם התוכנית יוצאת "מראה-הפוכה", מחליפים.
- **סגירה וגובה:** מתאר-סגור ⭕ / פתוח 〰 + גובה-קירות → **💾 סיום ושמירת N קירות**.
- אזהרות: *"הלייזר מנותק"*, *"DST 360-X לא מזוהה (אין זווית-אופקית)"* — בלי המתאם הפינות ייפלו על קו והכפתור חסום.

### 2.6 חזית + גבהים (מסך-הקיר)
מהרשימה בסעיף 2.4 לוחצים על קיר. כותרת: **"קיר N · L×H מ"מ"**. כפתורים:
- **⬜ מצב-חזית מאוחד (גבהים + מסגרת)** — המסך המרכזי לחזית.
- **📐 מדידת מבט-על · בטן (undulation · X6)** — גליות הקיר במבט-על.
- **🗄️ ארונות (תכנון-הנגר)**.
- **⌂ סגנון ראש קיר · <ישר/משופע/גמלון>**.
- **📷 צלם חזית** — רצועת-תמונות פר-קיר.
- רשימת האלמנטים על הקיר (למטה).

**בתוך "מצב-חזית מאוחד":** שני טאבים —
- **▦ מסגרת:** בונים מתאר-חזית מנקודות: **➕ קלוט נקודה · ↩︎ בטל נקודה · 🗑 מחק נקודה נבחרת · נקה · ✓ סיום מסגרת**. יש בחירת **פינת-אפס** ו**כיוון-סריקה**.
- **אלמנטים/גבהים:** מוסיפים אלמנט בגובה — **➕ הוסף בגובה**, וכפתור **"קלוט גובה מהלייזר"**.

⚠️ **נקודת-בדיקה קריטית:** *"קלוט גובה מהלייזר"* אמור לתת **גובה-מהרצפה**, לא מרחק-גלם. בביקורת-האיכות זה סומן כבאג פתוח (ירי לשקע בגובה 1.1 מ' מרחק 2.8 מ' עלול להישמר כ"גובה 2800"). **בדוק את זה בכל אלמנט.**

### 2.7 סקר-מפלסים (רצפה / תקרה)
כותרת **"מדידת רצפה"** או **"מדידת תקרה"**. מציג **קריאה חיה** (מרחק / זווית).
- קודם **🎯 קבע 0** — נקודת-הייחוס. אחר-כך **➕ מדוד נקודה (N)**.
- כל נקודה מציגה **סטייה ±מ"מ** מ-0, בצבע: **ירוק ≤3 · כתום ≤10 · אדום >10**.
- **בטל אחרונה** (undo נקודתי) · **אפס הכל** · 🗑 מחיקת-נקודה-בודדת.
- ⚠️ ירי ל-0 **ללא זווית-אנכית** נחסם ("לא ניתן לקבוע נקודת-0"); נקודה-רגילה ללא-זווית תסומן כ**"≈ ללא זווית"** (סטייה לא-אמינה).

### 2.8 הצבת אלמנטים + פתחים (מידות-אמת)
מ**＋** במסך-הקיר נפתח **בורר-הקטלוג** (כ-97 סוגים, מקובצים: חשמל · אינסטלציה · מוצרי חשמל · סניטרי · דלתות · חלונות · מיזוג ואיוורור · מבנה ותקרה · מטבח חוץ · הערות · סימון).

**אלמנט רגיל** (שקע/מים/גז/מזגן...) — שתי שיטות-מדידה (מתג):
- **מרכז:** מיקום-מרכז לאורך הקיר + רוחב/קוטר.
- **היסטים מפינות:** היסט-שמאל + היסט-ימין, והרוחב **מחושב אוטומטית**.
- ועוד: **עומק-בליטה D** (ממולא-מראש מהקטלוג — מקרר 650, מזגן 180) · **גובה מהרצפה** · **גובה האלמנט**.

**פתח פרמטרי** (דלת/חלון/מזגן) — טופס עם באנר: *"המידות ממולאות בברירת-מחדל של היצרן — עדכן למידת-האמת שנמדדה בשטח"*:
- מיקום על הקיר (מהפינה השמאלית/הימנית + היסט) · רוחב-פתח · גובה-פתח · גובה-סף (חלון) · עובי-קיר · עובי-משקוף/מסגרת · חשפה · עובי-כנף · מנגנון-פתיחה · צד-ציר · כיוון-פתיחה · מספר-כנפיים · זיגוג.

**שער-הזנה:** כפתור **"שמור"** כבוי עד שהוזנו **רוחב > 0, גובה > 0, ומיקום/היסט תקין (לא-שלילי)**. שדה שגוי מסומן אדום.
בשורת-אלמנט: ✎ עריכה · 📋 שכפול · 🗑 מחיקה.

### 2.9 צילום תמונות + וידאו
- **תמונות:** **"📷 צלם חזית · <סוג>"** — סוגים: **חזית · רחוק · תקריב · רצפה**. ממוזערות + **כיתוב (הערת-מודד)** + **מחק תמונה**.
- **וידאו:** סוגים **גישה · הסבר**. אפשר **לצפות / למחוק סרטון / להחליף** (VideoReviewBar).
- הרשאת-מצלמה מתבקשת בפעם הראשונה. אם נמנעה — דיאלוג **"נדרשת הרשאת-מצלמה"** עם **"פתח הגדרות"**.

### 2.10 רשימת-משימות + סגירת-חדר / פרויקט
**סגירת חדר** — שער-קשיח-עם-מוצא. פס-התקדמות **משימות-חובה**, ולכל קטגוריה שורה עם **📷 צלם · 🎥 סרטון · דלג**:
- קטגוריות-חובה (חזית לכל-קיר, פרטים...) חייבות להתבצע, **אבל** אפשר **"דלג עם סיבה"** (טקסט-חובה) כדי לא-להיתקע.
- **🔒 סגור חדר** — פעיל רק כשכל-החובה בוצע. אפשר **"פתח חדר מחדש"**.

**סגירת פרויקט:** גישה (לפני/אחרי) + סרטון-הסבר + **כל-החדרים-הושלמו** → **🔒 סגור פרויקט** → אחר-כך **⬇ ייצא .sol לממיר**. רשימת-החדרים-שנותרו מקושרת ישירות לסגירת-כל-חדר.

### 2.11 הגדרות + הרשאות
**הגדרות** (גלגל בפינת מסך-הבית) — נשמר אוטומטית:
- **פרטי מודד:** שם המודד.
- **מדידה:** יחידות-תצוגה · גובה-קיר ברירת-מחדל (מ"מ) · נעילת-זווית 90° · סאונד בקליטת-נקודה.
- **מכשיר:** התחברות-מחדש-אוטומטית ללייזר · השאר-מסך-דולק.
- **עבודה:** סוג-עבודה ברירת-מחדל.
- **שיתוף-מיקום:** מתג (דורש הסכמה) · **הפעילות שלי** · **בטל הסכמה (ומחק נתונים)**.
- **גיבוי ושחזור:** **גבה הכל ל-Drive (שיתוף)** — מאגד הכל לקובץ-אחד לשמירה ידנית ב-Drive.

**הרשאות / מסך-הסכמה-למיקום:** שיתוף-מיקום הוא **בהסכמה בלבד** — מסביר מה נאסף / למה / מי רואה / לכמה זמן / איך מכבים. **"אני מאשר"** (ואז בקשת-הרשאה) או **"לא עכשיו"**. ניתן-לביטול תמיד, וביטול מוחק את נקודות-המסלול.

## 3. פרוטוקול-בדיקה שלב-אחר-שלב

מדוד חדר **אמיתי** מקצה-לקצה, והפעל **כל** פונקציה — בסדר שמפוצץ באגים. לכל שלב: **מה לעשות · מה לצפות · מה לבדוק**.
עמודת "מה לבדוק" מכוונת אותך במכוון לקצוות שנמצאו חלשים בביקורת-האיכות.

### מקרא חומרה לדיווח
🔴 **חוסם** (אי-אפשר להמשיך / אובדן-נתונים) · 🟠 **גבוה** (מספר שגוי לנגר) · 🟡 **בינוני** (מציק אך יש מעקף) · ⚪ **נמוך** (טקסט/עיצוב).

---

### שלב 0 — חיבור והכנה
| מה לעשות | מה לצפות | מה לבדוק |
|---|---|---|
| מסך-הבית → סטטוס-לייזר → **חבר** → **סרוק** | "מחובר: X6" ירוק | נתק את הלייזר באמצע-סריקה — האם התגובה נקייה? |
| הגדרות → מלא שם-מודד, גובה-קיר ברירת-מחדל | נשמר מיד | הזן גובה **ריק / 0 / אותיות** — לא אמור לקרוס |

### שלב 1 — פרויקט וחדר
| מה לעשות | מה לצפות | מה לבדוק |
|---|---|---|
| **＋ פרויקט מהיר** → צור | נכנס לרשימת-חדרים | צור פרויקט בשם **ריק** — חסום? |
| **＋** חדר "מטבח" | חדר נוסף | הוסף שני חדרים **בשם זהה** — מה קורה? |
| מחק חדר (🗑) → אשר | נמחק | לחץ מחיקה ואז **ביטול** — נשאר? |

### 3.1 שלושה תרחישי-חדר (הרץ את הפרוטוקול על כל אחד)
1. **מלבני פשוט** — 4 קירות, דלת אחת, 2 שקעים. ריצה חלקה מקצה-לקצה (בסיס-השוואה).
2. **חדר-L** — 6 קירות בזווית. בדוק במיוחד: אשף-תבנית L, עריכת/מחיקת קיר-אמצעי, P2P עם פינה-פנימית שקשה-לירות בה.
3. **חדר עמוס** — הרבה פתחים/אלמנטים: כניסה + חלון + 2 מזגנים + מקרר + 6 שקעים + מים + גז. בדוק: עומק-D ממולא, דגל "נמדד", שכפול-אביזר, וזמני-הייצוא עם מדיה כבדה.

## 4. איך מדווחים באג

### 4.1 כפתור-הבאג 🐞
המנגנון המתוכנן לדיווח מהיר מהשטח: **כפתור-באג 🐞 בכל מסך** →
1. **צילום-מסך** אוטומטי של המסך הנוכחי.
2. **סימון:** חצים + תיבות-טקסט + הערות על התמונה (להצביע בדיוק על הבעיה).
3. **שיתוף לבעלים** (WhatsApp / מייל) בלחיצה.

> ⚠️ **הערת-כנות:** נכון לגרסה הנוכחית, כפתור-הבאג **טרם קיים בקוד** בכל המסכים. עד שייכנס — השתמש במעקף שנותן בדיוק אותו תוצר:
> 1. צלם מסך בטלפון (בד"כ **Power + Volume-Down**).
> 2. פתח את התמונה בגלריה → **עריכה/סימון** → הוסף חץ + טקסט על הבעיה.
> 3. שתף לבעלים בוואטסאפ עם התבנית שבסעיף 4.3.

### 4.2 סולם-חומרה
| דרגה | פירוש | דוגמה |
|---|---|---|
| 🔴 חוסם | אי-אפשר להמשיך / נתונים אובדים | תמונות נדרסות · קריסה בייצוא |
| 🟠 גבוה | מספר שגוי מגיע לנגר | "קלוט גובה" נותן מרחק-גלם |
| 🟡 בינוני | מציק, אבל יש מעקף | אי-אפשר לערוך קיר אמצעי |
| ⚪ נמוך | טקסט / עיצוב / נוחות | כפתור נחתך בטלפון צר |

### 4.3 באג מול דרישת-שדה — הבחנה חשובה
- **באג** = משהו **שבור** — עובד לא-נכון, קורס, או נותן מספר-שגוי. → *"מה עשיתי · מה ציפיתי · מה קרה"*.
- **דרישת-שדה** = משהו **חסר** שאתה צריך בשטח — התוכנה תקינה, אבל אין פונקציה/שדה שהיית צריך. → *"מה חסר לי · מתי · למה זה יחסוך זמן/טעות"*.

**תבנית-דיווח (העתק לוואטסאפ):**
```
[חומרה: 🔴/🟠/🟡/⚪]  [סוג: באג / דרישת-שדה]
מסך: (למשל: חזית-קיר → קלוט גובה)
מה עשיתי:
מה ציפיתי:
מה קרה בפועל:
תרחיש-חדר: (מלבני / L / עמוס)
מצורף: צילום-מסך מסומן
```

## 5. סדר-תפעולי יומי

### 5.1 מה לבדוק קודם (סדר-עדיפויות)
בדוק תחילה את שלוש הנקודות שהביקורת סימנה כחלשות-ביותר — הן מפילות איכות בשקט:
1. 🔴 **התנגשות-שמות-תמונות** (שלב 8) — צלם ריבוי-חדרים ובדוק שכלום לא-נדרס.
2. 🟠 **"קלוט גובה מהלייזר"** (שלב 5) — ודא גובה-מהרצפה, לא מרחק-גלם.
3. 🟠 **דגל "נמדד" מול ברירת-מחדל** (שלב 6) — ודא שהנגר יבחין מדידה-אמיתית מניחוש-קטלוג.

### 5.2 קצב (Cadence)
- **כל חדר** — הרץ את הפרוטוקול המלא (שלבים 1–9) פעם-אחת.
- **פעם ביום** — סבב-מדיה מלא (שלב 8) + ייצוא (שלב 9) על פרויקט רב-חדרי.
- **דווח מיד** על 🔴 חוסם; אגד 🟡/⚪ לסיכום-סוף-יום.

### 5.3 איך הבעלים מקבל וממיין
- הדיווחים מגיעים לוואטסאפ/מייל של הבעלים עם צילום-מסך מסומן.
- מיון: **🔴 קודם** (תיקון מיידי) → 🟠 (השבוע) → 🟡/⚪ (מצטבר).
- הפרד **באג** (תיקון) מ**דרישת-שדה** (החלטת-מוצר) — ראה סעיף 4.3.

### 5.4 צ'ק-ליסט יום-1
- [ ] חיבור מד-לייזר בבלוטות' (סעיף 2.2).
- [ ] מילוי הגדרות: שם-מודד + גובה-קיר ברירת-מחדל.
- [ ] מדידת **חדר מלבני פשוט** מקצה-לקצה (תרחיש 1) — פרויקט → קירות → אלמנט אחד → חזית → צילום → סגירת-חדר → ייצוא.
- [ ] תרגול **מד-לייזר → שדה** (הזרקת "📡 מדוד פעם אחת").
- [ ] שליחת **דיווח-באג ניסיוני** בתבנית (סעיף 4.3) כדי לוודא שהזרימה עובדת.
