# מנוע-המדידה — אפיון-עומק (Measurement Engine Specification)

> נכתב ע"י Claude כמודד-מוסמך + מוביל-מוצר. משלים את `UNIFIED_MEASURE_ARCHITECTURE.md`.
> הדף-החי המקביל (לאישור מנהל-המוצר בפורת): ארטיפקט `MEASURE_ENGINE_SPEC.html`.

## 3 שיטות-הקלט של המנוע
1. **לייזר-ידני** — מרחק ישיר נק'-לנק' (handheld).
2. **P2P (חצובה)** — תלת-ממד: זווית+מרחק+גובה → חישוב-מרחבי.
3. **מטר-ידני** — הזנה-ידנית בהעדר-נגישות-ללייזר.

## חלק 1 · אפיון-המנוע

### צינור-עיבוד אחיד
```
מקור → קריאה-גולמית → נרמול → ולידציה → פרשנות-גיאומטרית → אלמנט → מתאר
```
**עיקרון:** הלייזר נותן **גודל**; האפליקציה נותנת **טופולוגיה** (איזה קיר/פינה/פתח). כל אלמנט נושא **פרובננס**: `source, raw, timestamp, confidence` — מניע ולידציה, צבע-בדו"ח, ומדידה-חוזרת.

### זרימת-נתונים לפי שיטה
| שיטה | גולמי | נרמול | פרשנות→אלמנט |
|---|---|---|---|
| לייזר-ידני | `d` מ"מ (DIST/BLE) | מ"מ אחסון · ס"מ תצוגה | אורך הקיר/קטע פעיל, או מרחק נק'-נק' |
| P2P | קוטבי `d,v,h` | `r=d·cos v`, `Δh=d·sin v`, `x=r·cos h, y=r·sin h` | פינה/נקודה במרחב → קודקודי-מצולע→קירות+גבהים |
| מטר-ידני | מספר מוקלד+יחידה | `parseToMm` | כמו לייזר-ידני, מתויג `source=tape` (אמון-נמוך) |

**כוח P2P:** עמדה-אחת מפולסת יורה כל-הפינות → מתאר-מלא+גבהים בלי-לזוז. תנאי: פילוס + backsight.

### כיול / שגיאות / ולידציה
**שערי-כיול:** לייזר-ידני=בדיקת-חיבור+טריות. **P2P=טקס-חובה:** (1) פילוס → שער-אישור-ידני (BLE לא-קורא אמין); (2) backsight/אפס-אזימוט; (3) גובה-מכשיר. מטר=אישור-יחידה.

**ולידציה בזמן-אמת:**
- טווח-סבירות (0.05–80מ'); דחיית 0/אבסורד; גבולות-חדר.
- **שגיאת-זווית P2P:** שפיוֹת-אנכי (`v≈0` לירי-מפלסי) · זנית↔אופק + self-check (2-נק' אותו-גובה→Δh≈0) · חצייה-עצמית של המצולע · שגיאת-סגירה >2ס"מ/0.5% → Bowditch.
- **חריגה >2ס"מ** keep/delete (קיים) — מוכלל לכל-מקור.
- debounce הד-BLE · שער-טריות ("קריאה-ישנה?").

**מצבי-חיבור:** מנותק→סורק→מתחבר→מוכן→מודד→תקוע→מתחבר-מחדש; **מטר-ידני תמיד-זמין**. BLE ראשי (X6/D2/בוש), Serial/USB עתידי. **ניתוק לא-מאבד-מתאר** (DB-backed). offline משפיע רק על סנכרון/דו"ח.

## חלק 2 · ארכיטקטורת מסך-המדידה
פריסה portrait-first: **סטטוס-עליון** (צ'יפ-חיבור+סוללה · מונה · מצב) · **קנבס-מתאר משותף חי** (pan/zoom) · **פאנל-שיטה מתחלף** · **פעולת-לכידה ענקית** (טריגר-מכשיר+מסך).
- לייזר: readout-ענק + "איזה קיר" + ירה→הבא + re-arm.
- P2P: checklist-הקמה (פילוס/backsight) + readout-קוטבי + תצוגת-מצולע + סגור-מתאר.
- מטר: מקלדת+יחידה + slot-יעד.
**מעבר-שיטה מחליף רק פאנל-תחתון — הקנבס נשאר.**
**קיצורי-שטח:** readout-ענק קריא-בשמש · טריגר-מכשיר (יד-אחת) · auto-advance · undo-ענק · ביפ+haptic+צליל-שגיאה · מצב-שדה high-contrast · glove-mode · נעילת-קנבס.

## חלק 3 · מטריצת-פיצ'רים
**Core:** BLE connect/reconnect+צ'יפ · 3-שיטות · readout+לכידה · מתאר DB-backed (החלפה לא-מוחקת) · slots+auto-advance · חריגה keep/delete+פרובננס · undo/redo/עריכה · יחידות ס"מ · קנבס · offline · ‎.sol.
**Advanced:** P2P (קוטבי→קרטזי · עמדה-אחת · Δh · פילוס+backsight · Bowditch · רב-עמדתי) · גיאומטריה (שטח shoelace · היקף · נפח · אלכסון→זווית✓ · פיתגורס · ריבועיות · זווית-קירות) · פתחים (דלת/חלון/גומחה/עמוד) · snap 90°/קודקוד/קולינארי · min/max · ייצוא-קואורדינטות/DXF.
**Field UX:** טריגר-מכשיר · ביפ+שגיאה · הקראה-קולית · auto-advance · undo-ענק · readout-ענק · מצב-שמש · glove · haptic · יד-אחת · המשך-סשן · re-shoot · צילום פר-אלמנט.
