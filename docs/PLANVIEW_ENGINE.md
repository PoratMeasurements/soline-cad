# מנוע מבט-על מאוחד — מסך-מדידה אחד (מפרט)

> מפרט-הבעלים (2026-08-26, מהשטח). מאחד את כל מסלולי-מתאר-החדר ל**מנוע-אחד**: מסך-מדידה-אחד עם **סרגל-צד** לבחירת שיטת-שימוש-בלייזר והזרקת-נתונים. מחליף את 6 הכפתורים-המקבילים הנוכחיים.

## העיקרון (דברי-הבעלים)
- "מדידה-חיה" ו"שרטוט-חי" = **אותו-דבר** → מנוע-אחד.
- "המודד צריך **מסך-מדידה אחד** עם **סרגל בצד** לבחירת אופן-שימוש-בלייזר והזרקת-נתונים."
- גם **מתאר-אוטומטי** = פונקציה בתוך המנוע (לא מסלול-נפרד).

## הארכיטקטורה: מסך-אחד + סרגל-צד
**קנבס-מבט-על משותף** (מודל-אחד של קירות/פינות) + **סרגל-צד (פלטת-כלים)** שמחליף את **שיטת-הקלט הפעילה**. כל השיטות עובדות על אותו-מתאר, בלי-מעבר-בין-מסכים.

### כלי-הסרגל (שיטות-הקלט)
| כלי | מה עושה |
|---|---|
| ▭ **מתאר-אוטומטי** | תבניות מלבן/L/U/T/Z — התחלה-מהירה, ואז מזריקים מידות |
| ✏️ **צייר-באצבע** | מציירים את הקירות באצבע (סקיצה גסה של הצורה, כולל קשתות) |
| 📡 **הזרקת-מידה** | לכל קיר שצויר — מזריקים אורך מהלייזר (D2 / בוש / X6 / P2P) |
| 📐 **מדידה-חיה** | (מאוחד עם צייר-באצבע) — יורים אורך-קיר בזה-אחר-זה |
| 🎯 **P2P** | ירי-פינות מעמדה-אחת (X6 + DST) — נופל לאותו-מתאר |
| ∠ **אלכסון→זווית** | מודדים אלכסון בין קצוות שני-קירות → מחשבים זווית-פינה (קוסינוסים) |
| 🖉 **CAD/קשת** | ציור-חופשי + קשתות |

### מדידת-אלכסון → זווית (הליבה ל-D2/בוש בלי חיישן-זווית)
לפינה בין קירות `a` ו-`b` שנפגשים: מודדים את **האלכסון `c`** בין הקצוות-הרחוקים →
> **`זווית = acos((a² + b² − c²) / (2·a·b))`** (משפט-הקוסינוסים)

ככה מקבלים **זוויות-מדויקות עם מד-מרחק בלבד** — בלי DST/מצפן. שובר את מגבלת ה-D2/בוש. (טווח-תקף: משולש חוקי — `|a−b| < c < a+b`; אחרת אזהרה.)

## מודל-נתונים משותף
- מתאר = רשימת-קירות (אורך + זווית-לקיר-הבא) + פינות. כל הכלים כותבים לאותו-מודל (תואם `WallEntity`/`WallBuilder`).
- הזרקת-לייזר: מנגנון ה-re-arm הרציף (הקש 📡, ירה שוב-ושוב, מעדכן) — לכל שדה/קיר.
- תמיכת-מכשירים: D2 · Bosch GLM · Leica X6 · DST-360 (P2P).

## מה זה מחליף (הנוכחי)
6 הכפתורים-המקבילים ב"קירות החדר": אשף-תבניות · שרטוט-חי-CAD · מדידה-חיה · שרטוט-חצי-אוטומטי · P2P · עריכת-מידות → **מתאחדים** למסך-אחד + סרגל-צד. (עריכת-מידות/3D נשארים כפעולות על-המתאר.)

## עקרונות-מימוש
- מסך-אחד, state-משותף, סרגל-צד מחליף כלי-פעיל. גדלי-מגע ≥48dp (שדה/כפפות).
- אדיטיבי-ככל-האפשר: לשמר את הלוגיקה-הקיימת (StationSolver/WallBuilder/edit-in-place/CW-CCW/dedupe) מאחורי הכלים.
- עברית לשון-זכר, RTL.
- **מפרט-של-record** — כשבונים, לבנות מכאן. לעדכן כאן אם משתנה.

## סטטוס
בתור-אפליקציה (מצטבר ל-APK-של-סוף-סשן), אחרי: תיקון-P2P (רץ) · חוגת-כניסה. **פיצ'ר-ליבה** — לבנות כמנוע-אחד מהמפרט הזה.
