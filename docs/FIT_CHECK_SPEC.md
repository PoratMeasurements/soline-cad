# בדיקת-התאמה — אפיון (Fit-Check Spec · בדיקת-התאמה)

> נכתב בכובע כפול: **מודד-מוסמך** (מה נמדד באתר) + **נגר/מייצר-ארונות** (מה חייב להיות נכון כדי לבנות בלי-הפתעות).
> **מטרה-על:** לגשר על הפער בין *כוונת-המודד* (מה תיעד) ל*צורך-הנגר* (מה חייב להסיק). הרוב שנמדד "נכון" עדיין נכשל בייצור כי איש-לא תרגם קיר-קמור/רצפה-משופעת/פינה-לא-ישרה למשמעות-בנייה.
> **לא כפתור במסך-החדר.** בדיקה אוטומטית ארוגה בשתי-נקודות: (1) **שער טרום-ייצוא** — מוסיפה שכבת-נגרות מעל צ'קליסט-האימות ב-`VERIFY_CHECKLIST_SPEC.md`; (2) **דו"ח-המדידה הסופי** — פרק "בַּנִיוּת" (Buildability) שהנגר מקבל.
> **בונה על ולא-משכפל:** האימות (VERIFY) שואל *"האם נמדד?"*. בדיקת-ההתאמה (FIT) שואלת *"האם מה-שנמדד ניתן-לבנייה, ובאיזו הכנה?"*. VERIFY = שלמות-קלט. FIT = תרגום-לתוצר.

## מקרא
- **חוסם (BLOCK)** — הייצוא נעול עד תיקון/מדידה-חוזרת, או דריסת-מודד עם `overrideReason` מתועד ב-.sol.
- **מזהיר (WARN)** — מותר לייצא; מסומן צהוב בדו"ח + נרשם ל-.sol; מפעיל **המלצת-הכנה** (סקרייב/פילר/פילוס).
- **טולרנס-נגר** — הסטייה שנגר מוכן לספוג *עם* פתרון-הכנה (סקרייב/פילר/מישוש). מעבר לה = ארון-לא-נכנס או מרווח-מכוער.
- **מקורות-נתונים במודל:** מתאר-קירות `length/height/angle` · פתחים `W/H/sill` · ארונות `fromLeft/width/depth/heightFrom/heightTo` · נקודות-מסגרת-קיר X6 (`bulge` קמירה / `dip` שקע בחזית) · נקודות-מפלס רצפה/תקרה (שיפוע) · "בטן"-מתאר (`belly` — קמירת-קיר בתנוחת-תוכנית).

## חלק 1 · הפער: כוונת-המודד מול צורך-הנגר (The Gap)

המודד מתעד **גיאומטריה של המציאות**. הנגר צריך **מעטפת-בנייה**: הערך-הקובע-היחיד שלפיו הוא חותך, והמרווח שהוא חייב להשאיר לסקרייב. הפער נולד כשערך-בודד (אורך-קיר, גובה-בודד, "פינה=90°") מוצג כאילו הקיר/הרצפה/הפינה אידיאליים — והם לא.

| # | מה המודד מתעד (כוונה) | מה הנגר חייב להסיק (צורך) | היכן זה מתפוצץ בייצור |
|---|---|---|---|
| GAP-1 | אורך-קיר יחיד (`length`) | **מינ' ורוחב-נטו** לאורך כל-המהלך — הצר-ביותר קובע | קיר קמור 8מ"מ פנימה, מהלך-ארונות תוכנן שטוח → החלק האחרון לא-נכנס, או מרווח פעור בקצה |
| GAP-2 | גובה-קיר יחיד/כמה-גבהים (`height`) | **הגובה המינימלי** לאורך-מהלך יחידות-גבוהות; צניחת-תקרה מנוכה | תקרה צונחת 15מ"מ לאורך שורת-Tall → היחידה האחרונה נתקעת בתקרה |
| GAP-3 | זווית-פינה (`angle`) / הנחת 90° | **סטיית-הריבועיות** בפינה שבה נפגשים שני-מהלכים | פינה 87° מול משטח-אבן חתוך-לזווית-ישרה → מִשַּׁק פתוח 5מ"מ ומעלה, או משטח שלא-יושב |
| GAP-4 | נקודות-מסגרת X6 (`bulge/dip` בחזית) | **סטיית-חזית-הקיר מהמישור** — כמה סקרייב לתת בגב-היחידה | קיר עם בטן בחזית → גב-ארון פוגש רק בקצוות, היחידה "מתנדנדת" / מרווח-קיר לא-אחיד |
| GAP-5 | "בטן"-תוכנית (`belly`, קמירה בתנוחת-על) | **מעטפת-הריצה בפועל** — קו-הקיר האמיתי מול הקו-הישר שהתוכנית מניחה | מהלך-תחתונים ישר מול קיר-קמור → משטח בולט/שוקע ביחס לקיר; פילר-קצה לא-מספיק |
| GAP-6 | נקודות-מפלס-רצפה (שיפוע) | **הפרש-מפלס לאורך-המהלך** → גובה-רגליות/סוקל להתאמה + מפלס-משטח | רצפה יורדת 12מ"מ → תחתונים "מתגלשים", קו-משטח לא-אופקי, מגירות משתפשפות |
| GAP-7 | נקודות-מפלס-תקרה (שיפוע/צניחה) | **המרווח-האנכי הקטן-ביותר** ליחידות-עד-תקרה + קרניז | קורה/צניחה → קרניז לא-רציף, יחידה עליונה לא-מגיעה לתקרה בקצה-אחד |
| GAP-8 | גובה-סף פתח (`sill`) | **התנגשות עם בנק-מגירות/ציר-משטח** מתחת/ליד החלון | סף-חלון 900 מול בנק-מגירות שתוכנן ל-920 → המגירה העליונה לא-נפתחת |
| GAP-9 | רוחב-נישת-מכשיר (W/H/D) | **סבולת-הרכבה** — הנישה חייבת רוחב-נטו + מרווח-אוורור | נישת-תנור נמדדה בול → אין 2מ"מ הרכבה, המכשיר לא-נכנס |
| GAP-10 | פתח נמדד כרוחב-בלבד | **עומק-מלבן-הפתח / עובי-קיר** לתכנון-החזרות וקופינג | דלת/מעבר בלי עומק-קיר → החזרת-ארון בפינת-פתח לא-מתוכננת |
| GAP-11 | מהלך-פינתי (שני-קירות) | **חופש-הפינה (corner clearance)** — פתיחת-דלת/מגירה בלי התנגשות | שתי יחידות-פינה תוכננו למגע → ידיות/מגירות מתנגשות |
| GAP-12 | עומק-חדר / קיר-מול-קיר | **העומק-הפנוי המינימלי** במעבר (איי / חדר-צר) | אי תוכנן ל-900 מעבר, קיר קמור מוריד ל-870 → תקן-מעבר נשבר |

**עקרון-העל של הגישור:** לכל אלמנט-בנייה, הנגר בונה לפי **המקרה-הגרוע לאורך-המהלך**, לא לפי הערך-המדגמי. תפקיד בדיקת-ההתאמה הוא לחלץ אוטומטית את המינ/מקס/סטייה מתוך נתוני-המודד (X6, מפלסים, belly, angle) ולהמיר אותם ל**ערך-קובע + המלצת-הכנה**, כך שהמודד רואה זאת בזמן-אמת (עוד באתר) והנגר רואה זאת כמוכן-לבנייה בדו"ח.

## חלק 4 · טולרנסים מספריים ומה-לעשות-בכשל (Tolerances & Failure Actions)

ערכי-ברירת-מחדל שנגר מקבל; ניתנים-לכיול בהגדרות-מפעל. שתי-פעולות-כשל: **מדוד-שוב** (חוסם, שווה-נסיעה) או **רשום-והמשך עם קיצבת-סקרייב** (מזהיר, נפתר-בייצור).

| פרמטר | OK (שטוח) | WARN (רשום+הכנה) | BLOCK (מדוד-שוב) | פעולת-כשל |
|---|---|---|---|---|
| פער רוחב-קיר (מינ↔מקס) | ≤5מ"מ | 5–15מ"מ → מינ' קובע | >15מ"מ | >15: מדוד-שוב (חשד bad-shot). 5–15: המשך, פילר-קצה |
| קמירת/שקע-חזית | ≤3מ"מ | 3–12מ"מ | >12מ"מ | ≤12: המשך, סקרייב-גב. >12: מדוד-שוב/סמן-נקודה |
| בטן-תוכנית | ≤3מ"מ | 3–מוזן-ל-F1 | (דרך-F1) | המשך; משפיע על רוחב-מינ' |
| צניחת-תקרה (Tall/עד-תקרה) | ≤8מ"מ | 8–20מ"מ | >20מ"מ | ≤20: קרניז/חיתוך. >20: מדוד-שוב, בדוק-קורה |
| שיפוע-רצפה (תחתונים) | ≤3מ"מ | 3–15מ"מ | >15מ"מ | ≤15: רגלית-מתכווננת. >15: מדוד-שוב (חורג-סוקל) |
| ריבועיות-פינה | ≤0.5° | 0.5–1.5° | >1.5° | ≤1.5°: סקרייב-משטח. >1.5°: מדוד-אלכסון-שוב |
| מרווח-הרכבת-נישה | ≥מכשיר+10מ"מ | +2 עד +10מ"מ | <מכשיר+2מ"מ | <+2: מדוד-שוב חובה (מכשיר-לא-נכנס) |
| Σ-יחידות מול נטו | Σ<נטו−15 | נטו−40..נטו | Σ>נטו | Σ>נטו: תכנן-מחדש (לא-נכנס) |
| מעבר (עומק-פנוי) | ≥900מ"מ | 800–900מ"מ | <מינ'-תקן | <תקן: הקטן-עומק/מדוד-שוב |
| מרווח-חופש-פינה | נמדד ומעל-מינ' | מתחת-מינ'-יצרן | חסר-מדידה במהלך-פינתי | חסר: מדוד-clearance חובה |

**כלל-אצבע-הנגר:** סטייה שנפתרת ב**סקרייב ≤10מ"מ / פילר ≤40מ"מ / רגלית-מתכווננת ≤30מ"מ** = רשום-והמשך. סטייה מעבר-לכך, או **מכשיר-לא-נכנס / מהלך-לא-נכנס / מעבר-מתחת-תקן** = חוסם, שווה-נסיעה-חוזרת.
