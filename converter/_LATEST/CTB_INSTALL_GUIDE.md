# SOLINE.ctb — Install & Use Guide

For the carpenter, the print-shop, or the architect who opens Soline's DXF in AutoCAD.
Two-minute, one-time setup.

---

## What this file is (30 seconds)

`SOLINE.ctb` is a **plot style table** — a small file that tells AutoCAD:
"when you print, turn each drawing **color** into a specific **pen thickness**."
Walls print thick, dimensions print thin, text in between — the professional
line-weight hierarchy, automatically. On screen everything stays colored; only the
**print** gets the pen weights.

You get two files:

- **`SOLINE.ctb`** — everything prints **black**, with correct thicknesses. *Use this for working / shop drawings.*
- **`SOLINE-Color.ctb`** — keeps the colors, same thicknesses. *Use this for a color presentation to the client.*

> Note: Soline's DXF already carries the thicknesses inside the file, so it looks
> right even with no CTB. The CTB is here for the classic "plot-by-pen" workflow your
> print-shop expects, and to force clean all-black output.

---

## Step 1 — Put the file where AutoCAD looks for it

AutoCAD only sees CTBs in its **Plot Styles** folder. Fastest way to open that folder:

1. In AutoCAD type **`STYLESMANAGER`** and press Enter. A Windows folder opens — that is the Plot Styles folder.
2. **Copy `SOLINE.ctb` (and `SOLINE-Color.ctb`) into that folder.** Done.

The folder is usually:

```
C:\Users\<you>\AppData\Roaming\Autodesk\<AutoCAD version>\<lang>\Plotters\Plot Styles\
```

(In AutoCAD you can also check/change it under **Options → Files → Printer Support File Path → Plot Style Table Search Path**.)

If AutoCAD is open, restart it (or re-open the Plot dialog) so the new file shows up.

---

## Step 2 — Select it when plotting

1. Open the drawing, press **Ctrl+P** (Plot) — or **Print/Plot** from the menu.
2. Top-right of the Plot dialog: **Plot style table (pen assignments)**.
3. Pick **`SOLINE`** from the dropdown (choose **`SOLINE-Color`** for a color print).
4. If asked *"Assign this plot style table to all layouts?"* — **Yes** is fine.
5. Plot / preview. Walls are now heavy, dimensions thin, text medium — all black.

**Tip — set it as the default** so you never re-pick it: type **`OPTIONS` → Plot and Publish
tab → Plot Style Table Settings → Default plot style table → `SOLINE.ctb`**.

---

## Step 3 (optional) — Make it the default for new drawings

If you start drawings from a template (`.dwt`): open the template, set the plot style
to `SOLINE` in Page Setup (`PAGESETUP`), save the template. Every new drawing inherits it.

## The pen table (what prints how)

| Color in drawing | Prints as | What it is |
|------------------|:---------:|------------|
| White/black (255) | **0.70 mm** | Section-cut lines / sheet border |
| White/black (7) | **0.50 mm** | Walls (cut) |
| Grey (9) | 0.35 mm | Structure / columns |
| Blue (5) | 0.25 mm | Doors & windows |
| Magenta / cyan / yellow / blue-grey / orange / tan | 0.25 mm | Electrical / plumbing / gas / HVAC / lighting / furniture |
| Turquoise (150), grey (250) | 0.18 mm | Text, title-block rules |
| Red (1), green (3), grey (251) | 0.13 mm | Dimensions, tiling |
| Dark-grey (8) | 0.13 mm @ **50% grey** | Wall poché / hatch fill (prints as tone, not solid black) |
| Grey ramp (252 / 253 / 254) | 0.13 mm @ **50 / 40 / 25% grey** | Screened reference / background / XREF underlay |
| **any other color** | **0.25 mm** | Default medium pen — the table covers **all 255 colors** |

This is a **full 1–255 pen table** (professional office standard): no color prints at a
random weight, and poché prints as grey tone. Full detail: `docs/SOLINE_CTB_SPEC.md` ·
market verdict: `docs/CTB_MARKET_ASSESSMENT.md` · machine-readable: `templates/ctb/SOLINE_ctb_table.csv`.

## Troubleshooting

- **`SOLINE` not in the dropdown** → the file isn't in the Plot Styles folder (redo Step 1), or AutoCAD needs a restart.
- **Everything prints the same thin weight** → make sure the Plot style table is set to `SOLINE` (not "None"), and that **"Plot with plot styles"** is enabled in the Plot dialog.
- **Lines print grey instead of solid black** → you're on `SOLINE-Color`, or dithering is on in your printer driver; use `SOLINE.ctb` (dithering is already off in it).
- **Wall fill / poché prints grey (not solid black)** → that's intentional and correct: poché (colors 8, 252–254) is screened to a grey tone so it reads as shading and never competes with the wall outline. This is the professional convention, in both `SOLINE.ctb` and `SOLINE-Color.ctb`.
- **Colors won't go black** → confirm you picked `SOLINE.ctb`, not `SOLINE-Color.ctb`.
- **Using a DWG/older seat** → the CTB works in all AutoCAD versions from 2000 up, and in BricsCAD/ZWCAD/GstarCAD the same way (their Plot dialogs have the identical "Plot style table" dropdown).
