# Inbox — נקודת כניסה לנתונים מהצוות

שים כאן כל דבר שאתה רוצה שייכנס לפרויקט. הקלוד הראשי סורק את התיקייה בכל סשן, מטמיע את הרלוונטי, ומעדכן את `../STATUS.md`.

## מה לשים כאן
- **קבצים גולמיים** — PDF, תכניות, מפרטים, דוגמאות ORDX/PDP, טבלאות. שם ברור (למשל `spec-מטבח-חשמל.pdf`).
- **ידע והערות** — `notes-<שם>.md` (למשל `notes-ceo.md`): דרישות, החלטות, קונבנציות מהשטח.
- **פידבק על הספרייה** — `library-feedback.md`: אלמנטים חסרים, מידות/גבהים לתיקון, סמלים.

## מה קורה עם מה ששמת
1. הקלוד קורא, מסכם ומטמיע (ספרייה/קוד/דרישות).
2. מה שהוטמע יסומן כאן בקובץ `PROCESSED.md` (עם תאריך ומה נעשה), כדי שלא נעבד פעמיים.
3. עדכון מופיע ב-`STATUS.md`.

> טיפ ל-CEO: אם יש לך רק ידע בראש (בלי קובץ) — פשוט תכתוב אותו ל-`notes-ceo.md` בשפה חופשית. הקלוד יתרגם אותו לשפת האלמנטים של Soline.
