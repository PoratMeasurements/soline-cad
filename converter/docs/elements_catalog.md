# קטלוג אלמנטים — תשתיות וחשמל (מטבח ובית מגורים)

> קטלוג ייצור עצמאי עבור ממיר ORDX→PDP (Soline). לא מבוסס על ספריית InnoDraw/Raumplan — משמש כרפרנס כיסוי בלבד.
> מידות: **W** = רוחב פנל, **D** = עומק בליטה מהקיר, **H** = גובה פנל (מ"מ). **גובה התקנה** = ממרכז האביזר מעל הרצפה הגמורה, לפי נוהג ישראלי.
> העמודה "ORDX" מסמנת אם האלמנט קיים בקורפוס ה-ORDX הקיים.
