# ELEMENT BLOCK SPEC — מפרט-בלוק רב-פורמטי לכל אלמנט

> **מודל "אלמנט CVSM":** אובייקט אחד = **סמל-2D + גוף-3D + זהות-קטלוג (ORDX) + מיפוי-PDP + מערך-מאפיינים-לעריכת-מודד**. מקורות: `element_symbols_soline.js` · `ElementCatalog.kt` · `DXF3D_ELEMENTS.md` · `ordx_item_dictionary.json` · `OPENING_ELEMENT_SCHEMA.md`. 2026-08-22.

## מחלקות-טופס (form-class) — מערך-המאפיינים-לעריכה + התפשטות ל-4 פורמטים
כל אלמנט משתייך למחלקת-טופס אחת המגדירה אילו שדות המודד עורך בשטח (ברירת-מחדל יצרן/תקן → נדרס במידת-האמת) ואיך כל ערך-נערך מתפשט:

| form-class | תיאור | שדות-מודד (ברירת-מחדל→נמדד) | התפשטות 2D · 3D · ORDX · PDP |
|---|---|---|---|
| `POINT_WALL` | התקן-קיר נקודתי (שקע/מפסק/גלאי/נקודת-מים…) | גובה-התקנה, רוחב/גובה-פאה, עומק-בליטה, מספר-יחידות(gang) | 2D: עוגן על קו-הקיר + תווית · 3D: תיבת-התקן במיקום+גובה-התקנה, בולטת D לחדר · ORDX: מידות-attr · PDP: dims-bytes (W,D,H@0x79) |

| `UNIT` | יחידה/מכשיר (מזגן/דוד/לוח/מעבה/EV) | רוחב W, גובה H, עומק D, גובה-התקנה | 2D: מעטפת-יחידה בקנה-מידה · 3D: תיבת-גוף W×D×H · ORDX: attr · PDP: dims-bytes |

| `OPENING_WINDOW` | פתח-חלון | רוחב,גובה,גובה-סף,עובי-מסגרת,עובי-קיר,אופן-פתיחה,זיגוג | 2D: מסגרת+זיגוג · 3D: פאת-פתח + סף בגובה-סף · ORDX: Window · PDP: `חלון` bin + WDH + sill |
| `COLUMN` | עמוד מלבני | רוחב, עומק, גובה | 2D: מלבן+אלכסונים · 3D: תיבת-עמוד עד-תקרה · ORDX: TWall/`Pole` · PDP: `תעלה`(fallback) |
| `COLUMN_ROUND` | עמוד/אובייקט עגול | קוטר Ø, גובה | 2D: עיגול · 3D: גליל · ORDX: TWall/`RPole` · PDP: `תעלה`(fallback) |
| `WALLSEG` | קטע-קיר/מחיצה/חיפוי | אורך, עובי, גובה | 2D: קו/כפל-קו · 3D: קטע-קיר · ORDX: Miscellaneous · PDP: `תעלה`(fallback) |
| `STRUCT_MISC` | מבני-שונות (קורה/מדרגה/רמפה/כיפה/פתח-שירות) | W×H×D לפי-סוג | 2D: סמל-ייעודי · 3D: תיבה/פאה · ORDX: Miscellaneous · PDP: `תעלה`/`חלון` |
| `ANNOTATION` | הערה/סימון-ייחוס | טקסט/תוכן, מיקום | 2D: סמל-סימון · 3D: ללא-גוף · ORDX: Miscellaneous · PDP: `[UP_TEXT]` (ערוץ-טקסט) |
