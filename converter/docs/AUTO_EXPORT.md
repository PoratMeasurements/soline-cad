# AUTO_EXPORT — ייצוא אוטומטי: קובץ .sol אחד → כל הפורמטים

**המטרה:** שהפקת כל הפורמטים תרגיש כמו **פעולה אחת**. היום האפליקציה מייצאת `.sol` (ומשתפת אותו),
ואז מישהו מריץ את הממיר ידנית במחשב. עם המנגנון הזה — ברגע ש-`.sol` מופיע בתיקייה שנצפית, הוא הופך
**אוטומטית** ל-ORDX + PDP + DXF-2D + DXF-3D וגם דו״ח HTML + PDF, בלי אף צעד נוסף.

```
   האפליקציה משתפת  <שם>.sol   ──▶   G:\My Drive\Soline-Inbox\
        │
        │  (הצופה מזהה, ממתין שהקובץ יתייצב, וממיר)
        ▼
   G:\My Drive\Soline-Inbox\out\
        <שם>.ordx        ← ORDX (re-export, round-trip זהה)
        <שם>.pdp         ← PDP native (מבני — טעון בדיקת טעינה ב-Raumplan)
        <שם>_2d.dxf      ← תוכנית מדידה 2D + מקרא עברי
        <שם>_3d.dxf      ← 3D (קופסאות קירות + אלמנטים)
        <שם>_report.html ← דו״ח אינטראקטיבי עברי
        <שם>.pdf         ← דו״ח PDF עברי RTL (+ <שם>.print.html כמקור)
```

## איך זה עובד

`watch_convert.js` צופה בתיקייה אחת ומריץ את הממיר הקיים (`soline_convert.js`) על כל `.sol` חדש/משתנה:

1. **סריקת-סקר (polling)** של התיקייה כל 3 שניות — `readdir` + `stat` בלבד, מ-Node core. **לא** משתמשים ב-`fs.watch`:
   ב-Windows הוא קורס בקריסה בלתי-נתפסת (assertion של libuv, nodejs/node#48437) ברגע שהממיר כותב את הפלט
   בחזרה לתוך התיקייה הנצפית, ובנוסף סנכרון Google-Drive לרוב לא מפעיל אותו כלל. Polling חסין לשני הדברים.
2. **דיבאונס ~2 שניות + בדיקת יציבות-גודל**: הצופה ממתין שגודל ה-`.sol` יפסיק להשתנות לפני ההמרה, כך
   שכתיבה חלקית של סנכרון-Drive לעולם לא נמסרת לממיר.
3. **המרה** לכל ששת הפורמטים אל תת-התיקייה `out\` שליד ה-`.sol`.
4. **רישום בעברית** של שורת הצלחה/כישלון לכל קובץ. שגיאה בקובץ אחד נרשמת וממשיכים — הצופה לא קורס.
5. **מניעת כפילות**: כל `.sol` שכבר הומר (לפי mtime+גודל) מדולג. שינוי הקובץ מפעיל המרה מחדש.

## איך מריצים

במחשב, מתוך תיקיית הממיר (`G:\My Drive\claude\ordx-pdp-converter`):

```
node watch_convert.js
```

ברירת-המחדל צופה ב-`G:\My Drive\Soline-Inbox` (נוצרת אוטומטית אם אינה קיימת).

אפשרויות:

```
node watch_convert.js --dir "G:\My Drive\תיקייה-אחרת"   # תיקייה אחרת לצפייה
node watch_convert.js --once                             # ממיר את מה שקיים עכשיו ויוצא (בלי צפייה מתמשכת)
```

לעצירה: `Ctrl+C`.

## מגבלה שחשוב לדעת (בכנות)

הצופה רץ **במחשב** — הוא לא ענן. כדי שקובץ `.sol` שהאפליקציה שיתפה יומר אוטומטית, המחשב חייב להיות
**דולק** ו-`node watch_convert.js` חייב לפעול באותו רגע. אם המחשב כבוי או הצופה לא רץ — הקובץ פשוט
ימתין בתיקייה, וברגע שהצופה יופעל שוב הוא יסרוק ויהמיר גם קבצים שכבר נמצאים שם (וגם `--once` עושה זאת ידנית).

**המלצה:** להשאיר חלון אחד עם `node watch_convert.js` פתוח במהלך יום העבודה. (אפשר בהמשך לעטוף אותו
כ-Task מתוזמן ב-Windows כדי שיעלה עם הכניסה למערכת — לא נדרש לזה כאן.)

## הערות

- **אפס תלויות npm** — Node core בלבד (`fs`/`path`). אין `chokidar` ואין התקנות.
- הצופה קורא ל-`convert(inputPath, outDir)` שמיוצא מ-`soline_convert.js`. אותה פונקציה מזינה גם את
  ה-CLI הקיים, כך ש-`node soline_convert.js <input> --out <dir>` ממשיך לעבוד בדיוק כמקודם (רק עם תוספת
  דו״ח HTML/PDF).
- **PDP** נשאר **מבני** — יש לפתוח ב-Raumplan כדי לאמת טעינה (ראה `docs/EXPORT_ALL_FORMATS.md`).
- **PDF**: מרונדר בדפדפן headless שכבר על המחשב (msedge ב-Win10). אם אין דפדפן — נכתב `<שם>.print.html`
  והצופה רושם שיש לרנדר ידנית; ההמרה לא נכשלת בגלל זה.
