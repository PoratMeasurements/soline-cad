# סכימת ספריית האלמנטים — Soline

> קובץ הנתונים: `elements.json` — מערך של 170 אובייקטי אלמנט (מתוכם 39 אלמנטי-קיר אדריכליים עם `is_wall_part: true`).
> נכתב עבור Michael, Soline. תואם לעולם הבנייה בישראל 2026. עודכן: 2026-08-13.
> מקור הידע: `library_requirements.md` + `pdf_notes_corpus.md` (חילוץ מ-1,122 PDF של לקוחות).

כל אלמנט הוא אובייקט JSON יחיד המתאר **טיפוס נקודה** בקטלוג (תבנית). מאפיינים פר-מופע (למשל המצב הספציפי בשרטוט נתון) נגזרים מברירות המחדל שבקטלוג.

## 1. שדות — הגדרה מלאה

| שדה | טיפוס | חובה | תיאור |
|---|---|---|---|
| `he` | string | כן | שם האלמנט בעברית (המונח כפי שאנשי המקצוע כותבים). |
| `en` | string | כן | שם באנגלית (לצרכי קוד/ממשק). |
| `category` | string | כן | קטגוריה (ראה §2). |
| `width_mm` | number \| null | כן | רוחב במ״מ (ציר הקיר). `null` = אורך משתנה (פס תאורה, קיר, רמפה). |
| `depth_mm` | number \| null | כן | עומק/בליטה מהקיר במ״מ. `0` = אלמנט במישור הקיר/רצפה. |
| `height_mm` | number \| null | כן | גובה הגוף עצמו במ״מ. `null` = תלוי-הקשר (עמוד/קיר עד התקרה). |
| `mount_height_mm` | number \| null | כן | **גובה התקנה** = מרכז הנקודה מהרצפה הגמורה, במ״מ. `null` = בתקרה / תלוי-הקשר. `0` = מפלס רצפה. |
| `status_default` | enum | כן | מצב ברירת המחדל של הנקודה (ראה §3). |
| `measure_ref` | enum | כן | נקודת התייחסות למדידה (ראה §4). |
| `timing` | string \| null | כן | תזמון החיבור/הביצוע (ראה §5). `null` = לא רלוונטי. |
| `connection_spec` | string \| null | כן | מפרט חיבור/הזנה (מעגל, לחץ, קוטר, סוג כבל). `null` = אין. |
| `cable_slack_m` | number \| null | כן | עודף כבל/צנרת מומלץ להשארה, במטרים (ראה §6). `null` = לא רלוונטי. |
| `symbol_2d` | string | כן | תיאור מילולי של הסמל בתוכנית (למחולל ה-2D). |
| `notes` | string | כן | הערות מקצועיות, קונבנציות, וציטוטי-שדה רלוונטיים. |
| `in_ordx_corpus` | boolean | כן | האם האלמנט קיים בקורפוס ORDX (מיפוי ישיר ל-InnoDraw). 15 אלמנטים = `true`. |
| `sill_offset_mm` | number \| null | פתחים בלבד | גובה סף מהרצפה עד תחתית הפתח (ה-**a** בנוטציית החלון). |
| `opening_height_mm` | number \| null | פתחים בלבד | גובה הפתח נטו (ה-**b** בנוטציית החלון). |
| `head_clearance_mm` | number \| null | פתחים בלבד | מרווח מקצה עליון של הפתח עד התקרה (ה-**c** בנוטציית החלון). |
| `is_wall_part` | boolean | אדריכלי | `true` = אלמנט אדריכלי שהוא **חלק מהקיר** ונמדד כמקטע-קיר (תופס אורך/גובה/פתח בקיר), לא נקודת-תשתית. קיים רק באלמנטי-קיר (דלתות, פתחים, חלונות, עגולים, מקטעי קיר). |
| `wall_measure` | enum \| null | `is_wall_part` בלבד | **איך נמדד האלמנט בקיר** (ראה §12): `"opening"` / `"length"` / `"footprint"`. |
| `radius_mm` | number \| null | עגולים בלבד | רדיוס במ״מ לאלמנטים עגולים/מעוקלים (עמוד עגול, קשת, פינה מעוגלת, צוהר עגול, כיפה, קיר קמור). `radius_mm` = חצי הקוטר לעמוד/צוהר, רדיוס העקומה לקשת/קיר מעוקל. |

**סדר שדות מומלץ** באובייקט: `he, en, category, width_mm, depth_mm, height_mm, mount_height_mm, status_default, measure_ref, timing, connection_spec, cable_slack_m, [sill_offset_mm, opening_height_mm, head_clearance_mm], [radius_mm], [is_wall_part, wall_measure], symbol_2d, notes, in_ordx_corpus`.

> שדות בסוגריים הם מותנים: `sill_offset_mm/opening_height_mm/head_clearance_mm` לפתחים; `radius_mm` לאלמנטים עגולים/מעוקלים; `is_wall_part/wall_measure` לאלמנטי-קיר אדריכליים. הסדר: שדות הפתח → `radius_mm` → `is_wall_part`/`wall_measure` → `symbol_2d`.

## 3. `status_default` — מצב הנקודה (ממד ראשי)

מצב הנקודה הוא **ממד ראשון במעלה** בשפת השרטוט (טקסט בקורפוס: `שקע קיים`, `גז חדש`, `הכנה לגז`…). בקטלוג נשמר ה**מצב הטיפוסי**; במופע ספציפי ניתן לדרוס לכל אחד מהערכים:

| ערך | עברית | משמעות | תדירות בקורפוס |
|---|---|---|---|
| `existing` | קיים | נקודה קיימת בשטח | 45 |
| `new` | חדש | נקודה להוספה (ברירת המחדל לרוב האלמנטים) | 63 |
| `cancelled` | מבוטל | להסיר/לנטרל ("לבטל ולסגור קופסא") | 40 |
| `prep` | הכנה | תשתית בלבד, ללא גמר ("הכנה לחשמל/גז") | 58 |
| `future` | עתידי | יציאה/עובי לעתיד | 16 |
| `hidden` | סמוי | מוסתר ("הכנה לכירה סמויה") | 31 |

בקטלוג הנוכחי: `new` (רוב), `prep` (הכנות: צומת חשמל, שנאי LED, מצלמה, הכנת גז, PV-DC, קיר גבס…), `existing` (קורה, עמוד).

## 4. `measure_ref` — נקודת התייחסות למדידה

**עיקרון מרכזי:** תשתיות נמדדות **למרכז הנקודה** ("כלל המידות להזזת תשתיות למרכז נקודה"). היסט מפורש רק כשמצוין.

| ערך | משמעות | מתי |
|---|---|---|
| `center` | מרכז הנקודה (ברירת מחדל) | שקע, מזגן, כיור, ברזים, חלון, נקודת גז. |
| `offset_wall` | היסט מוגדר מהקיר | ביוב ("15 ס״מ מהקיר", "צמוד 25 ס״מ עם סופית 45°"). |
| `floor_line` | קו הריצוף (מפלס 0) | ניקוז רצפה, שקע רצפה, יציאת אסלה, בלון גז. |
| `ceiling` | מפלס התקרה | ספוט שקוע, גלאי עשן, מפזר מיזוג, רמקול, הנמכת תקרה. |

## 5. `timing` — תזמון

מתי מבצעים/מחברים את הנקודה ביחס להתקנת המטבח/הנגרות. ערכים:
- `"לפני התקנת מטבח"` — תשתית/בנייה שקודמת (גבס, הנמכת תקרה, הכנת גז).
- `"לאחר התקנת מטבח"` — חיבור סופי בתוך/מאחורי ארונות (יציאות מכשירים, חנוכיית גז, מנדף, מסתור).
- `null` — לא רלוונטי / עצמאי.

## 6. `cable_slack_m` — עודף כבל/צנרת

אורך עודף להשארה לחיבור עתידי, במטרים. ערכים חוזרים בקורפוס: 0.8 / 1 / 1.5 / 2 / 3.5 / 4.5 מ׳.

## 7. קונבנציית גבהים (`H`)

- כל הגבהים ב-**מ״מ בקובץ**, אך בשרטוט מסומנים ב-**ס״מ מהרצפה הגמורה** בקידומת `H` (`H 40` = 40 ס״מ = `mount_height_mm: 400`).
- **טווח `H x-y`** = אלמנט משופע / קיר בגובה משתנה (למשל `H 260.9-261.9` להכנת תאורה). מיוצג בקטלוג כ-`height_mm: null` / הערה.
- **`H 0`** = מפלס רצפה (`mount_height_mm: 0`): ניקוז רצפה, פתח דלת, קו ריצוף.
- **תקרה נמדדת בשני צדדים** ("גובה שמאל / גובה ימין") — הרצפה/תקרה לא בהכרח מפלסות. יש לתעד שני ערכים לחדר בשכבת הפרויקט.
- **תיקוני מידה**: `-7 ס״מ` לחישוב גובה ממדרגה; ריצוף עתידי `+~20 ס״מ`; ירידה מקו לייזר תקרה `-1.5 ס״מ`; צוקל `15 ס״מ`.

### 7.1 קידוד חלון/פתח: `H a+b+c`
נוטציית השדה (167 קבצים בקורפוס). שלושת המספרים = חתך אנכי של הפתח, וסכומם ≈ גובה הקיר:
- **a** = `sill_offset_mm` — סף מהרצפה עד תחתית הפתח.
- **b** = `opening_height_mm` — גובה הפתח נטו.
- **c** = `head_clearance_mm` — מקצה עליון של הפתח עד התקרה.

דוגמה: `חלון H 104.9+144+9.3` → `sill_offset_mm: 1049, opening_height_mm: 1440, head_clearance_mm: 93` (סכום 258.2 ס״מ ≈ גובה קיר). וריאנט 4-חלקי קיים לחלונות מיוחדים (משקוף/סורג). **חובה לקודד סף + גובה פתח, לא גובה התקנה יחיד.** שדות אלו קיימים ב-`חלון`, `אדן חלון`, `פתח דלת (עם/ללא משקוף)`.

## 8. "שפה" לתיאור נקודות — דקדוק ה-DSL

הערות השדה בנויות באופן עקבי. זהו הבסיס לפירוק/יצירת הערות אוטומטיות:

```
[אלמנט] + [מצב] + [פעולה] + [כיוון] + [מידה] + [גובה-יעד] + [תזמון] + [חיבור/מפרט]
```

| רכיב | ממופה לשדה | דוגמאות ערכים |
|---|---|---|
| אלמנט | `he` | שקע כפול, נקודת גז, ק.בקורת |
| מצב | `status_default` | קיים / חדש / מבוטל / הכנה / עתידי / סמוי |
| פעולה | (פר-מופע) | להזיז, להרים, לבטל, לסגור, לפרק, להכין, לקצר, לכופף, יחובר |
| כיוון | (פר-מופע) | שמאלה / ימינה / למעלה / למטה |
| מידה | (פר-מופע) | `<N> ס״מ` (10/15/20/30/50/70) |
| גובה-יעד | `mount_height_mm` | "באותו גובה" או "להרים ל-110" |
| תזמון | `timing` | לפני / אחרי התקנת מטבח |
| חיבור/מפרט | `connection_spec` / `cable_slack_m` | "30 מיליבר", "מעגל 16A", "להשאיר 1 מטר" |

דוגמת פירוק: *"שקע זה יש להזיז 30 ס״מ שמאלה באותו גובה"* → `{אלמנט: שקע, פעולה: הזזה, כיוון: שמאלה, מידה: 300מ״מ, גובה-יעד: שמירה}`.

## 9. מפרטים מספריים סטנדרטיים (מהקורפוס)

- לחץ גז: **30 מיליבר**.
- שקעי שירות: הרמה מ-**94 → 110 ס״מ** (מעל שיש); "המלצה בלבד".

- תשתיות נשלפות מהקיר: **15 ס״מ** מהקיר, עם **1 מטר** כבל/צינור עודף.
- כניסת גז לארון: **50 ס״מ**; הכנת גז יורדת ל-**40 ס״מ**.

## 11. הערה טכנית — גליף גופן (pipeline קלט)

בחילוץ טקסט מ-PDF של InnoDraw/HAMMES, האות **נ** מופיעה כתו `ð` (U+00F0). נורמליזציה `ð→נ` מתקנת את הקורפוס.
בנוסף, טקסט עברי מעורב במספרים עלול להופיע הפוך (RTL) — יש לטפל בכיווניות בעת פרסור. רלוונטי לכל pipeline עתידי שקורא PDF אלה.

## 12. אלמנטי-קיר אדריכליים — `is_wall_part` ו-`wall_measure`

בניגוד ל**נקודת-תשתית** (שקע, גז, ניקוז) שנמדדת כנקודה בודדת למרכזה, **אלמנט-קיר אדריכלי** הוא **חלק מהקיר עצמו** ותופס מקטע (אורך/גובה/פתח). כל אלמנט כזה מסומן `is_wall_part: true` ומקבל `wall_measure` המגדיר איך מכמתים אותו בשרטוט. 39 אלמנטים בקטלוג (5 תת-הקטגוריות האדריכליות החדשות).

### 12.1 ערכי `wall_measure`

| ערך | משמעות | נמדד לפי | אלמנטים טיפוסיים |
|---|---|---|---|
| `opening` | **פתח בקיר** | סף (`sill_offset_mm`) + גובה פתח (`opening_height_mm`) לאורך הקיר. משתמש בנוטציית `H a+b+c` (§7.1). | דלתות, פתחי מעבר, קשתות, כל החלונות, פתח שירות, דלפק-מעבר. |
| `length` | **אורך לאורך הקיר** | אורך המקטע האופקי לאורך קו הקיר (עם עומק/בליטה מהמישור). | מחיצות, קיר כפול, ניל״ל, נישה, בוקסה, פינה קטומה, קיר מעוקל, מדרגת קיר, קולונה, חיפוי, פינה מעוגלת, קשת קיר. |
| `footprint` | **טביעת רגל** | שטח שהאלמנט תופס ברצפה/תקרה סביב מרכזו (לא מקטע קיר ליניארי). | עמוד עגול, חצי-עמוד, כיפה (בתקרה). |

### 12.2 חוקי מדידה נלווים
- **`opening`** — חובה לקודד `sill_offset_mm` + `opening_height_mm` (ולא גובה התקנה יחיד). `mount_height_mm` = מרכז הפתח לנוחות. פתחי רצפה (דלתות) → `sill_offset_mm: 0`.
- **`length`** — `width_mm: null` = אורך משתנה שנקבע בשרטוט (קירות, חיפוי, קשתות). `depth_mm` = בליטה מהמישור; **`depth_mm` שלילי** = שקע פנימה לתוך הקיר (נישה/כוך).
- **`footprint`** — `width_mm/depth_mm` = ממדי הבסיס; לעגולים `radius_mm` = חצי הקוטר. `height_mm: null` = עד התקרה (עמוד).

### 12.3 `radius_mm` — אלמנטים עגולים/מעוקלים
נוכח ב-9 אלמנטים. לעמוד/צוהר = חצי הקוטר; לקשת/ארקה = חצי רוחב הפתח; לפינה מעוגלת/קיר קמור-קעור/כיפה = רדיוס העקומה (ערך גדול = עקמומיות מתונה). אלמנט עגול יכול לשאת גם `wall_measure` וגם שדות פתח (למשל צוהר עגול = `opening` + `radius_mm`; קשת = `opening` + `radius_mm`).
