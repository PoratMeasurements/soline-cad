## 3. קונבנציות מדידה (קריטי)

### 3.1 גובה — סנטימטרים, מהריצוף, קידומת `H`
- כל גובה ב-**ס"מ מהרצפה הגמורה** ("מריצוף"). `H 40` = 40 ס"מ.
- טווח `H x-y` (למשל `H 226-247`, `H 260.9-261.9`) = אלמנט משופע / קיר בגובה משתנה / פריט המתפרש בין שני גבהים.
- `H 0` (מופיע מאוד תדיר) = גובה רצפה: ניקוז רצפה, פתח דלת, קו ריצוף.
- **גובה תקרה נמדד בשני צדדים**: "גובה שמאל / גובה ימין" (22 מופעים) — כי הרצפה/תקרה לא מפלסות. יש לתעד שני ערכים לחדר.
- מדידת גובה **ממדרגה**: "במידה ורצים לחשב גובה ממדרגה יש להפחית 7 ס"מ" — קונבנציית תיקון.

### 3.2 נקודת התייחסות: מרכז מול היסט
- **ברירת מחדל = מרכז הנקודה.** "כלל המידות להזזת תשתיות **למרכז נקודה**". נמדדים למרכז: שקע, מזגן, כיור, ברזים, קיר, קומה.
- היסט מפורש כשנדרש: ביוב "15 ס"מ מרחק מהקיר"; ניקוז "0 עם הריצוף"; "יש להוציא במרחק 15 ס"מ מהקיר" (תשתיות שנשלפות מהקיר לפני התקנת ארונות).

### 3.3 נוטציית חלון מורכבת: `חלון H a+b+c`  (150 מופעים)
פירוש שלושת המספרים (סכומם ≈ גובה הקיר):
- **a** = גובה הסף מהרצפה עד תחתית החלון (למשל 104.9)
- **b** = גובה פתח החלון (למשל 144)
- **c** = מרווח מקצה עליון של החלון עד התקרה (למשל 9.3)
- דוגמה: `חלון H 104.9+144+9.3` ⟵ 104.9+144+9.3 = 258.2 ≈ גובה קיר `H 258`.
- וריאנט 4-חלקי מופיע לחלונות מיוחדים (משקוף/סורג): `חלון H 122.2+3+67.4+175.6`.
- ל-InnoDraw/PDP: יש לקודד חלון כ-**offset תחתון + גובה פתח** (ולא רק גובה התקנה יחיד).

### 3.4 מידות "לא סופיות" ותיקוני גבס/ריצוף
דפוס חוזר וקריטי לדיוק: המודד מסמן שהמידה עדיין תשתנה.
- "יש להפחית עובי גבס עתידי" — מידות עד קו קונסטרוקציה, לפני חיפוי גבס.
- "גובה לא סופי — יש להפחית עובי גבס".
- "יש לאמת את כלל מידות הגובה לאחר ביצוע ריצוף… ריצוף יעלה ~20 ס"מ".
- "קו לייזר בתקרה סומן עם הקבלן — מקו זה יש לרדת 1.5 ס"מ".
→ למחולל: לתמוך בשדה **"סטטוס מידה" (סופי / לא-סופי / לאימות)** ובקיזוז גבס/ריצוף.

### 3.5 זוויות קיר
זוויות מסומנות במעלות (`90.0°`, `88.6°`, `91°`). קירות לא בהכרח בזווית ישרה — יש לתעד זווית לכל קיר (כבר קיים ב-ORDX כ-`Angle`).

## 4. "שפה" לתיאור נקודות — הדקדוק שחולץ

ההערות בנויות באופן עקבי לפי הרכב של רכיבים. זהו הבסיס לקידוד ל-DSL:

```
[אלמנט] + [מצב] + [פעולה] + [כיוון] + [מידה] + [גובה-יעד] + [תזמון] + [חיבור/מפרט]
```

### 4.1 מצב (STATE)
| מצב | מילה | ספירה | משמעות |
|---|---|---|---|
| קיים | קיים / קיימת | 45 | נקודה קיימת בשטח |
| חדש | חדש / חדשה | 63 | נקודה להוספה |
| מבוטל | לבטל / מבוטל / מבוטלת | 40 | להסיר/לנטרל |
| הכנה | הכנה ל… | 58 | תשתית בלבד, ללא גמר ("הכנה לחשמל/גז/כירה סמויה") |
| עתידי | עתידי / עתידית | 16 | יציאה/עובי לעתיד |
| סמוי | סמוי / סמויה | 31 | מוסתר ("הכנה לכירה סמויה") |

### 4.2 פעולה (ACTION)
להזיז / יזוז / יעבור / יזוז (הזזה); להרים · להנמיך (שינוי גובה); לבטל · לסגור · לפרק (הסרה); להכין · להשאיר חופשי · להוציא (הכנה); להחליף (החלפה); לקצר · לכופף · לחתוך (עיבוד צנרת); יחובר · לחבר (חיבור סופי).

### 4.3 כיוון + מידה
שמאלה (17) / ימינה (13) / למטה / למעלה + `<N> ס"מ`. היסטים אופייניים: 10, 15, 20, 30, 50, 70 ס"מ.
מתלווה: **"באותו גובה"** (שמירת גובה) או גובה-יעד מפורש (הנפוץ: **"להרים ל-110"**).

### 4.4 תזמון (TIMING) — נפוץ מאוד

חילוץ הטקסט מפיק את האות **נ** כתו `ð` (U+00F0) בעקבות מיפוי גופן שגוי בקבצי InnoDraw/HAMMES (1,927 מופעים). כל שאר האותיות תקינות. נורמליזציה יחידה `ð→נ` מתקנת את הקורפוס במלואו — כבר הוחלה על קובץ הציטוטים. יש לזכור זאת בכל pipeline עתידי שקורא PDF אלה. בנוסף, טקסט עברי מעורב במספרים עלול להופיע הפוך (RTL) בשורות מסוימות — יש לטפל בכיווניות בעת פרסור.
