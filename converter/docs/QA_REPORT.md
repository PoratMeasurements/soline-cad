## מקרי-קצה שנבדקו והתנהגות (אחרי התיקון)
- **ריק / זבל / לא-XML / בלי `<Job>`** → נכשל **בחן** ל-4 פורמטים (`parse failed: ...`), הריצה ממשיכה.
- **חדר בלי קירות / קיר בלי מיקום / קיר באורך אפס** → 4 פלטים תקינים; ORDX round-trip זהה; DXF תקין (זוגות/ASCII/EOF/סקציות מאוזנות).
- **מידות אפס/שליליות** → DXF3D עושה `Math.abs` ומחליף אפס בברירת-מחדל; אפס-רוחב נופל ל-100; לא קורס.
- **קואורדינטות/מידות ענק** → 2D/3D/ORDX תקינים; PDP בלבד `ERR` דרך ה-try/catch (ראה באג #4).
- **שם עם `& < > " ' עברית אמוג׳י`** → escaping XML תקין, round-trip זהה, ה-DXF נשאר ASCII.
- **שם לא-ממופה למיפוי סמלים** → מסומן ב-`missing` ו-DXF-2D יורד ל-✗ (התנהגות רצויה — מסמן חוסר סמל).
