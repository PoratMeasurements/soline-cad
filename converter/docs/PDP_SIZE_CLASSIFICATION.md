# PDP — סיווג גודל-אלמנט: קבוע 🔒 / משתנה 🎚️ / "+X" ➕

> **הפיצוח הגדול (2026-08-25, אושר ע"י הבעלים בבדיקה חיה ב-Raumplan על `tashtiot_inject_test.pdp`).**
> ב-Raumplan כל אלמנט שייך לאחת מ**שלוש** משפחות-**גודל**:
> - **🔒 קבוע** — Raumplan מצייר אותו בגודל-ה-native הקבוע שלו. **הגודל שלנו נזרק/מתעלמים ממנו.** אם נכתוב מידות → **האייקון יוצא מעוות/מוטה** (הבאג שהבעלים ראה: הקוקוו/מיקום נכון, הגליף מסובב). → **להזריק מיקום בלבד, לשמר את בייטי-הגודל ה-native.** (חוק-הבייט: `t1==t2`, שניהם native.)
> - **🎚️ משתנה** — Raumplan לוקח את **המידות שלנו**. → להזריק מיקום **+ מידות-שלנו** (לשתי השלישיות). (חוק-הבייט: `t1!=t2`.)
> - **➕ "+X"** — לקחת טיפוס-🔒 (X) ולתת לו **מידה-מותאמת שלנו תוך שמירה על אייקון-נכון**: משמרים `t1 @0x79` = native של X (הגליף נעול, אין הטיה), כותבים `t2 @0x7f` = המידה-שלנו, וה-label = `+X`. **לא נוגעים ב-`[0x91,0x9c)`** (code+block → אותו אייקון, אין 921). זהו בדיוק מנגנון-הספרייה של Raumplan ל-+שקע/+מפסק/+טלפון. פירוט מלא: `docs/PDP_SOCKET_PLUS.md`.
>
> ⚠️ ציר-הגודל **אינו זהה** לציר-העוגן (CENTER/OFFSET של המיקום). זה סיווג נפרד שהבעלים מסר ישירות — גובר על ניחוש-העוגן.
