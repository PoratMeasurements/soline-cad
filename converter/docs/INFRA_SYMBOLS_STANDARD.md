## 0. עקרונות-על ומקורות

### 0.1 הבחנה קריטית: תכנית-אדריכלית מול תרשים-חשמל (schematic)
יש שתי משפחות-סמלים שונות לחלוטין, וזה שורש-הבלבול:

| | תרשים-מעגל (schematic / circuit diagram) | **תכנית-התקנה אדריכלית (installation / floor-plan)** ← שלנו |
|---|---|---|
| מטרה | חיווט חשמלי לוגי | **מיקום פיזי** של אביזרים על הקיר/תקרה/רצפה |
| שקע | קו + זוויות-מגע | **חצי-עיגול על קו-הזנה** (IEC 60617-11) |
| מפסק | מגע נשבר | **עיגול/נקודה + מנוף** על הקיר |
| תקן-מקור | IEC 60617-2..8 | **IEC 60617-11 (Installation)**, ISO 4157, AGS |

Soline מייצרת **תכנית-התקנה** (המודד מסמן היכן כל אביזר). לכן כל סמל חייב להיות
מ־IEC 60617-11 (Building installation) ולא מתרשים-המעגל. זו נקודת-הכשל של ספריות גנריות.

### 0.2 התקנים המחייבים
- **IEC 60617** — *Graphical symbols for diagrams*. סעיף 11 = "Architectural and topographical
  installation plans and diagrams" — סמלי-שקע/מפסק/מאור/הארקה. (BS EN 60617 בוטל והוחלף במאגר-המקוון של IEC.)
- **IEC 60417** — Graphical symbols for use on equipment (סימוני-מכשיר: הארקה, ~, וכו׳).
- **ISO 128 / ISO 4157** — Construction drawings: קונבנציות-קו, סימון-חתכים ומרחבים.
- **ISO 14617 / ISO 10628** — Graphical symbols for diagrams (שסתומים/צנרת — ה"פרפר" לשסתום).
- **NFPA 170** — Standard for fire safety & emergency symbols (גלאים/מתזים/סירנות).
- **ASHRAE 134 / SMACNA** — סמלי-HVAC. *אין תקן-על יחיד ל-HVAC*; כל משרד מחזיק מקרא. הקונבנציות שלהלן הן המשותפות.
- **תקן ישראלי / מקרא-אדריכלי** — בישראל **אין מקרא-חובה אחיד** ("המקרא משתנה בין
  האדריכלים... לא קיים סטנדרט קבוע"). הקונבנציה-הנפוצה בתכניות-מגורים ישראליות:
  שקע = עיגול עם קו; מפסק = משולש/עיגול עם קו; גוף-מאור = עיגול עם קו-אופקי;
  תיבת-חיבורים = ריבוע. תקנות-החשמל (מעגלים סופיים, תשמ״ה-1984) מגדירות מונחים ("נקודת-מאור") אך לא צורות.

### 0.3 עקרון-ההיררכיה של Soline (החלטת-עיצוב)
מכיוון שהתכנית ישראלית-אדריכלית אך צריכה גם קריאוּת בין-לאומית, אימצנו **בסיס-צורה לפי
דיסציפלינה** — קבוע וחד-משמעי, שמאפשר זיהוי-מיידי ב-1:50/1:20 גם בשחור-לבן:

| דיסציפלינה | בסיס-הצורה | מקור |
|---|---|---|
| חשמל — כוח (שקע) | **חצי-עיגול** (כיפה) על קו-הזנה | IEC 60617-11 |
| חשמל — מיתוג (מפסק) | **עיגול/נקודה + מנוף** | IEC 60617-11 |
| מתח-נמוך / תקשורת | **משולש** (חוד = אות) + אות-זיהוי | AGS / IEC 60617-11 comms |
| מאור | **עיגול + סימן-פנימי** (צלב/קרניים/קו) | IEC 60617-11 / RCP |
| מים/גז — שסתום | **"פרפר"** (שני משולשים חוד-אל-חוד) | ISO 14617 |
| מים/גז — נקודת-הזנה | **עיגול + אות** (C/H/G) על צינור | ISO 4157 + מקרא |
| ניקוז | **עיגול/ריבוע + מחסום** | plumbing legend |
| מיזוג/אוורור | **ריבוע/עיגול + זרימה** | ASHRAE/SMACNA |

עקביות-הבסיס הזו היא ה"מקצועיות" שהמקרא-הישראלי הרנדומלי חסר: קורא-התכנית לומד 8 בסיסי-צורה
ומזהה 100 אלמנטים.

## 1. חשמל — שקעים (IEC 60617-11)

**סמל-הבסיס (תקן):** חצי-עיגול (כיפה) שהקוטר-השטוח שלו יושב על **קו-ההזנה** (הגזע מהקיר),
והקשת פונה אל תוך-החדר. זהו סמל-השקע 11-11-… של IEC. מספר-המקומות (gang) מסומן ב**מספר
הקווים/שנתות החוצים את קו-הקוטר**: יחיד = שנתה אחת, כפול = שתיים, משולש = שלוש. (קונבנציה
חלופית מקובלת: חזרה על חצי-העיגול. בחרנו שנתות — קומפקטי יותר וחד-משמעי ב-1:50.)

| key | אלמנט | הסמל הנכון | הבחנה | מקור |
|---|---|---|---|---|
| `socket_single` | שקע יחיד | כיפה + גזע + **שנתה 1** | — | IEC 60617-11 |
| `socket_duplex` | שקע כפול | כיפה + **2 שנתות** | 2 מקומות | IEC 60617-11 (twin) |
| `socket_triple` | שקע משולש | כיפה + **3 שנתות** | 3 מקומות | IEC 60617-11 |
| `socket_waterproof` | מוגן-מים IP44 | כיפה + **תג IP44** + גגון-מגן | סימון-סביבה | IEC + IP (60529) |
| `socket_3phase` | תלת-פאזי | עיגול-כוח + **3 מוטות-פאזה** + `3~` | 3~ = תלת-פאזי | IEC 60417 (~) |
| `socket_popup` | שקע-רצפה נשלף | **ריבוע-רצפה** (אלכסונים) + כיפה + חץ-הרמה | ריבוע = רצפה | AGS floor outlet |
| `socket_usb` | שקע USB | כיפה + תג `USB` | — | מקרא |
| `socket_counter/service` | שיש/שירות | כיפה כפולה + תווית | מיקום | מקרא |

**מה תיקנּו:** שקע מרובה-מקומות צויר כ-N כיפות נפרדות; התקן = **כיפה אחת + N שנתות**.
שקע-רצפה חייב את **מסגרת-הריבוע** (הבחנה מ"שקע-קיר"), לפי AGS "circle inside a square = floor".

## 2. חשמל — מפסקים (IEC 60617-11)

**סמל-הבסיס (תקן):** נקודת-ציר על הקיר + **מנוף** (קו-מפעיל) נטוי אל תוך-החדר. מספר-המנופים/
מקבצים = מספר-המעגלים (חד/דו/תלת). הקונבנציה הישראלית מוסיפה "משולש/עיגול עם קו".

| key | אלמנט | הסמל הנכון | הבחנה | מקור |
|---|---|---|---|---|
| `switch_single` | חד-קוטבי | ציר + מנוף יחיד | — | IEC 60617-11 (S00302) |
| `switch_double` | דו-קוטבי/כפול | ציר + **2 מנופים** | 2 מעגלים | IEC 60617-11 |
| `switch_triple` | תלת | ציר + **3 מנופים** | 3 מעגלים | IEC 60617-11 |
| `switch_2way` | מחליף (two-way) | מנוף + **מגע-חלופי (מזלג)** | changeover | IEC 60617-11 |
| `switch_cross` | צלב (intermediate) | ציר + **מגעים-מוצלבים X** | 4-terminal | IEC 60617-11 |
| `switch_dimmer` | דימר/עמעם | מנוף + **סימן-וויסות** (משולש-מפלס) | variability | IEC 60617 (regulation) |
| `switch_button` | לחצן-רגעי | עיגול + **ליבה-מלאה** | push-button | IEC 60617-11 |
| `switch_pullcord` | מפסק-חבל | עיגול + חבל-משיכה מקווקו | pull-cord | IEC 60617-11 |

**קנון:** one-way = מנוף אחד; two-way = מזלג-changeover; intermediate = X. אלה בדיוק
"one line / fork / cross" מ-IEC. תואם.

## 3. תקשורת ומתח-נמוך (בסיס = משולש)

**סמל-הבסיס (תקן/AGS):** אביזרי מתח-נמוך = **משולש** (החוד מצביע כמו ראש-חץ של אות).
טלפון = משולש-מלא; טלוויזיה = משולש בתוך עיגול; מחשב/רשת = משולש + סימן-נתונים.

| key | אלמנט | הסמל הנכון | הבחנה | מקור |
|---|---|---|---|---|
| `data_phone` | טלפון | **משולש-מלא** על גזע | solid Δ = phone | AGS / IEC comms |
| `data_tv` | טלוויזיה/אנטנה | **משולש בתוך עיגול** + `TV` | Δ-in-○ = TV | AGS |
| `data_rj45` | רשת/מחשב | משולש (מתאר) + סימן-נתונים | data outlet | AGS / IEC comms |
| `data_cat/fiber/hdmi` | Cat/סיב/HDMI | משולש + תג-אות | variant | מקרא |
| `speaker_ceiling` | רמקול | ריבוע + חרוט-קול | — | AGS |
| `intercom_*` | אינטרקום/דלתון | מסך + עדשה/`דלתון` | — | מקרא |

**מה תיקנּו:** RJ45 היה עיגול+משולש; טלפון היה משולש-ריק+T; TV היה עיגול+טקסט. התקן מאחד
את כל המתח-הנמוך על **בסיס-משולש** (הבחנה נקייה מ"עיגול = כוח/מאור"). טלפון→משולש-מלא;
TV→משולש-בעיגול.

## 12. סיכום השינויים מול המצב-הקודם (מה שגינו)

1. **שקע מרובה-מקומות** — צוירו N כיפות נפרדות → התקן: **כיפה אחת + N שנתות** (IEC 60617-11).
2. **תקשורת** — עיגול/מלבן מעורבבים → **בסיס-משולש אחיד** למתח-נמוך (טלפון=משולש-מלא, TV=משולש-בעיגול).
3. **נקודת-גז** — משושה לא-תקני → **עיגול+G** (אספקה) / **פרפר** (ברז); המשושה הוסר.
4. **חוסר-היררכיה** — עתה **8 בסיסי-צורה לפי דיסציפלינה** (§0.3), זיהוי-מיידי ב-1:50.
5. שאר-הסמלים (מפסקים, שסתום-פרפר, הארקה, מאור, ניקוז, HVAC) — כבר תאמו את התקן; בוצעו
   שיפורי-פרופורציה וניקוי-קווים לקריאות ב-1:20.
