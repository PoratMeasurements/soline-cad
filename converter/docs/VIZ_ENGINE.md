# מנוע הדמייה למדידה — VIZ_ENGINE

> מנוע הדמיית 3D עצמאי, אופליין לחלוטין, ללא תלויות, למטבחים מדודים של סולין.
> מרנדר את החדר המדוד עם ארונות, צוקל, משטחי עבודה, קירות ורצפות בטקסטורות
> פרוצדורליות אמיתיות-למראה — וגם משמש ככלי **תכנון ובדיקת התאמה** (זיהוי
> התנגשויות בין גוף הארון לתשתיות). נכתב עבור Michael, סולין.

**קבצים בבעלות המנוע (רק אלה):**
- `src/viz_engine.js` — המנוע (UMD: דפדפן + Node לחלקים הטהורים).
- `viz/kitchen_viz.html` — צופה עצמאי, קובץ-בודד, נפתח ישירות מ-Google Drive.
- `docs/VIZ_ENGINE.md` — המסמך הזה.

המנוע **אינו** טוען שום דבר מהרשת: אין CDN, אין three.js, אין URL חיצוני. כל
הטקסטורות נוצרות פרוצדורלית ל-`<canvas>` בזמן טעינה. אימות: `grep -E "https?:"`
על `viz/kitchen_viz.html` מחזיר 0.

## 1. גישת הרינדור — WebGL עם נפילה חלקה ל-Canvas 2.5D

המנוע כותב **מרנדר WebGL קומפקטי בעבודת-יד** (ללא ספריות). אם `WebGL` לא זמין
(או ב-`options.forceCanvas`) הוא נופל ל**מרנדר Canvas 2.5D** לפי אלגוריתם-הצייר
(painter's algorithm): כל מצולע מוקרן, ממוין לפי עומק מהרחוק לקרוב, וממולא
בתבנית-הטקסטורה עם הצללה.

| היבט | WebGL | Canvas 2.5D |
|---|---|---|
| גיאומטריה | משולשים מבוצ'רים לפי חומר | מצולעים ממוינים לפי עומק |
| טקסטורה | `TEXTURE_2D` עם `REPEAT` + mipmaps | `createPattern("repeat")` + טרנספורם אפיני |
| תאורה | shader (ראה §4) | חישוב לכל-פאה ב-CPU |
| הסתרת פנים | `CULL_FACE` + קירות דו-צדדיים + hide-set | קילינג לפי נורמל + hide-set |

שני המסלולים חולקים את אותו `buildScene`, אותה מתמטיקת `mat4` ואותם מחוללי-טקסטורה,
כך שהמראה עקבי. שניהם נבדקו חיים בדפדפן (WebGL: רינדור מלא ללא שגיאות קונסול;
2.5D: `backend=canvas2.5d`, 3 התנגשויות, פיקסלים מטוקסטרים).

## 2. צורת ה-JSON של החדר (קלט)

מערכת-צירים: `X` = מישור-רוחב (ימינה), `Z` = עומק (לתוך החדר), `Y` = גובה. הרצפה
ב-`Y=0`. כל היחידות **מ״מ**. תואם ברוחו ל-`OBJECT_MODEL.md` (`dimensions_mm`,
`mount_height_mm`, placement).

```jsonc
{
  "meta":   { "name": "מטבח לדוגמה", "units": "mm" },

  // מילון חומרים בשם -> {kind, base, accent, scale}. אופציונלי.
  "materials": {
    "OAK":    { "kind": "WOOD",        "base": "#b5884f", "accent": "#6f4a22", "scale": 1.0 },
    "DEKTON": { "kind": "MARBLE_VEIN", "base": "#f1efe9", "accent": "#7f8790" }
  },

  "room": {
    "height": 2700,
    "floorMaterial": "TILE_GRID",     // מפתח-חומר / שם-TextureKind / אובייקט inline
    "wallMaterial":  "CONCRETE",

    // אופציה א': קירות מפורשים (מומלץ — נדרש כדי לתלות אביזרים)
    "walls": [
      { "id": "W1", "from": [0,0], "to": [4200,0], "height": 2700, "material": "CONCRETE",
        "accessories": [ /* ראה §3 */ ] },
      { "id": "W2", "from": [4200,0], "to": [4200,3200] }
    ],
    // אופציה ב': קו-מתאר סגור (אם אין walls). ייגזרו קירות בלי אביזרים.
    "outline": [ [0,0], [4200,0], [4200,3200], [0,3200] ]
  },

  // ארונות כתיבות. type: "base" | "wall" | "tall".
  "cabinets": [
    { "id": "b1", "type": "base",
      "x": 100, "z": 0,               // פינה קרובה-שמאלית בתכנית (מ״מ)
      "width": 600, "depth": 600,
      "heightFrom": 0, "heightTo": 900,
      "front": "OAK",                 // חומר החזית/דלתות
      "carcass": "WHITE",             // חומר גוף הארון
      "kickboard": true,              // צוקל (ברירת-מחדל true לארון בסיס)
      "label": "ארון בסיס 60" }
  ],

  // משטחי עבודה — או מעל ארונות, או תיבה מפורשת.
  "counters": [
    { "id": "ct1", "overCabinets": ["b1","b2"], "material": "DEKTON",
      "height": 920, "thickness": 40, "overhang": 25, "label": "דקטון" }
    // חלופה: { "x":100, "z":0, "width":1800, "depth":600, "height":920, "thickness":40, "material":"DEKTON" }
  ],

  // מוצרים/מכשירים כתיבות חופשיות. type קובע צבע ברירת-מחדל (ראה §5).
  "products": [
    { "id": "sink", "type": "sink", "x": 850, "z": 150,
      "width": 480, "depth": 400, "heightFrom": 880, "heightTo": 930,
      "material": "STEEL",           // אופציונלי; אם חסר -> צבע לפי type
      "label": "כיור נירוסטה" }
  ]
}
```

**הפניית-חומר** (בכל שדה material/floorMaterial/…) יכולה להיות:
1. שם-מפתח מתוך `materials`, 2. שם-TextureKind ישיר (למשל `"WOOD"`), או
3. אובייקט inline `{kind, base, accent, scale}`.

## 3. אביזרים / תשתיות על הקיר (שכבת המדידה)

כל קיר נושא מערך `accessories`. אביזר ממוקם ביחס לקיר: `fromLeft` (מרחק לאורך
הקיר מנקודת-ההתחלה), `fromBottom` (גובה מהרצפה), `width`, `height`, `depth`
(בליטה לתוך החדר). `depth` אופציונלי — יש ברירת-מחדל לכל סוג.

```jsonc
{ "id":"gas1", "kind":"pipe_gas", "fromLeft":1000, "fromBottom":0,
  "width":45, "height":950, "depth":55, "label":"צינור גז" }
```

| `kind` | משמעות | צבע | מחלקת-התנגשות |
|---|---|---|---|
| `socket` | שקע חשמל | לבן | `neutral` (מותר מאחורי ארון) |
| `switch` | מפסק | לבן | `neutral` |
| `pipe_water` | צינור מים | כחול | `hard` |
| `pipe_gas` | צינור גז | צהוב | `hard` |
| `electric_line` | קו חשמל | אדום-חום | `hard` |
| `window` | חלון | תכלת-זכוכית | `hard` (עומק-בדיקה 400 מ״מ) |
| `door` | דלת | עץ | `hard` |
| `ceiling_drop` | הנמכת-תקרה | אפור-בהיר | `hard` |
| `floor_drain` | ניקוז רצפה | אפרפר | `floor` |

`floor_drain` יושב על הרצפה ובולט לחדר במרחק `depth`. אביזרים חיים בשכבת `infra`
ונשלטים בנפרד; הם **נשארים גלויים** גם כשמסתירים את הקיר שלהם (כדי לראות היכן
התשתית ביחס לתכנון) — כבה את שכבת "תשתיות" כדי להעלים אותם.

## 4. מודל ההצללה (מצב "רנדר")

זהו מצב ברירת-המחדל בשני המרנדרים — הצללה **על גבי** הטקסטורה הפרוצדורלית
(`צבע-סופי = טקסטורה × תאורה × tint`):

- **Lambert (אור-מפתח):** `d = max(dot(N, L), 0)`, כיוון אור `normalize(0.45, 0.8, 0.35)`.
- **אור-עליון (sky):** `0.18 · max(N.y, 0)` — פאות פונות-מעלה מוארות מעט יותר.
- **מילוי קר מנוגד:** `0.16 · max(dot(N, (-0.35,0.15,-0.6)), 0)`.
- **אמביינט:** `0.44`.
- **AO מגע (fake ambient occlusion):** `1 − 0.34·exp(−y/90)·(1 − max(N.y,0))` —
  מכהה פאות אנכיות סמוך לרצפה, לתחושת "נחיתה"/צל-מגע בחיבורי ארון/רצפה.
- **הכהיית-קצה (rim):** `pow(1 − dot(N, V), 3)` מכהה מעט בזוויות-מבט משיקיות
  לתלת-ממדיות. (`V` = כיוון-מבט מנקודת-הפיקסל לעין.)

הערכים מקוזזים ל-`[0, ~1.2]`. ב-2.5D אותו חישוב מתבצע לכל-פאה על ה-CPU; קירות
דו-צדדיים משתמשים ב-`abs(dot(N,L))` כדי להיות מוארים משני הצדדים.

## 5. מפת צבע-לפי-סוג (מוצרים/מכשירים)

כשלמוצר אין `material` מפורש, נבחר חומר ברירת-מחדל לפי `type` (או `kind`),
case-insensitive. `COLOR_BY_TYPE` מיוצא מהמנוע.

| `type` | חומר ברירת-מחדל |
|---|---|
| `grill` / `bbq` | נירוסטה מוברשת כהה (`METAL_BRUSH #3a3d42`) |
| `fridge` / `freezer` / `ice_maker` | נירוסטה בהירה |
| `sink` / `faucet` | נירוסטה מוברשת |
| `cooktop` / `cooktop_gas` | זכוכית שחורה + אקצנט כחול-להבה (`SOLID #1c1d20 / #2a6df0`) |
| `oven` | מתכת כהה |
| `dishwasher` / `hood` | נירוסטה בהירה |
| `microwave` | כהה |
| `planter` | טרקוטה + ירוק (`SOLID #b5651d / #4a7c3f`) |
| `plant` | ירוק |
| ברירת-מחדל | נירוסטה בהירה |

ארונות משתמשים ב-`front`/`carcass` שלהם; משטח משתמש באבן שלו; אביזרים
צבועים לפי §3. `material` מפורש תמיד גובר.

## 6. צוקל (kickboard) ומשטח עבודה

- **צוקל:** כל ארון בסיס (`type:"base"` או `heightFrom<50` וגובה≤1100) מצויר עם
  צוקל שקוע בתחתית: גובה **120 מ״מ** (`VizEngine.KICK_H`), נסיגה של **55 מ״מ**
  (`VizEngine.KICK_INSET`) בצד החזית, כפס כהה/מט (`#2b2b2e`). ניתן לבטל עם
  `"kickboard": false`. גוף-הארון מתחיל מעל הצוקל, כך שהנסיגה נראית באמת.
- **משטח:** לוח מעל ריצת-הבסיס בגובה ~920 מ״מ (ברירת-מחדל), עובי 40 מ״מ,
  overhang 25 מ״מ, בחומר-אבן משלו (Dekton/Sensa → `MARBLE_VEIN`/`GRANITE_SPECKLE`).

## 7. טקסטורות פרוצדורליות (TextureKind)

תשע טקסטורות, בקנה-אחד עם `MATERIALS_LIBRARY.md` (אם קיים; אחרת אלה השמות
הקנוניים). כל מחולל מקבל `{base, accent, scale, size}` ומחזיר `<canvas>` שחוזר
על-עצמו (tiling). `KIND_DEFAULTS` נותן צבע-בסיס + `tileMm` (גודל-מונח אמיתי לכל
חזרה, כדי שהקנה-מידה ייראה נכון).

| Kind | טכניקה |
|---|---|
| `SOLID` | צבע אחיד + רעש עדין |
| `WOOD` | פסים מעוותי-דומיין (domain-warp) → סיבי-עץ + קווי-טבעת |
| `MARBLE_VEIN` | ורידים טורבולנטיים `pow(1−|sin(freq+turb)|,3)` |
| `GRANITE_SPECKLE` | רעש-רקע + נקודונים בהירים/כהים |
| `TERRAZZO` | שבבים אליפטיים אקראיים בפלטה |
| `TILE_GRID` | תאים עם שונות + קווי-רובה (grout) |
| `CONCRETE` | fbm מנומר עדין |
| `LINEN` | אריגה: חוטי שתי/ערב מתחלפים (אניזוטרופי) |
| `METAL_BRUSH` | פסים אניזוטרופיים (רעש חלק לאורך ציר אחד) + ברק אנכי |

הרעש (`hash2`/`vnoise`/`fbm`) דטרמיניסטי וטהור — בדיק ב-Node.

## 8. שכבת תכנון והסתרת קירות (בקרות UI)

- **שכבת תכנון** (`setLayer("design", on)`): מציג/מסתיר את הארונות + המשטח +
  המוצרים (התכנון). כיבוי → רואים את **החדר המדוד בלבד** (קירות, רצפה, תשתיות).
- **תשתיות** (`setLayer("infra", on)`): מציג/מסתיר את אביזרי-הקיר.
- **הסתרת קירות ידנית** (`setWallHidden(wallId, true)`): מסתיר קיר ספציפי לגמרי —
  צ׳קבוקס לכל קיר ("קיר 1 / קיר 2 / …"). זו הבקרה **הנדרשת** להצצה פנימה.
- **הסתר קירות קדמיים אוטומטית** (`setAutoHide(on)`, ברירת-מחדל דלוקה): מסתיר בכל
  פריים את הקירות שהנורמל-הפנימי שלהם פונה מהמצלמה (הקירות הקרובים החוסמים).
  קירות מצוירים דו-צדדית כדי שהאוטו-הייד יעבוד זהה ב-WebGL וב-2.5D.

הסתרת קיר **אינה** מסתירה את האביזרים שעליו (שלוט בהם דרך שכבת "תשתיות").

## 9. חוקי זיהוי התנגשות/התאמה (`detectClashes`)

המטרה שהגדיר Michael: **"נזהה בעיות בהתאמת מטבח לשטח"**. החוקים פשוטים ומתועדים:

1. **תשתית-קשיחה (`hard`)** — צינור מים/גז, קו-חשמל, חלון, דלת, הנמכת-תקרה —
   שגוף-הבדיקה שלה **חותך את גוף הארון** (חפיפת AABB תלת-ממדית) → התנגשות.
   *(לחלון/דלת עומק-בדיקה 400 מ״מ, כדי לתפוס ארון עליון שמותקן מולם.)*
2. **`floor_drain`** שטביעת-הרגל שלו חופפת לטביעת-רגל של **ארון בסיס** → התנגשות
   ("חוסם גישה לניקוז").
3. **אי-התאמה לשטח** — ארון שקופסתו חורגת ממתאר-החדר (מעבר לגבולות) → "לא נכנס".
4. **ניטרלי** — שקע/מפסק לעולם אינם מתנגשים (צפוי שיהיו מאחורי ארון בסיס).

כל התנגשות מסומנת ב**אדום** (tint אדום על גוף הארון והאביזר) ומופיעה ברשימת
"בעיות התאמה" עם נימוק בעברית. דוגמת-הדמו כוללת בכוונה 3 התנגשויות (גז↔ארון בסיס,
ניקוז↔ארון בסיס, חלון↔ארון עליון) וגם צינור-מים **מנותב נכון** שאינו מתנגש —
כדי להראות שהמנוע מבחין.

## 10. API

```js
// טהור / בדיק ב-Node:
VizEngine.TEXTURE_KINDS        // 9 שמות
VizEngine.KIND_HE, KIND_DEFAULTS, ACC_META, COLOR_BY_TYPE
VizEngine.noise.{hash2,vnoise,fbm}
VizEngine.M4.{ident,mul,perspective,lookAt,apply,invert}
VizEngine.buildScene(room)     // -> { faces, objects, walls, roomBounds, bounds, center, radius, roomHeight }
VizEngine.detectClashes(scene) // -> [ {cabinetId, accId, kind, reason} ]
VizEngine.resolveMat(ref, materials)

// דפדפן:
VizEngine.makeTexture(kind, {base,accent,scale,size}) // -> <canvas>
var viewer = VizEngine.createViewer(canvasEl, room, {
  forceCanvas, autoHide, theta, phi, radius, target, onHover
});
viewer.render(); viewer.resize();
viewer.setLayer("design"|"infra"|"structure", bool);
viewer.setWallHidden(wallId, bool);
viewer.setAutoHide(bool);
viewer.walls; viewer.clashes; viewer.scene; viewer.backend; // "webgl" | "canvas2.5d"
```

**אינטראקציה:** גרירת-עכבר/מגע = אורביט · גלגלת/צביטה = זום · ריחוף/נגיעה על ארון
מציג מידות במ״מ (`onHover`). UI ב-RTL עברית, לשון זכר. מקרא-חומרים + מונה-התנגשויות.

## 12. בנייה מחדש של ה-HTML

`viz/kitchen_viz.html` נבנה על-ידי הטבעת `src/viz_engine.js` בתוך `<script>` +

לעדכן: ערוך את `viz_engine.js` והרץ מחדש את סקריפט-הבנייה (מטביע את המנוע העדכני).
