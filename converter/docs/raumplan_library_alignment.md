# יישור ספריית Soline לספריית Raumplan המקורית

מסמך זה ממפה את 170 האלמנטים של Soline (`elements.json`) מול ספריית Raumplan/InnoDraw
המקורית, בונה ספרייה מיושרת (`elements_raumplan.json`), ומתעד את **השראת-עיצוב-הסמלים**
מ-Raumplan לסמלי Soline (הצעות ב-`symbols_raumplan.json`).

> כל השמות פוענחו מחדש מ-cp1255 (בייט `0xE0–0xFA` → `א–ת`). קבצי-הקטלוג בינאריים/ini
> מכילים גם מחרוזות-זבל (Windows-API, טוקני-סקריפט) — סוננו; נשמרו רק שמות-אלמנט עבריים אמיתיים.

## 2. היררכיית-הקטלוג של Raumplan (מבנה-הספרייה שאנו מחקים)

הקטלוג בנוי מ**קבוצות-על עם קידומת-אות** (מפתח-מיון) → תת-קטגוריה → משפחה. הקבוצות:

```
א.תחתון        ארונות תחתונים (גובה 89.5)          ← ריהוט-מטבח (מטריצות)
ב.עליון        ארונות עליונים
ג.גבוה         ארונות-גובה (185–240)
ה.המחשה        ★ קטלוג-הרינדור המונחה-שם: ★
               ├─ מבנה\נקודות אספקה   ← MEP (שקע/מפסק/מים/גז/ביוב/אוורור/תקשורת)
               ├─ מבנה                ← מבנה: קיר/עמוד/מדרגות/נישה/פתח/קיטום/כיפה
               ├─ דלתות               ← דלתות (סגורה/פתוחה/פנימה/החוצה/הזזה/מתכתית/משקוף)
               ├─ חלונות              ← חלונות (בלגי/עגול/גלילה/בשיפוע/בודד/כפול)
               ├─ ברזים               ← ברזים (אמבט/מטבח/מקלחת)
               ├─ כיורים · לאמבטיה    ← כלים סניטריים
               ├─ תאורה               ← גופי-תאורה (ספוט/תליה/קיר/פלורסנט)
               ├─ מכשירי-חשמל\יצרנים  ← AEG/BOSCH/MIELE/NEFF/GAGGENAU/Blanco
               ├─ מכשירי-חשמל\קולטים  ← מנדפים/קולטי-אדים
               ├─ אביזרי-נישה · מערכות-ישיבה · צמחים · דקורציות · שולחנות · ריהוט
ו.מבנה         תג-הדיסציפלינה של קבוצת "נקודות אספקה" (ראה §3)
ז.מכשירים      מכשירי-חשמל
```

> **המסקנה למבנה-הספרייה שלנו:** ספריית Soline צריכה שני צירים — (א) **דיסציפלינה**
> (חשמל/מים/גז/מיזוג/תקשורת/מבנה) כמו `נקודות אספקה`, ו-(ב) **תצוגה** (חזית מול מבט-על).
> זה בדיוק מה שקטגוריות ה-`category` שלנו כבר עושות, ולכן היישור טבעי.

## 3. תגלית-המפתח — שלושת וריאנטי-התצוגה של כל סמל-MEP

בקטלוג `נקודות אספקה` **כל נקודה קיימת ב-3 קובצי-KDT** לפי תצוגה וכיוון-מימוד:

| KDT | טוקן-קטגוריה | תפקיד |
|---|---|---|
| **`SUPP_FR`** | `ו.מבנה \ נקודות אספקה \ מבט חזית` | **סמל-חזית** (אלֶוַוציה) — נראה על מראה-הקיר |
| **`SUPP_UPL`** | `… \ מבט על \ קו מידה משמאל` | **סמל-תוכנית** (מבט-על) + קו-מידה **משמאל** |
| **`SUPP_UPR`** | `… \ מבט על \ קו מידה מימין` | **סמל-תוכנית** (מבט-על) + קו-מידה **מימין** |

כלומר Raumplan מציירת סוקט אחרת בחתך-חזית מאשר בתוכנית-מדידה, ומספקת שתי גרסאות-מראה
(שמאל/ימין) כדי שקו-המידה לאורך-הקיר תמיד ייצא לכיוון הנכון. **קטגוריה `מבט על` היא
בדיוק סמלי תוכנית-החשמל הישראלית** — וזו הספרייה שממנה נגזרים הסמלים המקצועיים.

**הרכב `מבט על` (סמלי-התוכנית האמיתיים, 40+):**
שקע · שקע כח · שקע מוגן · מפסק · מפסק כפל · מ.מחליף · מאור קיר · פלורסנט · גוף שקוע ·
בתקרה · טלפון · תקשורת · TV · LCD · NET · מ_מחשב · אזעקה · בוילר · גוף חמום · תריסחשמל ·
פ_פעמון · ר_רמקול · גז · ביוב · נ.מים חמים · נ.מים קרים · ברז חמים קרים · מוגן מים.
פרימיטיבים-עזר: `קו מרוסק`/`קו קשתי` (קווי-קישור אביזר↔לוח), `מקרא חשמל`/`מקרא1`/`מקרא2`
(מקרא), `ריבוע`/`עיגול`, מספרים `1/2/3` (מספור-מעגלים).

> **החלטה שמשפיעה על שאר הסוכנים:** מייצא-ה-DXF (`export_dxf_pro.js`) ומציג-ה-3D צריכים
> **שתי ספריות-סמלים** — `symbol_plan` (מבט-על) ו-`symbol_elev` (חזית) — ולבחור לפי סוג-הפלט.
> מקבילה כבר קיימת ב-`DXF_2D_METHOD.md` (`BLOCKS_2D`) ל-3D (`export_dxf3d.js`).

### 4.2 מה חסר ב-Raumplan (37 האלמנטים ה"חדשים" שלנו)

## 5. השראת-עיצוב-סמלים (`symbols_raumplan.json` — חדש)

מ-Raumplan נלמד **דקדוק-סמלים** אחיד. הצעות-עיצוב מנורמלות ל-`[1000,1000]` (כמו `symbols.json`),
במוסכמת "קו-קיר אופקי ב-`y=228`, גוף-הסמל יורד למרכז" — תואם ל-`export_dxf_pro.js`.
28 סמלים מרכזיים הוצעו. עקרונות-העיצוב שאומצו:

| משפחה | דקדוק-Raumplan שאומץ | סמל שלנו |
|---|---|---|
| **שקעים** | חצי-מעגל צמוד לקו-הקיר; **מספר חישורים רדיאליים = מספר תקעים** (מוסכמת ת"י) | Single/Duplex/Triple: 1/2/3 חישורים |
| **שקע כח / מוגן** | חצי-מעגל + פס-אופקי (כח) / קשת-כפולה (מוגן-מים) | 3-Phase, IP44 |
| **מפסקים** | עיגול-קטן על הקיר + זרוע/ות באלכסון; מחליף = זרוע עם סימן-חילוף | Single/Double/Triple/Two-Way |
| **מים** | עיגול על מוט-הזנה: חם=חצי-מלא, קר=קו-אופקי, **משולב=צלב** | Hot/Cold/Combined |
| **גז** | **משושה** + אות ג/G על מוט-הזנה | Gas Point |
| **ביוב** | עיגול עם **משולש פונה-מטה** (כיוון-זרימה) | Sewage |
| **תקשורת** | **משולש** = דיסציפלינת-תקשורת; דאטה = קו-בסיס כפול; TV = עיגול+אנטנה(V) | Phone/Data/TV |
| **רמקול** | עיגול + גלי-קול (קשתות-צד) | Speaker |
| **תאורה** | מאור-קיר = חצי-עיגול+קרניים · תקרה = עיגול+X · שקוע = עיגול+נקודה · פלורסנט = מלבן-מוארך | Wall/Ceiling/Recessed/LED |
| **אוורור** | ריבוע עם 2 אלכסונים (שבכה) | Vent Grille |
| **בוילר** | עיגול עם סליל-חימום | Boiler |
| **פעמון/אזעקה** | פעמון = עיגול+צלב · אזעקה = משולש-אזהרה + סימן-קריאה | Doorbell/Alarm |

**הכי כדאי לאמץ מ-Raumplan (המלצות-עדיפות):**
1. **חוק החישורים** — מספר תקעי-שקע = מספר קווים רדיאליים בחצי-המעגל. מיידי, מקצועי, מוכר לחשמלאי.
2. **שתי תצוגות** — לייצר לכל אביזר-MEP `symbol_plan` (מבט-על, למדידה/DXF-2D) ו-`symbol_elev`
   (חזית, לרינדור/3D). זו התגלית מ-§3 והיא הכי משמעותית ארכיטקטונית.
3. **צורה = דיסציפלינה** — משולש→תקשורת, משושה→גז, עיגול+צלב→מים-משולב, ריבוע-אלכסונים→אוורור.
   מאפשר זיהוי-דיסציפלינה במבט, גם ללא צבע.
4. **גרסאות-מראה שמאל/ימין** (SUPP_UPL/UPR) — לקו-מידה-לאורך-הקיר; מיושם כבר חלקית ב-DXF-2D.

## 7. סייג-דיוק

- שמות-Raumplan רבים הם **וריאנטים גנריים** (`שקע`, `מפסק`, `קיר`) ולא פריט-לכל-מכשיר; לכן
  `close`/`family` נפוצים ביציאות-מכשירים. זה **נכון סמנטית** — Raumplan באמת לא מבחינה בין
  "שקע לתנור" ל"שקע למדיח"; ההבחנה היא תכונת-Soline (`connection_spec`), לא סמל נפרד.
- הגאומטריה הבינארית המדויקת של כל `.kdt` (QUADER×101, ZYLINDER×65 ב-`SUPP_FR.KDT`) **לא**
  פוענחה פרימיטיב-פרימיטיב; דקדוק-הסמלים נגזר משמות-הקטלוג + מוסכמות-התצוגה + מוסכמות-ת"י.
