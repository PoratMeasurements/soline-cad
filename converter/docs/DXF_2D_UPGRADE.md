# שדרוג מייצא ה-DXF-2D — לתכנית-מדידה ברמת הגשה

עודכן: 2026-08-18 · קובץ: `src/export_dxf2d.js` (נכתב מחדש) · חיווט: `soline_convert.js`

## מה השתנה ולמה

הפלט הקודם של תכנית ה-2D (שנוצר ע"י `exportDXF2DPro` שב-`export_dxf_pro.js`) היה
"ברמה מאוד נמוכה" בעיני המודד: על נתוני-`.sol` אמיתיים **כל 11 האלמנטים קרסו לסמל
"ControlBox" גנרי אחד** על שכבת `Electrical` אחת (כי שמות-האלמנטים בעברית לא התאימו
ל-8 ה-regex-ים באנגלית), **בלי זהות לכל אלמנט, בלי כותרת, בלי מידות-על, בלי שם-חדר/מספר-אזור,
מקרא שבור עם רשומה אחת, וקשתות-דלת שנמתחו בסקאלה לא-אחידה** (גאומטריה פסולה).

`export_dxf2d.js` נכתב מחדש כמייצא **תכנית-מדידה (DR1) מקצועית** עצמאי (קורא רק את המודל
המשותף דרך `placement.js` + `elements.json`), ולא נוגע במייצאי ה-3D/ORDX/PDP/HTML.
`soline_convert.js` הופנה לקרוא ל-`exportDXF2DPro` (alias) מהמודול החדש. שאר הפורמטים
ללא שינוי. הפלט מאומת ע"י ה-self-test של המודול ו-ע"י המאמת הקיים של הממיר.

## מה הפלט מייצר עכשיו

- **קירות poché**: שתי פאות (פנים `Walls` + חוץ `Ext_Wall`) עם מילוי `SOLID` ביניהן
  (`Walls_Fill`); כל קיר מוארך בחצי-עובי בשני הקצוות כך שהפינות **נסגרות נקי** (בלי
  פערים/קווים מצטלבים). זיהוי פנים/חוץ לפי הכיוון ביחס למרכז-החדר.
- **מנוע-מימוד ידני** (אין ישויות `DIMENSION`, כמו בייחוС): כל מידה = 2 קווי-הארכה +
  קו-מידה + 2 ראשי-חץ `SOLID` + `TEXT` בס"מ, מיושרת ותמיד קריאה. מיוצרות: אורך לכל קיר
  (`DIM`), תיבת-היקף החדר (`Dim_overall`), רוחב כל פתח (`DIM`), ומרחק כל אלמנט לאורך
  הקיר מהתחלת-הקיר (`Dim_{discipline}`).
- **סמל מזוהה לכל אלמנט**, מסווג לדיסציפלינה האמיתית שלו (שקע / שקע-מרובע / מפסק / גז /
  מים / ניקוז / מיזוג / תאורה / תקשורת / חיישן / לוח-חשמל / קונסטרוקציה / כללי) על שכבה
  צבועה משלו — כל אחד עם **שם עברי** (שכבת `Text`) ו**גובה-התקנה `H nn`** (שכבת-הדיסציפלינה).
- **דלתות/חלונות** בגאומטריה אמיתית לפי הרוחב הנמדד: דלת = כנף + קשת-פתיחה ברדיוС=הרוחב;
  חלון = מסגרת לרוחב הקיר + קו-זיגוג. **בלי מתיחת בלוק-יחידה** (שפגמה בקשתות).
- **מקרא אוטומטי** (`Text_Legend`): סמל + שם-קטגוריה עברי לכל דיסציפלינה שמופיעה בשרטוט.
- **בלוק-כותרת** (`Text_Title` + מסגרת `Frame`): פרויקט / לקוח / כתובת / מודד / תאריך /
  קנ"מ, **חץ-צפון**, ו**סרגל-קנה-מידה** גרפי. כן **שם-החדר + מספר-אזור `P.1`** במרכז.
- **DXF R12 ASCII נקי**: HEADER מלא (`$EXTMIN/$EXTMAX` מחושבים, `$DWGCODEPAGE ansi_1255`,
  `$LTSCALE`), VPORT, שני LTYPE (CONTINUOUS+HIDDEN), STYLE→ARIAL.TTF, handle לכל ישות,
  SECTION/ENDSEC מאוזנים + EOF. עברית כ-`\U+XXXX` (הקובץ 7-bit ASCII טהור על הדיסק).

## מימוד — אנטומיה (5 ישויות למידה)

`2× LINE (הארכה) + 1× LINE (קו-מידה) + 2× SOLID (חצים) + 1× TEXT (ערך בס"מ)`.
גובה-הטקסט נגזר מקנה-המידה של השרטוט (`~diag/70`, מוגבל ל-60..200). ערך = `round(mm/10,1)`.
