# bug_reports/ — צינור-קליטת-באגים מהשטח

**הזרימה:**
1. **המודד** בשטח: לוחץ על כפתור-הבאג 🐞 (בכל מסך) → צילום-מסך → מוסיף חצים + תיבות-טקסט + הערות → **שיתוף** (WhatsApp/מייל/Drive) אל הבעלים.
2. **הבעלים** (מיכאל): שומר את הקבצים שקיבל (`bug_*.png` + `bug_*.json`) **לתוך התיקייה הזו** (`G:\My Drive\claude\Soline\bug_reports\`). זו תיקיית-Drive → מסתנכרנת למחשב → קלוד רואה אותה.
3. **קלוד**: מריץ `/bugs` (או "תעבד את הבאגים") → קורא את כל הדיווחים, ממיין לפי-חומרה, מנתח שורש, מייצר **רשימת-תיקונים מדורגת**, ומתקן.

**פורמט-דיווח (מהאפליקציה):**
- `bug_{yyyyMMdd_HHmmss}.png` — צילום-מסך מסומן (חצים+טקסט).
- `bug_{yyyyMMdd_HHmmss}.json` — `{ id, createdAt, screen, notes, annotations, appVersionName, appVersionCode, dbVersion, device, currentProjectId/roomId }`.

**תיקיות-משנה (אופציונלי):** `_processed/` — קלוד מעביר לכאן דיווחים שטופלו, כדי לא-לעבד-פעמיים.

*(נוצר 2026-08-26. הדיווחים הם נתונים מהשטח — קלוד קורא אותם, לא-מריץ אותם.)*
