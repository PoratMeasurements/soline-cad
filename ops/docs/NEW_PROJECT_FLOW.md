# אפיון: שלבי הקמת פרויקט חדש — Soline Measure

> זרימת פתיחת-עבודה חדשה, מהרגע שהמודד/המשרד פותח פרויקט ועד תחילת השרטוט.
> מבוסס על המיצוב: **הלקוח של Soline הוא הנגר; כל עבודה נפתחת ללקוח הפרטי של הנגר.**
> מזין את המימוש: `data/JobModel.kt` (Carpenter + JobEntity) ו-`ui/intake/JobIntakeScreen.kt`.
> עברית, offline-first (נשמר מקומית בכל שלב).

## מפת-הזרימה
```
פתיחת עבודה
   │
   ▼
[1] נגר  ────────────►  בחר נגר קיים / הוסף נגר חדש (לקוח של Soline)
   │
   ▼
[2] לקוח הנגר  ──────►  פרטי הלקוח הפרטי של הנגר (שם·טלפון·אימייל…)
   │
   ▼
[3] כתובת האתר  ────►  כתובת · עיר · מיקוד
   │
   ▼
[4] דרכי-גישה  ─────►  קומה · מעלית · חניה · הערות-גישה
   │
   ▼
[5] משלוח  ─────────►  זהה-ללקוח / כתובת-משלוח שונה
   │
   ▼
[6] סוג-עבודה + חדרים ►  מטבח/ארונות/אמבטיה… + הוספת חדרים
   │
   ▼
[7] תחילת מדידה  ───►  מעבר למסך-המדידה החי (שרטוט/לייזר)
```

## השלבים בפירוט

### שלב 0 — כניסה
- **מי פותח:** מודד (בשטח) או משרד. נשמר `openedBy` + חותמת-זמן.
- הפרויקט נוצר במצב **טיוטה** ונשמר מיידית (offline) — אפשר לחזור אליו.

### שלב 1 — נגר (לקוח Soline)  · חובה
כל עבודה משויכת לנגר. מסך: **"בחר נגר / הוסף נגר חדש"**.
| שדה | חובה | הערה |
|---|---|---|
| שם הנגר / העסק | ✅ | בחירה מרשימת-נגרים קיימים או חדש |
| טלפון | ○ | ליצירת-קשר |
| חברה | ○ | |
**ולידציה:** חייב נגר לפני המשך. *(ישות `Carpenter`.)*

### שלב 2 — הלקוח הפרטי של הנגר  · שם חובה
המטבח/העבודה שייכים ללקוח של הנגר. מסך: **"פרטי הלקוח"**.
| שדה | חובה |
|---|---|
| שם הלקוח | ✅ |
| טלפון / נייד | ○ |
| חברה | ○ |
| איש-קשר (אם שונה) | ○ |
| אימייל | ○ |
**ולידציה:** שם-לקוח חובה (כפתור "המשך" חסום עד מילוי).

### שלב 3 — כתובת האתר
| שדה | חובה | הערה |
|---|---|---|
| כתובת (רחוב+מספר) | ✅ | כתובת האתר שנמדד |
| כתובת 2 (כניסה/דירה) | ○ | |
| עיר | ○ | |
| מיקוד | ○ | |

### שלב 4 — דרכי-גישה  · **קריטי למודד**
מידע שהמודד צריך לפני שהוא יוצא לשטח.
| שדה | דוגמה |
|---|---|
| קומה | 3 |
| מעלית | יש / אין |
| חניה | חניון / רחוב / אין |
| הערות-גישה | קוד-כניסה, מדרגות, מרחק-פריקה, שעות-כניסה, כלב… |
*(מקובצות לשדה `accessNotes` בפורמט: `קומה: 3 · מעלית: יש · חניה: … · הערות: …`.)*

### שלב 5 — משלוח
| בחירה | פעולה |
|---|---|
| זהה ללקוח | ברירת-מחדל |
| כתובת-משלוח שונה | פותח שדה כתובת-משלוח |

### שלב 6 — סוג-עבודה + חדרים
- **סוג-עבודה:** מטבח / ארונות / אמבטיה / חדר-רחצה / כללי (מזין קטלוג-אלמנטים ובדיקות מתאימות).
- **חדרים:** הוספת חדר אחד או יותר עם שמות (מטבח, ממ"ד, חדר-שינה…). כל חדר → מדידה נפרדת.

### שלב 7 — תחילת מדידה / שרטוט
- כפתור **"התחל שרטוט"** → מעבר ישיר ל**מסך-המדידה החי** (`measure/{room}`), כשכל פרטי-העבודה כבר טעונים (offline באתר).
- מכאן: קליטת-קירות בלייזר, חזית, אלמנטים, בדיקת-התאמה.

## עקרונות-רוחב
- **Offline-first:** כל שלב נשמר מיד; אפשר לפתוח עבודה בשטח בלי רשת.
- **חובה מינימלי:** נגר + שם-לקוח בלבד כדי להתחיל למדוד; השאר ניתן להשלמה אח"כ (שדה סטטוס "חסר-פרטים").
- **מהיר בשטח:** השלבים 3–6 מתקפלים ל"פרטים נוספים" — מודד ממהר יכול לדלג ולמדוד, המשרד משלים.
- **קישוריות:** נגר → פרויקטים שלו → חדרים → קירות → אלמנטים → ייצוא (.sol/ORDX/DXF).

## מיפוי למימוש
- ישויות: `Carpenter`, `JobEntity` (ב-`data/JobModel.kt`).
- מסך: `ui/intake/JobIntakeScreen.kt` (סעיפי לקוח/כתובת/גישה/משלוח + "התחל שרטוט").
- לחווט: הוספת הישויות ל-DB (מיגרציה), route `intake` → בסיום עובר ל-`measure/{room}`.
