# מפת מסכים — אפליקציית המדידה CVSM (Cabinet Vision Smart Measure)

תיעוד שיטתי של כל מסכי אפליקציית המדידה על הטאבלט (Samsung, serial `R5GL60ZDP5N`), חבילה `com.roommeasure.app`, גרסה **v5.2.0**. רזולוציה 1920×1200 landscape, ממשק עברי RTL, ערכת נושא "כהה במיוחד (שחור)", שפת עיצוב "Elsop".

הצילומים בתיקייה `docs/screenshots/`. הפרויקט לדוגמה: **לטכנטכ** (חדר אחד — "ניסיון", 5 קירות).

---

## סקירה כללית — היררכיית ניווט

```
מסך בית (HomeScreen) — פרויקטים
  ├─ סרגל עליון: בלוטות' · הגדרות · ארכיון · מידע · מתג רשימה/גריד
  ├─ FAB + → דיאלוג "צור פרויקט"
  └─ כרטיס פרויקט → רשימת חדרים (RoomListScreen)
        ├─ FAB + → דיאלוג "צור חדר"
        ├─ שיתוף → דיאלוג "ייצא פרויקט"
        └─ כרטיס חדר → מצב תכנון (PlanMode)
              ├─ כרטיסיות: הוסף · ערוך · מצב חזית · 3D · מידת CAD · ארונות
              ├─ ערוך → בחירת קיר → סרגל עריכת קיר → דיאלוג "בחר נקודה"
              ├─ מצב חזית → בחירת קיר → מצב חזית (ElevationMode)
              │     └─ תפריט +: צלם תמונה · הערה · הוסף אביזר · הוסף ארון
              │           └─ דיאלוג "הוסף אביזר" (+ רשימת סוגי אביזרים)
              └─ 3D → תצוגה תלת-ממדית (Preview3D)
```

## הערות
- **חיבור:** במהלך התיעוד המכשיר עבר בין "מחובר" ל"מנותק · נסה שוב" — מחוון החיבור מוצג בפינה הימנית-תחתונה של מסכי התכנון/חזית ובבית.
- **בטיחות:** לא בוצעו מחיקות, לא שונו הגדרות מהותיות ולא בוצעה מדידה; כל הדיאלוגים בוטלו. תאריך העדכון של הפרויקט השתנה (18:02 → 22:16) עקב פתיחת החדר בלבד.
- **שני עיצובים:** האפליקציה תומכת ב"עיצוב קלאסי" וב"עיצוב Elsop" (הנוכחי). התיעוד נעשה בעיצוב Elsop.
