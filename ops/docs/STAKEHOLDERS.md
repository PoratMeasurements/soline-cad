# ניתוח בעלי עניין — מה חשוב לכל אחד ואיזה פיצ'ר פותר לו

לכל תפקיד: המשקפיים שלו, מה הכי חשוב לו, הכאב, והפיצ'ר במערכת שפותר את זה.
זה מחבר את האסטרטגיה (`STRATEGY.md`) למוצר (`SPEC.md`) — כל פיצ'ר נולד מכאב אמיתי של מישהו.

> בחברה קטנה תפקידים מתאחדים (המנכ"ל = גם היועץ, המזכירה = גם מנהלת התפעול). המשקפיים עדיין שונים — לכן מפרידים.

---

## 1. יועץ פיננסי (CFO)
**מה חשוב לו:** רווחיות אמיתית לעבודה, שוליים, תזרים, מספיקות התמחור, וחובות פתוחים.
**הכאב:** "אני לא יודע כמה באמת עולה לי עבודה, כמה כסף תקוע אצל נגרים, ואם אני מתמחר בהפסד."
**הפיצ'רים שפותרים:**
- **מנוע מדדים נסתר** → עלות אמיתית (מודד+נסיעה+משרד) לכל עבודה.
- **דאשבורד כספי** → הכנסה/עלות/רווח, שוליים, תרומה לעבודה.
- **גבייה + גיל חוב + תנאי אשראי** (פער נוכחי) → שליטה בתזרים וחסימת חייבים.
- **לולאת reprice** (הערכה↔בפועל) → זיהוי עבודות בתת-תמחור.
> הפיצ'ר-המפתח: **מנוע המדדים + דאשבורד כספי.** בלעדיו הוא עיוור.

## 2. יועץ עסקי (Growth)
**מה חשוב לו:** צמיחה, שימור נגרים, LTV מול CAC, בידול/חפיר, ARPU.
**הכאב:** "איך גדלים בלי לאבד נגרים, ואיך מבדילים אותנו ממתחרה זול."
**הפיצ'רים שפותרים:**
- **פורטל נגר + שקיפות + SLA** → מנוע שימור (retention).
- **מדרגות נפח/ריטיינר** → נעילת נגרים גדולים (switching cost).
- **upsell בקטלוג** (3D/PDP/רשימות חיתוך) → ARPU גבוה על אותה מדידה.
- **לולאת דיוק הדאטה** → חפיר שמתחזק עם הזמן.
- **דאשבורד: נגרים מובילים + נתח-ארנק + שימור** → החלטות צמיחה מונחות-דאטה.
> הפיצ'ר-המפתח: **הפורטל כמנוע שימור + מדדי הנגרים בדאשבורד.**

## 3. מנהל תפעול (COO)
**מה חשוב לו:** תפוקה, ניצולת מודד, שכלום לא נופל, עמידה בזמנים, מינימום חזרות.
**הכאב:** "עבודות נופלות בין הכיסאות, המודד נוסע חצי יום, ואנחנו חוזרים לשטח."
**הפיצ'רים שפותרים:**
- **קונסולת מתאם** (תור + לוח כל העבודות + סטטוסים) → כלום לא נופל.
- **שיבוץ גאוגרפי / אופטימיזציית מסלול** (פער נוכחי) → ניצולת מודד.
- **צ'קליסט שלמות שטח + בדיקת DR1 בזמן אמת** → מניעת חזרות.
- **לו״ז + הערכת זמן** → שיבוץ מדויק ליום.
- **דאשבורד תפעולי** (משפך, SLA, שיעור חזרות, עומס מודד) + **התראות פיגור**.
> הפיצ'ר-המפתח: **קונסולת המתאם + שיבוץ גאוגרפי + צ'קליסט השטח.**

## 4. מזכירה / רכזת משרד
**מה חשוב לה:** לקלוט הזמנות בלי בלגן, לתאם כניסה לאתר, לא לשכוח, פחות הקלדה, פחות טלפונים.
**הכאב:** "וואטסאפ ואקסל ופתקים; אני רודפת אחרי לקוחות לתיאום, ומקלידה הכול מחדש."
**הפיצ'רים שפותרים:**
- **תור הזמנות נכנסות** → סדר במקום כאוס.
- **טופס הזמנה שהנגר ממלא** → אפס הקלדה כפולה.
- **תיאום כניסה + חיוג/ניווט בלחיצה** → תיאום מהיר.
- **התראות אוטומטיות ללקוח (וואטסאפ/SMS)** (פער נוכחי) → פחות טלפונים.
- **הזמנה חוזרת/תבניות** → פחות עבודה חוזרת.
- **יומן סטטוס** → לא שוכחים כלום.
> הפיצ'ר-המפתח: **תור ההזמנות + התראות אוטומטיות ללקוח.**

## 5. נגר (הלקוח)
**מה חשוב לו:** להזמין מהר, לדעת מה קורה, לקבל קבצים תקינים בזמן, מחיר צפוי.
**הכאב:** "שלחתי בקשה ונעלמתי; אני לא יודע מתי מוכן; לפעמים הקבצים לא מדויקים."
**הפיצ'רים שפותרים:**
- **פורטל נגר** (טופס + מעקב סטטוס חי + הורדת קבצים).
- **הצעת מחיר שקופה + אישור** → אין הפתעות.
- **התראות** (התקבלה / נקבע מועד / מוכן).
- **SLA/זמן אספקה מוצג** → ציפייה ברורה.
- **הזמנה חוזרת בקליק + בקשת שינויים מובנית.**
> הפיצ'ר-המפתח: **מעקב סטטוס חי + הורדת הקבצים + התראות.**

## 6. מודד
**מה חשוב לו:** לדעת מה למדוד היום, לקלוט מהר, לעבוד בלי רשת, לא לחזור לשטח.
**הכאב:** "לא ברור לי איזו עבודה, אין קליטה באתר, ולפעמים שוכח לצלם משהו וחוזר."
**הפיצ'רים שפותרים:**
- **"העבודות שלי היום" + ניווט + זמן משוער.**
- **קליטה offline + DISTO** → מהיר ואמין בשטח.
- **צ'קליסט שלמות** → מגן עליו מחזרה מיותרת.
- **פרטי גישה + איש קשר** (חיוג/ניווט) → פחות תקלות באתר.
- **כפתורי מנוע פשוטים** (יצאתי/הגעתי/סיימתי) → חיכוך מינימלי.
> הפיצ'ר-המפתח: **מסך "העבודות שלי" offline + הצ'קליסט.**

## 7. מנכ"ל
**מה חשוב לו:** התמונה הגדולה — רווחיות, צמיחה, כיוון אסטרטגי, סיכונים, בריאות העסק.
**הכאב:** "אני לא רואה איפה העסק עומד, לאן הוא הולך, ואיפה הסיכונים."
**הפיצ'רים שפותרים:**
- **דאשבורד ניהולי + KPI** (North Star + עץ מדדים).
- **מנוע מדדים** → רווחיות אמיתית ברמת החברה.
- **מדדי צמיחה/שימור/חפיר** → כיוון אסטרטגי.
- **קיבולת מול ביקוש** → החלטות גיוס/הרחבה.
- **מפת סיכונים / ניטור ריכוזיות** → הגנה.
> הפיצ'ר-המפתח: **הדאשבורד הניהולי כמסך בית — חדר הבקרה.**

| תפקיד | מה הכי חשוב | הפיצ'ר שפותר |

| יועץ פיננסי | רווחיות ותזרים | מנוע מדדים + דאשבורד כספי + גבייה |
| יועץ עסקי | שימור וצמיחה | פורטל כמנוע שימור + מדדי נגרים + upsell |
| מנהל תפעול | ניצולת ומינימום חזרות | קונסולת מתאם + שיבוץ גאוגרפי + צ'קליסט |

| מנכ"ל | תמונה גדולה וסיכונים | דאשבורד ניהולי + KPI |

## מה זה מלמד על סדר הבנייה
שלושה פיצ'רים מופיעים אצל כמה בעלי עניין בו-זמנית — אלה בעלי המינוף הגבוה ביותר:
1. **מנוע מדדים + דאשבורד** (פיננסי + מנכ"ל + תפעול) — לראות אמת.
2. **צ'קליסט שטח** (תפעול + מודד + פיננסי דרך מניעת עלות) — למנוע חזרות.
3. **התראות אוטומטיות** (מזכירה + נגר) — לשחרר את המשרד ולרצות את הלקוח.
> אלה משלימים את המלצות ה-ROI ב-`OWNER_ANALYSIS.md` ו-`STRATEGY.md`.
