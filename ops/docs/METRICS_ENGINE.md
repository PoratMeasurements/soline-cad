# מנוע מדדים נסתר (Metrics Engine)

שכבה **חוצת־תהליך** שרצה ברקע ואוספת אוטומטית זמן ומרחק בכל שלב.
**נסתר** = נאסף פסיבית, בלי שהמשתמש "מפעיל פיצ׳ר". מוצג רק ל**מתאם/מנהל**, לעולם לא לנגר.
המטרה: לדעת את ה**עלות האמיתית** של כל עבודה, את ה**רווחיות**, ולשפר את **הערכת הזמן** לעתיד.

## מה המנוע מודד
| מדד | מה זה | איך נמדד (נסתר) | שלב |
|---|---|---|---|
| **זמן עבודת משרד** | דקות שהמתאם השקיע בעבודה | אוטומטי — סכום משך השהייה בשלבים שבאחריות המשרד (`accepted`/`assessment`/`review`/`delivered`) מתוך חותמות הזמן ב-`job.history`; + טיימר ידני אופציונלי לפעולה ממוקדת | לאורך התהליך |
| **זמן נסיעת מודד** | דקות מהיציאה עד ההגעה (הלוך+חזור) | GPS בטלפון: אירועי `depart → arrive` ובחזרה `return`; או geofence אוטומטי סביב האתר | שטח |
| **זמן מדידה** | דקות מדידה בפועל באתר | חותמות `measure_start → measure_end` (משתלב בטופס הקליטה הקיים) | שטח |
| **ק״מ נסיעה** | מרחק שהמודד נסע | אורך מסלול ה-GPS (סכום Haversine בין נקודות), או מרחק מחושב מוצא↔אתר ×2 | שטח |

## למה זה "נסתר"
- **המשרד**: לא עושה כלום — הזמן מחושב לבד מחותמות מעברי הסטטוס.
- **המודד**: חיכוך מינימלי — כמה טאפים ("יצאתי", "הגעתי", "סיימתי") או GPS אוטומטי ברקע. הוא לא רואה סכומים/עלויות.
- **הנגר**: לא נחשף אליו בכלל.

## מה זה מפעיל
1. **עלות אמיתית לעבודה** = זמן×תעריף שעה + ק״מ×תעריף נסיעה.
2. **רווחיות** = מחיר שנגבה − עלות אמיתית.
3. **יעילות מודדים** = זמן/ק״מ ממוצע לפי סוג עבודה ואזור.
4. **לולאת שיפור הערכה** ⭑ — הזמן שנמדד בפועל מוזרם בחזרה ל**שלב הבירור** (`assessment`) ומדייק את הערכת הזמן לעבודות דומות בעתיד. ככל שנצבור דאטה, ההערכה נעשית חכמה יותר.

## מודל נתונים
```
metrics (store, keyed by jobId):
  jobId
  office:   { minutes }                       // אוטומטי מחותמות job.history
  travel:   { minutesOut, minutesBack, km }   // GPS
  measure:  { minutes }                       // חותמות באתר
  estimate: { estMinutes, estKm }             // משלב הבירור (assessment)
  events[]: { type:'depart'|'arrive'|'measure_start'|'measure_end'|'return',
              at, lat, lng }
  // נגזרים בזמן דו״ח: laborCost, travelCost, totalCost, margin, estVsActual
```
- `office.minutes` מחושב לבד: לכל שלב־משרד, `leftAt − enteredAt` מתוך `history`.
- `travel.km` מחושב מרצף נקודות ה-GPS (Haversine), עם נפילה למרחק כתובות אם אין GPS.

## מנגנון איסוף באפליקציה
- **מסך המודד** מקבל אירועים פסיביים: פתיחת ניווט/יציאה = `depart`, geofence/טאפ "הגעתי" = `arrive`, תחילת קליטה = `measure_start`, שמירה = `measure_end`, "סיימתי" = `return`. כל אירוע חותם זמן + מיקום GPS.
- **זמן משרד** נצבר אוטומטית ברקע בכל מעבר סטטוס — אפס פעולה.
- הכול offline-first: האירועים נשמרים מקומית ומסתנכרנים כשיש רשת.

## הרשאות — רק האדמין הראשי
- **מנהל (אדמין ראשי)**: **היחיד** שרואה את המנוע — זמנים, ק״מ, עלות, רווחיות, מגמות.
- **מתאם**: ❌ לא רואה. (תורם זמן־משרד אוטומטית ברקע, בלי גישה לנתונים.)
- **מודד**: ❌ לא רואה. תורם דאטה (GPS/זמנים), לא רואה סכומים.
- **נגר**: ❌ אף פעם.

> המנוע נסתר לחלוטין מכולם חוץ מהאדמין הראשי. זו נקודת השליטה של Michael על עלות ורווחיות.
