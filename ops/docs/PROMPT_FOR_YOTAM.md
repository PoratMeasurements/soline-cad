לפני שנתחיל, קרא בבקשה את הקבצים האלה כדי להתיישר עם כל מה שכבר נעשה:
1. `soline-ops-app/docs/COLLABORATION.md` ← קרא ראשון (מסביר הכול)
2. `soline-ops-app/STATUS.md` ← מקור-האמת + אינדקס כל המסמכים
3. `soline-ops-app/docs/Soline_Yotam.html` ← המסמך המרכזי (חזון + מוצר)

הקשר חשוב: Soline היא חברת-בת של **פורת מדידות**. פורת מודדת **שיש** למפעלי-שיש; סוליין מודדת **ארונות לנגרים — לפני השיש**. הן משלימות. מעבר למדידה אנחנו בונים פלטפורמת עיצוב+מדידה+ייצור סביב פורמט קנייני `.sol`.

כללי עבודה (חשוב לשמירה על סנכרון מול מיכאל):
- כל עדכון מהותי — כתוב אותו חזרה לקבצים ב-`soline-ops-app/docs/`, **ועדכן את `soline-ops-app/STATUS.md`**.
- אל תערוך קובץ שמיכאל עובד עליו במקביל — תיאום דרך `soline-ops-app/inbox/` או דרך מיכאל.
