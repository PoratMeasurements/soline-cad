# דאשבורד ניהולי + KPI (אדמין)

מסך הבית של ה**אדמין הראשי** — חדר הבקרה של Soline. מנקז את כל הדאטה של הפלטפורמה:
תפעול (עבודות/שלבים), כספים (מק״טים→הכנסה), עלות ורווחיות (מנוע נסתר), ויעילות שטח.
**אדמין בלבד.** (אופציה לאישורך: תת־תצוגה תפעולית ללא כספים למתאם — כברירת מחדל לא.)

מקורות דאטה: `jobs` (שלבים + חותמות זמן), `pricing` (הכנסה), `metrics` (עלות/זמן/ק״מ), `assessment` (הערכות).
קשור ל-[[soline-two-systems]] — זו שכבת ה-BI התפעולית.

## שורת KPI עליונה (stat tiles)
| KPI | חישוב |
|---|---|
| **הכנסות החודש** | Σ `pricing.total` לעבודות שנמסרו החודש |
| **רווחיות %** | (הכנסות − עלות) / הכנסות |
| **עבודות פעילות** | עבודות שאינן `closed`/`approved` |
| **זמן מחזור ממוצע** | ממוצע ימים `submitted → delivered` |
| **עבודות בפיגור** | עבודות שחרגו מהדדליין ועדיין פתוחות |

## פאנל תפעולי
- **משפך שלבים** — כמה עבודות בכל אחד מ-11 השלבים (איתור צווארי בקבוק).
- **חדשות מול נמסרות** — מגמה שבועית/חודשית.
- **שיעור לולאות תיקון** — % עבודות שחזרו (הזמנה חסרה / בירור / עיבוד / שטח / שינויי נגר). מדד איכות.
- **עמידה בזמנים (SLA)** — % עבודות שנמסרו עד הדדליין.

## פאנל כספי (אדמין)
- **הכנסה · עלות · רווח** — מגמה חודשית (שלושה קווים/עמודות).
- **רווחיות לפי סוג עבודה** (מטבח/מלא/חשמל...).
- **רווחיות לפי נגר** — מי רווחי ומי לא.
- **הכנסה/עלות ממוצעת לעבודה.**

## פאנל שטח ומודדים (מהמנוע)
- **זמן מדידה ממוצע** לפי סוג עבודה.
- **זמן נסיעה מול זמן מדידה** — יחס יעילות.
- **סה״כ ק״מ / ק״מ ממוצע לעבודה** — עלות נסיעה.
- **עומס לפי מודד** — עבודות/שעות לכל מודד.

## דיוק הערכה (לולאת שיפור)
- **הערכת זמן (`assessment`) מול זמן בפועל (מנוע)** — סטייה ממוצעת ומגמה.
- מזין בחזרה את שלב הבירור: ככל שהדיוק עולה, ההערכות והתמחור נעשים חדים יותר.

## נגרים
- **Top נגרים** לפי הכנסה/נפח.
- **נגרים חדשים** החודש.
